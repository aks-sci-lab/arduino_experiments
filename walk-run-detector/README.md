# 🏃 걷기·뛰기 판정기

스마트폰 가속도 센서로 걷기와 뛰기를 판정하는 **고등학교 물리학 실험용 웹앱**입니다.
설치 없이 스마트폰 브라우저에서 바로 실행되며, Gemini AI에게 측정 결과의 물리적 해석을 요청할 수 있습니다.

## 주요 기능

- **실시간 측정**: `devicemotion` 이벤트의 중력 포함 가속도 크기 |a| 를 그래프로 표시
- **자동 판정**: 최근 4초 구간의 표준편차 σ, 최소 |a|(체공 여부), 걸음 수·케이던스로 정지/걷기/뛰기 판정
- **기준값 조절·보정**: 학생이 기준값을 직접 바꾸거나, 걷기·뛰기를 10초씩 기록해 자신만의 기준을 만듦
- **CSV 내보내기**: 원본 데이터(시간, ax, ay, az, |a|)와 구간 분석 결과를 엑셀·구글 시트에서 분석
- **시뮬레이션**: 센서가 없는 PC에서도 걷기/뛰기 신호로 수업 시연 가능
- **AI 분석 (Gemini API)**: 측정 요약을 보내 판정 근거, 물리 개념 설명, 측정 개선 팁, 탐구 질문을 받음 + 자유 질문
- **탭 화면**: 측정 / 기준 / AI 분석 / 원리 / 관리자(관리자에게만 표시)

## 판정 원리

| 구분 | 걷기 | 뛰기 |
|---|---|---|
| 지면 접촉 | 항상 한 발 이상 접촉 | 두 발 모두 떨어지는 **체공 구간** 존재 |
| 최소 \|a\| | 약 0.6g 이상 | 체공 중 자유낙하 → **0 근처** |
| 최대 \|a\| | 약 1.5g | 착지 충격 → 2~3g 이상 |
| 흔들림 σ | 작음 | 큼 |

기본 규칙 (화면에서 변경 가능):

1. σ < 0.6 m/s² → **정지**
2. σ ≥ 4.0 m/s² → **뛰기**
3. 최소 |a| ≤ 2.5 m/s² 이고 걸음이 2개 이상 → **뛰기** (체공 구간)
4. 그 외 → **걷기**

## AI 기능 설정 (Gemini · 관리자)

AI 분석은 **Google Gemini** API를 사용하며, 모델과 API 키는 **관리자가 Firebase(Firestore)에 저장**합니다.

1. [Google AI Studio](https://aistudio.google.com/apikey)에서 Gemini API 키를 발급합니다.
   - 발급 후 키에 **웹사이트(HTTP 리퍼러) 제한**(`https://<계정>.github.io/*`)과 **사용량 한도**를 설정하세요.
2. **Firestore 규칙을 배포**합니다 (저장소 루트의 `firestore.rules`, 최초 1회).
   ```bash
   firebase deploy --only firestore:rules
   ```
3. 관리자(교사 권한이 있는 구글 계정)로 앱에 로그인하면 **🔧 관리자** 탭이 나타납니다.
   - 키 입력 → **모델 목록 불러오기**로 사용 가능한 Gemini 모델 선택 → **연결 테스트** → **저장**
   - "로그인한 학생도 AI 분석 사용 허용"을 끄면(기본) 관리자만 AI를 쓸 수 있습니다.
4. 학생은 구글 로그인 후 **🤖 AI 분석** 탭을 사용합니다(허용된 경우).

접근 제어 (`firestore.rules`의 `appConfig`):
- 로그인하지 않은 사람은 키를 읽을 수 없습니다.
- 읽기는 관리자, 또는 관리자가 학생 사용을 허용했을 때의 로그인 사용자만 가능합니다.
- 쓰기·삭제는 관리자만 가능합니다.
- 관리자 지정은 기존과 같습니다: `lany0665@gmail.com` 또는 `roles/{uid}.isTeacher == true` (`Grant Teacher Role` 워크플로).

보안 참고:
- 학생 사용을 허용하면 로그인한 학생의 브라우저로 키가 전달되어 개발자도구로 볼 수 있습니다. 반드시 위의 리퍼러 제한과 사용량 한도를 설정하세요.
- AI에는 원본 데이터 전체가 아닌 통계 요약과 최근 8초의 10Hz 파형만 전송됩니다.

## 수업 활용 아이디어

1. 천천히 걷기 → 빠르게 걷기 → 조깅 → 질주 순서로 σ와 케이던스 변화를 표로 정리

4. 모둠별 기준값을 비교해 모두에게 잘 맞는 판정 기준 찾기
5. AI 판정과 규칙 판정이 다를 때 그 이유 분석
