# 🏃 걷기·뛰기 판정기

스마트폰 가속도 센서 데이터를 학생들이 직접 모아 **머신러닝 모델을 학습**시키고, **조별 모델을 비교**하는 고등학교 1~2학년 빅데이터 수업용 웹앱입니다. 설치 없이 스마트폰 브라우저에서 실행됩니다.

## 화면 구성 (탭)

세로 스크롤을 줄이려고 큰 탭 안에서도 하위 탭으로 화면을 나눴습니다.

| 탭 | 하위 탭 | 하는 일 |
|---|---|---|
| 📱 판정 | | 학습된 모델로 실시간 판정, 라벨별 확률 막대, 그래프 |
| 🧪 데이터 | 기록하기 · 내 데이터 · 라벨 | 라벨을 붙여 12~30초 기록, 학급 데이터 불러오기, **라벨 추가**(계단, 제자리 뛰기 등 최대 6개) |
| 🔍 탐색 | 특징 순위·분포 · 2차원 산점도 | "두 동작을 구별하려면 어떤 데이터가 필요한가?" 특징별 구별력 순위, 히스토그램 |
| 🧠 학습 | 설정·학습 · 결과 · 학습곡선 | **사용할 특징 직접 선택**, 모델 종류 선택, 정확도·혼동 행렬·가중치, 데이터 양에 따른 정확도 변화 |

| 🤖 AI | API 선택 · 분석·질문 · 토큰 비교 | 교사 제공 API / 내 API 키 선택, Gemini 해석, LLM 토큰 비교 |
| 📘 원리 | | 물리·머신러닝·토큰 개념, 탐구 활동 아이디어 |

## 수업 진행 예시 (45분 × 2차시)

1. **기록**: 조별로 걷기·뛰기(+조가 정한 새 라벨)를 여러 사람·속도·휴대폰 위치(손/주머니/팔)로 기록하고 학급 데이터로 올림
2. **탐색**: 어떤 특징이 걷기/뛰기를 가장 잘 가르는지 순위·분포로 확인, 물리적 이유 토의 (체공, 착지 충격 F·Δt = Δp)
3. **학습**: 특징을 1개/3개/전체로 바꿔 학습해 보고, 학습곡선으로 "데이터가 얼마나 필요한가" 확인
4. **조별 비교**: 교사가 지정한 평가용 기록으로 모든 조 모델을 채점, 1등 모델의 비결 토의 (자체 정확도와 평가 정확도의 차이 = 일반화)
5. **토큰 비교**: 같은 구간을 LLM에게 물을 때 입력 형식별 토큰·정확도, 우리 모델(토큰 0)과 비교

## 화면 편집 모드 (교사 전용)

관리자로 로그인하면 헤더에 **✏ 화면 편집** 버튼이 보입니다. 코드를 몰라도 화면을 다듬을 수 있습니다.

- **문구 수정**: 문구를 눌러 선택 → "문구 수정". 굵게(`<b>`)·기울임(`<i>`)·줄바꿈(`<br>`)만 쓸 수 있고 그 밖의 태그는 자동으로 제거됩니다.
- **숨기기**: 필요 없는 안내·블록·탭을 숨깁니다(삭제가 아니라서 언제든 "다시 보이기"). 편집 중에는 숨긴 항목이 흐리게 보입니다.
- **순서 변경**: 블록·버튼·통계 타일·탭을 ▲▼로 이동. 타일처럼 안쪽 글자가 선택되면 "⬆ 상위 선택"으로 바깥 블록을 고릅니다.
- 편집 중에는 측정·학습 등 버튼이 동작하지 않습니다. 탭은 눌러서 이동할 수 있습니다.
- **저장하고 종료**를 누르면 Firebase(`walkRunLayout/current`)에 저장되어 **모든 학생 화면에 똑같이 적용**됩니다. "취소"는 저장 전 상태로, "전체 초기화"는 원래 화면으로 되돌립니다.
- 문구가 같으면 코드를 업데이트해도 편집이 유지됩니다. 결과 표·상태 메시지처럼 앱이 계속 바꾸는 부분은 편집 대상이 아닙니다.
- 편집은 읽기는 누구나, 쓰기는 교사만 가능하며(`firestore.rules`) 스크립트나 속성은 저장할 수 없습니다.

## 모델이 보는 특징 (10개)

휴대폰을 어떻게 들었는지와 무관하도록 가속도 크기 |a| = √(ax²+ay²+az²) 만 쓰고, 센서 주기가 달라도 같도록 50Hz로 다시 표본화한 뒤 4초 구간마다 계산합니다.

평균 |a|, 표준편차 σ, 최소 |a|(체공 ≈ 0), 최대 |a|(착지 충격), 90%−10% 폭, 평균 변화율, 케이던스, 주기성(자기상관), |a|<3 비율, |a|>15 비율

- **모델**: 로지스틱(소프트맥스) 회귀(라벨별 가중치 확인 가능), k-최근접 이웃. 라벨이 3개 이상이면 다중 분류.
- **테스트 분리**: 같은 기록의 구간이 학습·테스트에 섞이면 정확도가 부풀려지므로 **기록 단위**로 나눕니다.
- 흔들림이 거의 없으면(σ < 0.5) 분류하지 않고 "움직임 없음"으로 표시합니다.

## 조별 모델 비교 방식

- 학생 한 명이 모델 하나를 조 이름과 함께 게시합니다(다시 게시하면 덮어씀). 같은 조 학생이 각자 만든 모델도 같은 조 이름으로 게시해 비교할 수 있습니다.
- **공정한 채점**: 교사가 학급 데이터 중 일부를 **평가용**으로 지정하면(🧪 데이터 → 내 데이터의 "평가용" 체크), 그 기록은 학생 학습에서 자동으로 빠지고 모든 모델을 같은 기록으로 채점합니다. 시험 문제를 미리 보고 공부한 것처럼 점수가 부풀려지는 것을 막기 위해서입니다.
- 평가 데이터로 "불러온 학급 데이터 전체"나 "내 기록"도 고를 수 있지만 학습에 쓴 기록이 섞여 점수가 높게 나옵니다(화면에 경고 표시).
- 표시 항목: 평가 정확도, F1, 학생이 학습 때 본 자체 정확도와의 차이, 모델 크기, 추론 시간, 라벨별 재현율.
- **평가용 기록은 라벨마다 다양한 사람·동작으로 교사가 직접 기록해 지정하는 것을 권장합니다.**

## API 선택 (🤖 AI 탭)

AI는 **Google Gemini** REST API를 브라우저에서 직접 호출합니다.

- **교사가 제공한 API(제한됨)**: 교사가 🔧 관리자 탭에서 키·모델·학생 1인당 하루 사용 횟수를 설정. 키는 Firebase에 저장되고 로그인하지 않은 사람은 읽을 수 없습니다.
- **내 API 키**: 학생이 자신의 Gemini 키와 모델을 입력(로그인 불필요). "이 기기에 저장"을 체크하지 않으면 새로고침 시 사라집니다. 요금은 키 주인에게 청구됩니다.

보안·비용 참고:
- 교사 API를 학생에게 허용하면 로그인한 학생의 브라우저로 키가 전달되어 개발자도구로 볼 수 있습니다. **Google AI Studio/Cloud 콘솔에서 이 키에 웹사이트(HTTP 리퍼러) 제한과 사용량(할당량) 한도를 반드시 설정**하세요.
- **하루 사용 횟수는 앱 화면에서만 적용되는 안내용**입니다(브라우저에서 우회 가능). 실제 상한은 키의 할당량으로 거세요.
- AI에는 원본 데이터 전체가 아닌 통계 요약과 최근 8초의 10Hz 파형만 전송됩니다.

## 토큰 비교 (🤖 AI → 토큰 비교)

같은 4초 구간을 Gemini에게 "무슨 동작이야?"라고 물을 때 입력 형식에 따라 토큰이 얼마나 다른지 봅니다.

- 원시 파형 50Hz(숫자 200개) / 파형 10Hz(40개) / 특징 10개
- **토큰 수만 세기**: `countTokens`로 생성 없이 계산(저렴)
- **실제로 분류시키기**: 입력·출력·생각(thinking) 토큰, 응답 시간, 정확도를 우리 모델과 나란히 비교 (우리 모델은 토큰 0, 응답은 1000분의 몇 ms)
- "1시간 환산" = 2초마다 판정할 때 1800번의 합계

### Firestore 규칙 배포 (최초 1회, 클라우드 기능에 필요)

저장소 루트의 `firestore.rules`에 다음 규칙이 들어 있습니다. 배포해야 학급 데이터·조별 모델·교사 API가 동작합니다.

```bash
firebase deploy --only firestore:rules
```

## 구글 로그인이 안 될 때

화면 위쪽에 원인이 표시됩니다. 자주 있는 경우:

| 표시되는 내용 | 원인 · 해결 |
|---|---|
| "승인된 도메인에 없습니다" (`auth/unauthorized-domain`) | **가장 흔한 원인.** 배포 주소(예: `aks-sci-lab.github.io`)를 Firebase 콘솔 → Authentication → 설정 → **승인된 도메인**에 추가 |
| "Google 로그인이 꺼져 있습니다" | Firebase 콘솔 → Authentication → 로그인 방법 → **Google 사용 설정** |
| "앱 안의 브라우저에서는 막힙니다" | 카카오톡·네이버 등에서 링크를 연 경우. Chrome/Safari에서 주소를 직접 열기 (구글 정책상 앱 내 브라우저는 로그인 불가) |
| 팝업이 안 뜸 | 팝업 차단 시 자동으로 페이지 이동 방식으로 다시 시도 |

## 좋은 데이터 모으는 법

- 걷기·뛰기를 각각 **여러 사람이, 여러 속도로, 여러 휴대폰 위치**에서 기록할수록 처음 보는 상황에서도 잘 맞습니다.
- 라벨을 틀리게 붙이면 모델이 나빠집니다(그래프를 보고 저장하세요).
- 시뮬레이션 데이터는 수업 시연용입니다. 두 동작이 매우 깔끔하게 갈려서 정확도가 비현실적으로 높게 나오므로, 실제 성능은 센서 데이터로 평가하세요.
