# 🏃 걷기·뛰기 판정기

스마트폰 가속도 센서로 걷기와 뛰기를 판정하는 **고등학교 물리학 실험용 웹앱**입니다.
설치 없이 스마트폰 브라우저에서 바로 실행되며, 학생이 모은 데이터로 걷기/뛰기 분류 모델을 직접 학습하고, Gemini AI에게 측정 결과의 물리적 해석을 요청할 수 있습니다.

## 주요 기능

미리 정해 둔 기준값으로 판정하지 않고, **학생들이 모은 걷기·뛰기 데이터로 모델을 학습**시켜 판정합니다.

1. **🧪 데이터**: 라벨(걷기/뛰기)을 정하고 3초 카운트다운 뒤 12~30초 기록. 기록은 이 기기에 저장되고, 원하면 **학급 공용 데이터(Firebase)** 로도 올립니다. 학급 데이터를 불러와 합쳐 학습할 수 있습니다(빅데이터).
2. **🧠 학습**: 기록을 4초 구간(2초씩 이동)으로 잘라 10가지 특징을 계산하고 **로지스틱 회귀** 또는 **k-최근접 이웃**을 브라우저에서 학습합니다.
   - 테스트는 **기록 단위로 분리**(같은 기록의 구간이 학습·테스트에 섞이지 않음)
   - 학습/테스트 정확도, 정밀도·재현율, 혼동 행렬, 특징별 가중치, 특징 산점도(★ = 방금 판정한 구간)
   - 교사는 학습한 모델을 **반 모델로 게시**, 학생은 불러와 사용
3. **📱 판정**: 학습된 모델로 실시간 판정(뛰기일 확률 표시). 흔들림이 거의 없으면(σ < 0.5) 분류하지 않고 "움직임 없음"으로 표시합니다.
4. **🤖 AI (Gemini)**: 판정 근거·물리 해석·탐구 질문, 학습 결과(과적합 여부, 데이터 보강 방향) 해석, 자유 질문
5. **📘 원리 / 🔧 관리자**: 물리·머신러닝 개념 설명 / Gemini 모델·API 키 설정(관리자만)
6. CSV 내보내기(원본 |a|, 구간별 판정, 학습용 특징), 센서 없는 PC용 시뮬레이션

## 특징 (모델이 보는 10개 숫자)

휴대폰을 어떻게 들었는지와 무관하도록 가속도 크기 |a| = √(ax²+ay²+az²) 만 사용하고, 센서 주기가 달라도 같도록 50Hz로 다시 표본화한 뒤 계산합니다.

평균 |a|, 표준편차 σ, 최소 |a|(체공 ≈ 0), 최대 |a|(착지 충격), 90%−10% 폭, 평균 변화율, 케이던스, 주기성(자기상관), |a|<3 비율, |a|>15 비율

## 좋은 데이터 모으는 법

- 걷기·뛰기를 각각 **여러 사람이, 여러 속도로, 여러 휴대폰 위치(손/주머니/팔)** 에서 기록할수록 처음 보는 상황에서도 잘 맞습니다.
- 라벨을 틀리게 붙이면 모델이 나빠집니다(그래프를 보고 저장하세요).
- 시뮬레이션 데이터는 수업 시연용입니다. 두 동작이 매우 깔끔하게 갈려서 정확도가 비현실적으로 높게 나오므로, 실제 성능은 센서 데이터로 평가하세요.

## AI 기능 설정 (Gemini · 관리자)

AI 분석은 **Google Gemini** API를 사용하며, 모델과 API 키는 **관리자가 Firebase(Firestore)에 저장**합니다.

1. [Google AI Studio](https://aistudio.google.com/apikey)에서 Gemini API 키를 발급합니다.
   - 발급 후 키에 **웹사이트(HTTP 리퍼러) 제한**(`https://<계정>.github.io/*`)과 **사용량 한도**를 설정하세요.
2. **Firestore 규칙을 배포**합니다 (저장소 루트의 `firestore.rules`, 최초 1회).
   ```bash
   firebase deploy --only firestore:rules
   ```
3. 관리자(교사 권한이 있는 구글 계정)로 앱에 로그인하면 **🔧 관리자** 탭이 나타납니다.
   - 키 입력 → **모델 목록 불러오기**로 사용 가능한 Gemini 모델 선택 → **연결 테스트** → **저장**
   - "로그인한 학생도 AI 분석 사용 허용"을 끄면(기본) 관리자만 AI를 쓸 수 있습니다.
4. 학생은 구글 로그인 후 **🤖 AI** 탭을 사용합니다(허용된 경우).

접근 제어 (`firestore.rules`):

- `walkRunData`(학급 학습 데이터): 로그인한 사용자만 읽기, 본인 이름으로만 올리기, 본인 또는 교사만 삭제. 업로드에는 이메일을 넣지 않고 Firebase uid만 저장합니다.
- `walkRunModel`(반 모델): 로그인한 사용자 읽기, 교사만 게시.
- `appConfig`(Gemini 설정):
- 로그인하지 않은 사람은 키를 읽을 수 없습니다.
- 읽기는 관리자, 또는 관리자가 학생 사용을 허용했을 때의 로그인 사용자만 가능합니다.
- 쓰기·삭제는 관리자만 가능합니다.
- 관리자 지정은 기존과 같습니다: `lany0665@gmail.com` 또는 `roles/{uid}.isTeacher == true` (`Grant Teacher Role` 워크플로).

보안 참고:
- 학생 사용을 허용하면 로그인한 학생의 브라우저로 키가 전달되어 개발자도구로 볼 수 있습니다. 반드시 위의 리퍼러 제한과 사용량 한도를 설정하세요.
- AI에는 원본 데이터 전체가 아닌 통계 요약과 최근 8초의 10Hz 파형만 전송됩니다.

## 파일 구조

```
index.html        화면 (탭: 판정 / 데이터 / 학습 / AI / 원리 / 관리자)
style.css         스타일 (다크 모드 지원)
app.js            화면 동작 전체 (판정, 기록, 학습, 탭, 로그인, 관리자)
analysis.js       50Hz 표본화 · 특징 추출 · 시뮬레이션 (순수 함수)
ml.js             로지스틱 회귀 · kNN · 기록 단위 분리 · 평가 (순수 함수)
dataset.js        이 기기의 기록·모델 저장 (localStorage)
sampler.js        센서/시뮬레이션 표본 수집
charts.js         canvas 그래프 (시계열, 타임라인, 산점도)
accounts.js       Firebase 로그인 · 관리자 확인 · AI 설정 · 학급 데이터 · 반 모델
ai.js             Gemini API 호출 (구조화된 JSON 응답)
```
