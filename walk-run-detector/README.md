# 🏃 걷기·뛰기 판정기

스마트폰 가속도 센서로 걷기와 뛰기를 판정하는 **고등학교 물리학 실험용 웹앱**입니다.
설치 없이 스마트폰 브라우저에서 바로 실행되며, Claude AI에게 측정 결과의 물리적 해석을 요청할 수 있습니다.

## 주요 기능

- **실시간 측정**: `devicemotion` 이벤트의 중력 포함 가속도 크기 |a| 를 그래프로 표시
- **자동 판정**: 최근 4초 구간의 표준편차 σ, 최소 |a|(체공 여부), 걸음 수·케이던스로 정지/걷기/뛰기 판정
- **기준값 조절·보정**: 학생이 기준값을 직접 바꾸거나, 걷기·뛰기를 10초씩 기록해 자신만의 기준을 만듦
- **CSV 내보내기**: 원본 데이터(시간, ax, ay, az, |a|)와 구간 분석 결과를 엑셀·구글 시트에서 분석
- **시뮬레이션**: 센서가 없는 PC에서도 걷기/뛰기 신호로 수업 시연 가능
- **AI 분석 (Claude API)**: 측정 요약을 보내 판정 근거, 물리 개념 설명, 측정 개선 팁, 탐구 질문을 받음 + 자유 질문

## 판정 원리

| 구분 | 걷기 | 뛰기 |
|---|---|---|
| 지면 접촉 | 항상 한 발 이상 접촉 | 두 발 모두 떨어지는 **체공 구간** 존재 |
| 최소 \|a\| | 약 0.6g 이상 | 체공 중 자유낙하 → **0 근처** |
| 최대 \|a\| | 약 1.5g | 착지 충격 → 2~3g 이상 |
| 흔들림 σ | 작음 | 큼 |

기본 규칙 (화면에서 변경 가능):

1. σ < 0.6 m/s² → **정지**
2. σ ≥ 4.0 m/s² → **뛰기**
3. 최소 |a| ≤ 2.5 m/s² 이고 걸음이 2개 이상 → **뛰기** (체공 구간)
4. 그 외 → **걷기**

## 실행 방법

센서는 **HTTPS** 주소에서만 동작합니다.

### GitHub Pages로 배포 (권장)
1. 이 폴더의 내용을 새 GitHub 저장소의 루트에 올립니다.
2. 저장소 **Settings → Pages → Source** 를 **GitHub Actions** 로 설정합니다.
3. `main` 브랜치에 push하면 `.github/workflows/pages.yml` 이 자동 배포합니다.
4. `https://<계정>.github.io/<저장소>/` 주소를 학생들에게 QR 코드로 공유합니다.

### PC에서 화면 확인
```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 → 시뮬레이션 버튼 사용
```

## AI 기능 설정

1. [Anthropic Console](https://console.anthropic.com)에서 API 키를 발급합니다.
   - 수업용이라면 교사가 별도 워크스페이스를 만들고 **월 사용 한도**를 설정한 키를 쓰는 것을 권장합니다.
2. 앱의 "AI 분석" 칸에 키를 입력합니다. "이 기기에 키 저장"을 체크하면 해당 브라우저에만 저장됩니다.
3. 모델 선택: Opus 5.5(기본, 가장 정확) / Sonnet 5.5 / Haiku 5.5(가장 저렴).

보안 참고:
- 키는 브라우저에서 Anthropic API로 **직접** 전송되며 다른 서버를 거치지 않습니다.
- 공용 기기에서는 "키 저장"을 체크하지 마세요. 키를 코드에 넣어 커밋하지 마세요.
- AI에는 원본 데이터 전체가 아닌 통계 요약과 최근 8초의 10Hz 파형만 전송됩니다.

## 수업 활용 아이디어

1. 천천히 걷기 → 빠르게 걷기 → 조깅 → 질주 순서로 σ와 케이던스 변화를 표로 정리
2. 휴대폰 위치(손/주머니/팔)에 따른 결과 차이와 원인 토의
3. 충격량-운동량 관계(FΔt = Δp)로 착지 봉우리 크기 설명, 쿠션 신발의 효과 예측
4. 모둠별 기준값을 비교해 모두에게 잘 맞는 판정 기준 찾기
5. AI 판정과 규칙 판정이 다를 때 그 이유 분석
