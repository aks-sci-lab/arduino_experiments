4. 물리 원리

가속도 센서는 무엇을 재나요?

스마트폰 가속도 센서는 중력을 포함한 가속도를 잽니다. 가만히 놓아 두면 |a| ≈ g = 9.8 m/s²이 나오고, 자유낙하하면 |a| ≈ 0이 됩니다. 센서는 내부의 작은 추가 받는 힘(수직항력과 같은 접촉력)을 측정하기 때문입니다.

걷기와 뛰기는 왜 다르게 보이나요?
  • 걷기: 항상 한 발 이상이 땅에 닿아 있습니다. 몸의 위아래 흔들림이 작아 |a|는 대략 0.6g~1.5g 사이에서 부드럽게 오르내립니다.
  • 뛰기: 두 발이 모두 땅에서 떨어지는 체공 구간이 있습니다. 이때 몸은 거의 자유낙하 상태라 |a|가 0 근처까지 떨어지고, 착지 순간에는 지면이 짧은 시간에 큰 힘을 주어 2g~3g 이상의 큰 봉우리가 생깁니다.
  • 그래서 뛰기는 σ(흔들림)가 크고, 최소 |a|가 작으며, 케이던스도 보통 더 높습니다.
탐구 활동 아이디어
  1. 천천히 걷기 → 빠르게 걷기 → 조깅 → 전력 질주 순서로 σ와 케이던스가 어떻게 변하는지 표로 정리해 보세요.
  2. 휴대폰 위치(손, 주머니, 팔)를 바꾸면 결과가 어떻게 달라지나요? 이유는?
  3. 운동량-충격량 관계(F·Δt = Δp)로 착지 봉우리의 크기를 설명해 보세요. 쿠션 있는 신발은 무엇을 바꿀까요?
  4. 친구들과 기준값을 비교해 보고, 모두에게 잘 맞는 기준을 찾아보세요.
