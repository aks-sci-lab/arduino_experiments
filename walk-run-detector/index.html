AI에게 질문하기

가속도 센서는 무엇을 재나요?

스마트폰 가속도 센서는 중력을 포함한 가속도를 잽니다. 가만히 놓아 두면 |a| ≈ g = 9.8 m/s²이 나오고, 자유낙하하면 |a| ≈ 0이 됩니다. 센서는 내부의 작은 추가 받는 힘(수직항력과 같은 접촉력)을 측정하기 때문입니다. 세 축의 크기 |a| = √(ax²+ay²+az²) 는 휴대폰을 어떻게 들었는지와 상관없이 쓸 수 있습니다.

걷기와 뛰기는 왜 다르게 보이나요?
  • 걷기: 항상 한 발 이상이 땅에 닿아 있어 |a|가 g 근처에서 부드럽게 오르내립니다.
  • 뛰기: 두 발이 모두 떨어지는 체공 때문에 |a|가 0 근처까지 내려가고, 착지 때 지면이 짧은 시간에 큰 힘을 주어 큰 봉우리가 생깁니다. (F·Δt = Δp)
이 앱은 어떻게 "학습"하나요? (머신러닝)
  1. 데이터 모으기: 걷기/뛰기라는 정답(라벨)을 붙여 기록합니다.
  2. 특징 뽑기: 4초 구간마다 평균, 흔들림 σ, 최소·최대, 케이던스 등 10개 숫자로 요약합니다.
  3. 학습: 정답이 있는 예시에서 "어떤 특징이 어떤 값일 때 뛰기였나"를 컴퓨터가 스스로 찾습니다. 사람이 기준값을 정하지 않습니다.
  4. 평가: 학습에 쓰지 않은 기록으로 정확도를 잽니다. 이것이 진짜 실력입니다.
  5. 판정: 새 구간의 특징을 모델에 넣으면 "뛰기일 확률"이 나옵니다. 0.5 이상이면 뛰기입니다.

데이터가 많고 다양할수록(사람, 속도, 휴대폰 위치) 처음 보는 상황에서도 잘 맞힙니다. 이것이 "빅데이터"의 힘입니다.

탐구 활동 아이디어
  1. 기록을 2개, 10개, 40개로 늘리며 테스트 정확도가 어떻게 변하는지 그래프로 그려 보세요.
  2. 나 혼자 모은 데이터로 학습한 모델이 친구에게도 잘 맞을까요? 학급 데이터를 합치면 달라지나요?
  3. 휴대폰을 손/주머니/팔에 둔 기록만 따로 학습시켜 비교해 보세요.
  4. 로지스틱 회귀의 가중치가 큰 특징은 물리적으로 왜 중요할까요?
  5. 일부러 걷기를 "뛰기"라고 잘못 붙인 기록을 섞으면(라벨 오류) 정확도가 얼마나 떨어지나요?
