라벨(동작)을 고르고 휴대폰을 든 채로 그 동작을 하세요. 사람·속도·휴대폰 위치를 바꿔 여러 번 기록할수록 모델이 좋아집니다.

데이터 출처

버튼을 누르면 3초 카운트다운 뒤 기록이 시작됩니다. 시작 전에 휴대폰을 몸에 고정하세요.

☆ 평가용: 교사가 지정한 기록은 학습에서 빠지고 조별 모델 비교에만 쓰입니다.

걷기·뛰기 말고도 동작을 추가해 보세요 (예: 계단 오르기, 제자리 뛰기, 천천히 걷기). 라벨이 3개 이상이면 모델이 여러 동작을 구별합니다. 최대 6개.

추가한 라벨에는 시뮬레이션 데이터가 없습니다. 센서로 직접 기록하세요. 라벨마다 기록이 2개 이상 있어야 학습할 수 있습니다.

두 동작을 구별하려면 어떤 데이터가 필요할까? 모은 데이터를 특징별로 살펴보고, 가장 잘 구별하는 특징을 찾아보세요. 이 결과를 보고 🧠 학습 탭에서 쓸 특징을 직접 고를 수 있습니다.

"정확도" = 그 특징 하나에 기준선 한 줄만 그어 맞힌 비율 (50%는 찍기). 줄을 누르면 아래에 분포가 나옵니다.

분포

★ = 📱 판정 탭에서 방금 판정한 구간. 점들이 라벨별로 뭉쳐 갈라질수록 구별하기 쉬운 특징 조합입니다.

기록을 4초 구간(2초씩 이동)으로 잘라 특징을 계산하고, 라벨을 구별하도록 학습합니다. 학습은 이 브라우저 안에서 이루어집니다.

사용할 특징

아직 학습한 결과가 없습니다. ⚙ 설정·학습에서 학습을 시작하세요.

테스트 정확도는 학습에 쓰지 않은 기록으로 잰 값입니다. 학습 정확도만 높고 테스트 정확도가 낮으면 외워버린(과적합) 것입니다.

라벨별 성적 (테스트)

혼동 행렬 (테스트) — 행: 실제, 열: 예측

어떤 특징을 중요하게 봤나? (표준화 가중치)

양수(빨강)면 그 특징이 클수록 해당 라벨 쪽으로, 음수(파랑)면 반대쪽으로 판단합니다.

데이터가 얼마나 있어야 할까? 같은 테스트 기록으로, 학습 기록을 라벨마다 1개, 2개, 3개… 늘려 가며 정확도가 어떻게 달라지는지 봅니다. (⚙ 설정의 특징·모델 종류로 계산)

선: 평균 테스트 정확도, 음영: 4번 반복했을 때의 최소~최대. 곡선이 아직 오르고 있다면 데이터를 더 모으면 좋아진다는 뜻입니다.

조별로 모델을 만들어 게시하면, 모든 조의 모델을 같은 평가용 기록으로 채점해 비교할 수 있습니다. 로그인이 필요합니다.

한 사람당 모델 하나만 게시됩니다(다시 게시하면 덮어씀). 같은 조 학생이 각자 만든 모델도 같은 조 이름으로 게시해 비교할 수 있습니다.

비교할 라벨

"자체 정확도"는 학생이 학습할 때 본 테스트 정확도, "평가 정확도"는 여기서 새로 채점한 값입니다. 둘의 차이가 크면 처음 보는 데이터에 약한 모델입니다.

어떤 API를 쓸까요?

키는 이 브라우저에서 Google 서버로만 전송되며 선생님·다른 학생에게 보이지 않습니다. 사용 요금은 키 주인에게 청구됩니다. 키는 Google AI Studio에서 발급합니다.

측정·학습 결과 요약을 AI에게 보내 판정 근거와 물리적 해석을 받아봅니다. 원본 데이터 전체가 아니라 통계 요약과 짧은 파형만 전송됩니다.

학습 결과 해석

AI에게 질문하기

LLM으로 동작을 분류하면 토큰이 얼마나 들까? 같은 4초 구간을 Gemini에게 "무슨 동작이야?" 하고 물을 때, 입력 형식에 따라 토큰이 달라집니다. 우리가 학습시킨 모델은 같은 일을 토큰 0개로 합니다.

입력 형식

가속도 센서는 무엇을 재나요?

스마트폰 가속도 센서는 중력을 포함한 가속도를 잽니다. 가만히 놓아 두면 |a| ≈ g = 9.8 m/s²이 나오고, 자유낙하하면 |a| ≈ 0이 됩니다. 세 축의 크기 |a| = √(ax²+ay²+az²) 는 휴대폰을 어떻게 들었는지와 상관없이 쓸 수 있습니다.

걷기와 뛰기는 왜 다르게 보이나요?
  • 걷기: 항상 한 발 이상이 땅에 닿아 있어 |a|가 g 근처에서 부드럽게 오르내립니다.
  • 뛰기: 두 발이 모두 떨어지는 체공 때문에 |a|가 0 근처까지 내려가고, 착지 때 지면이 짧은 시간에 큰 힘을 주어 큰 봉우리가 생깁니다. (F·Δt = Δp)
이 앱은 어떻게 "학습"하나요? (머신러닝)
  1. 데이터 모으기: 동작 이름(라벨)을 붙여 기록합니다.
  2. 특징 뽑기: 4초 구간마다 평균, 흔들림 σ, 최소·최대, 케이던스 등 10개 숫자로 요약합니다.
  3. 탐색: 어떤 특징이 두 동작을 잘 가르는지 살펴봅니다.
  4. 학습: 정답이 있는 예시에서 "어떤 특징이 어떤 값일 때 어느 라벨이었나"를 컴퓨터가 스스로 찾습니다.
  5. 평가: 학습에 쓰지 않은 기록으로 정확도를 잽니다. 이것이 진짜 실력입니다.
  6. 비교: 조마다 만든 모델을 같은 평가용 기록으로 채점해 가장 잘 구별하는 모델을 찾습니다.
빅데이터와 공정한 비교
  • 데이터가 많고 다양할수록(사람·속도·휴대폰 위치) 처음 보는 상황에서도 잘 맞힙니다. 학습곡선으로 확인해 보세요.
  • 모델 점수를 비교하려면 모든 조가 같은 평가용 기록으로 채점해야 하고, 그 기록은 학습에 쓰면 안 됩니다(시험 문제를 미리 보고 공부하면 점수가 부풀려지므로).
  • 라벨을 틀리게 붙이면 모델이 나빠집니다. 데이터 품질이 양만큼 중요합니다.
토큰이란? 머신러닝 모델과 LLM의 차이
  • 토큰은 LLM이 글을 읽고 쓰는 단위(대략 단어 조각)입니다. 입력·출력 토큰 수에 따라 시간과 비용이 정해집니다.
  • 숫자 200개를 그대로 넣으면 토큰이 많이 들고, 특징 10개로 요약하면 훨씬 적게 듭니다. 좋은 요약(특징)은 비용도 줄입니다.
  • 우리가 학습시킨 소형 모델은 곱셈·덧셈만 하므로 토큰이 0이고 1000분의 몇 초면 끝납니다. 대신 이 일 하나만 할 수 있습니다. LLM은 무엇이든 설명할 수 있지만 느리고 비쌉니다.
탐구 활동 아이디어
  1. 특징 하나만으로 걷기/뛰기를 얼마나 맞힐 수 있나요? 가장 약한 특징과 강한 특징은?
  2. 특징을 1개, 3개, 10개로 바꿔 학습해 정확도와 모델 크기를 비교해 보세요.
  3. 기록을 2개, 10개, 40개로 늘리며 학습곡선을 그려 보세요. 데이터는 얼마나 필요한가요?
  4. 나 혼자 모은 데이터 vs 학급 전체 데이터로 학습한 모델, 평가용 기록에서 어느 쪽이 높나요?
  5. "계단 오르기" 같은 라벨을 추가하면 걷기와 헷갈리나요? 혼동 행렬로 확인해 보세요.
  6. 일부러 라벨을 틀리게 섞으면 정확도가 얼마나 떨어지나요?
  7. 같은 구간을 LLM에게 물을 때 입력 형식별 토큰과 정확도를 비교하고, 우리 모델과 비교해 보세요.
