# 설계서: 데이터 가공 과정 체험 + 숨 참기 심박수 탐구

> 2026-11-17 선생님 승인("진행해"). 결정: 1부 사이트 체험만, 2부 안정→참기→회복 연속 측정, 비교 항목 운동 습관·성공/멈춘 시점·키·몸무게(구간), 성별은 받지 않음, 대상 고등학교 융합(과학+정보+윤리).

- 대상: 고등학교 **융합(과학 + 정보 + 윤리)**
- 목표: 원본(로우) 데이터 수집부터 가공·검증까지의 과정을 직접 체험하고(1부), 그 과정을 자기 탐구에 적용해 결론을 낸다(2부)
- 바탕: 지금 사이트의 **스마트폰 카메라 심박수**(손가락으로 뒤 카메라를 덮어 맥파 측정)

---

## 1부. 데이터 가공 실험실 (사이트 체험만, 코딩·수식 없음)

**자료:** 학생 자신의 측정 원본 + 선생님이 고른 **문제 있는 예시**(어두움·손가락 떨어짐·노출 출렁임, 선생님 실측 4회차 포함)

**화면:** 단계 상자가 위에서 아래로 이어지고, 상자마다 **전 → 후 그래프**와 바꿔 볼 설정이 있다. 설정을 바꾸면 아래 단계와 최종 심박수가 바로 다시 계산된다.

| 단계 | 하는 일 | 학생이 바꿔 보는 것 | 배울 점 |
|---|---|---|---|
| 0 원천 | 카메라 한 장(화소 수만 개) → 빨강·초록·밝기 평균 3개로 줄어드는 것 보기 | 평균 낼 영역 크기 | 원본도 이미 '요약'이다 |
| 1 수집 | 30초 원본 표(시각이 고르지 않음, 초당 장 수) | 보는 구간 | 표본 추출 빈도 |
| 2 점검·정제 | 손가락 떨어진 구간·너무 어두움·빠진 값 찾기 → 자르기 | 자를 구간(자동 제안 켜기/끄기) | 쓰레기가 들어가면 쓰레기가 나온다 |
| 3 변환 | 고른 간격으로 맞추기(보간), 채널 고르기, 노출 보정 | 빨강/초록/밝기, 보정 켜기/끄기 | 같은 원본, 다른 선택 |
| 4 걸러 내기 | 느린 흐름 빼기, 심박 범위만 남기기 | 이동평균 길이, 범위(분당 ○~○회) | 잡음과 신호 |
| 5 특징 뽑기 | 봉우리 → 박동 간격, 주파수 분석 | 봉우리 최소 간격 | 알고리즘의 가정 |
| 6 결과·검증 | 심박수 → 손목 맥박(15초×4)과 비교, 오차 | — | 정답과 비교해 평가 |

**핵심 활동:** 같은 원본으로 선택을 바꾸면 결과가 37회가 되기도, 78회가 되기도 한다(실제 사례). 학생은 단계마다 **"무엇을 골랐고 왜"를 한 줄씩 기록**하고, 이 기록이 과정 평가 자료가 된다. 기록은 보고서에 옮겨 쓸 수 있게 인쇄·복사.

## 2부. 탐구: 숨 참기와 심박수

**측정 순서** (한 학생 1회차, 연속 측정)

| 구간 | 길이 | 화면 |
|---|---|---|
| 안정 | 60초 | "편하게 앉아 숨 쉬세요" |
| 숨 참기 | **30초** 또는 **60초** | 큰 카운트다운, **■ 멈춤 단추**(힘들면 바로) |
| 회복 | 60초 | "편하게 숨 쉬세요" |

- 같은 학생이 30초 → (충분히 쉬고, 예: 3분 이상) → 60초를 한다 → **개인 안 비교** 가능
- 연속 심박 곡선(10초 창, 1초씩)과 구간 경계를 기록
- 자동 계산: 안정 평균, 숨 참기 마지막 10초 평균, **변화율(%)**, 가장 낮은 값과 그 시각, 회복 시간(안정 ±5% 로 돌아오기까지)
- 1부의 가공 과정을 그대로 적용(점검·정제 → … → 검증)

**함께 받는 항목** (모두 선택 입력, 이름·학번 없음, 조·번호로만)
- **운동 습관:** 주 0회 / 1~2회 / 3~4회 / 5회 이상
- **숨 참기 성공 여부·멈춘 시점:** 자동 기록(멈춤 단추를 누른 초)
- **키·몸무게:** **구간으로만**(예: 키 150대·160대·170대·180 이상, 몸무게 10 kg 구간)
- **성별은 받지 않는다**(선생님 결정: 민감 정보·고정관념 위험을 피하고 운동 습관·체격으로 비교)

**반 전체 비교** (교사 화면, 그리고 학생 결과 단계)
- 30초 vs 60초 변화율(개인별 선 + 평균)
- 운동 습관별·체격 구간별 변화율 분포(상자 그림)
- 숨 참기 중 시간에 따른 평균 곡선(구간별 묶음)
- 정돈된 CSV 내려받기(한 줄 = 한 회차, 열 설명서 포함)
- 화면 안내: "표본이 작아 차이는 우연일 수 있고, 한 요인만의 효과라고 단정할 수 없음" (윤리·통계 토론 거리)

## 안전 (화면과 수업 안내에 넣음)

- **반드시 앉은 자세**, 조원이 옆에서 관찰
- 힘들면 언제든 **■ 멈춤**, 멈춘 것도 정상 자료(실패가 아님)
- 천식·심장 질환·어지럼증·최근 아픈 학생은 참여하지 않고 다른 역할(관찰·기록)
- 시작 전 안전 확인 체크(앉음·관찰자 있음·몸 상태 괜찮음)를 해야 측정 단추가 켜짐
- 60초는 선택, 30초만 해도 됨

## 개인정보·윤리

- 이름·학번·성별을 받지 않음, 키·몸무게는 구간으로만, 모두 선택
- 영상은 저장·전송하지 않음(색 평균값만)
- 수업 시작 때 "이 자료를 수업 분석에 써도 됨" 동의 체크, 동의하지 않으면 자기 화면에서만 보고 반 전체 자료에는 들어가지 않음
- 저장: 선생님 구글 시트(지금 방식), 공개 저장소의 개발 자동 수집은 **선생님 기기만**(학생 자료는 올라가지 않음)
- 윤리 토론 소재: 건강 자료의 공개 범위, 익명화의 한계(작은 반에서 구간 정보로도 누구인지 알 수 있음), 비교 결과를 사람에게 낙인처럼 쓰지 않기

## 개발 순서 (승인 뒤)

1. **심박 측정 안정화 마무리** — 실제 폰에서 노출 잠금·밝기 맞추기 확인(진행 중)
2. **2부 프로토콜 측정 모드** — 안정→참기→회복 안내·카운트다운·멈춤·안전 체크·연속 곡선·자동 계산·선택 항목·동의 (심박 페이지에 추가)
3. **1부 데이터 가공 실험실** — 새 페이지, 단계 상자·전후 그래프·설정·기록, 예시 묶음
4. **반 전체 모으기·비교** — 수업 연결(조 코드)·교사 화면 비교 그래프·정돈된 CSV (서버 판 올림 필요할 수 있음 → 🔄 업데이트)
5. 수업 활동지(학생용 단계 기록지, 교사용 진행 안내) — 사이트 안 안내로

차시 예시: ① 1부 가공 체험(1~2차시) ② 2부 측정(1차시) ③ 반 전체 비교·토론(1차시)

## 아직 확인할 것

- 실제 폰(갤럭시 Z 플립6 외 학생 폰)에서 측정이 안정적인지 — 1번 단계에서 확인
- 숨 참기 중 손가락 힘·움직임으로 신호가 나빠지는 정도 — 측정해 보고 정제 단계에 반영
- 학교 개인정보 지침(건강 정보·체격 구간 수집)
