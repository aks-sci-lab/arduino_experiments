# 스마트폰 진자 — 선생님 설정 (한 번만)

학생 폰의 측정값이 **선생님 자기 구글 시트**에 저장되고, 같은 조 노트북 분석 화면에 자동으로 나타나게 하는 설정입니다.
**화면으로 하는 것을 권합니다**: https://aks-sci-lab.web.app/projects/pendulum-setup.html (구글 로그인 → 시트 만들기 → 배포 → 주소 붙여 넣기 → "우리 반 링크").

학생은 로그인하지 않고, 이름·학번·이메일은 저장하지 않습니다. 조 코드(예: `2-3-4821`, 반-조-숫자 4개)로만 구분합니다.

## 선생님마다 자기 시트 (2026-11-14 사용자 결정)

- 저장은 **Apps Script 를 유지**합니다(사용자가 Apps Script 웹앱 수업을 듣는 중). 나중에 필요하면 Firestore 로 바꿉니다.
- 선생님은 설정 화면에서 **구글 로그인** 후 자기 웹 앱 주소를 붙여 넣고 "연결 시험하고 저장" → 주소의 스크립트 ID 가 Firestore `pendulumTeachers/{선생님 uid}` 에 저장됩니다(본인만 읽고 씀). 코드·PR 수정이 필요 없습니다.
- 화면에 나오는 **우리 반 링크** `pendulum-report.html?s=<스크립트 ID>` 로 학생 노트북을 열면, 그 노트북은 그 시트를 기억하고 폰 QR 에도 `&s=<ID>` 를 넣습니다. 학생 쪽은 Firestore 를 읽지 않습니다.
- 링크 없이 열면 `js/pendulum-config.js` 의 기본 시트(`appsScriptUrl`)를 씁니다. 노트북 화면의 '기본 시트로 되돌리기'로 기억을 지울 수 있습니다.
- 폰은 기억하지 않고 링크(QR)의 `s` 만 따릅니다(예전 선생님 시트로 잘못 보내지 않게).
- **규칙 배포 필요**: `firestore.rules` 의 `pendulumTeachers` 규칙을 게시해야 계정 저장이 됩니다(게시 전에도 연결 시험·우리 반 링크는 됨).

## 템플릿 시트로 더 줄이기 (사이트 관리자가 한 번)

코드 붙여 넣기 대신 "사본 만들기" 한 번으로 시트와 스크립트를 함께 받게 할 수 있습니다(구글 시트를 복사하면 그 시트에 붙은 Apps Script 도 함께 복사됨, 배포는 복사되지 않아 선생님이 2번 배포는 해야 함).

1. 새 시트(학생 데이터가 없는 깨끗한 시트)를 만들고 이름을 "진자 실험 템플릿"으로 정한다.
2. 확장 프로그램 → Apps Script 에 `apps-script/Code.gs` 를 붙여 넣고 저장(배포는 안 해도 됨).
3. `공유` → 일반 액세스: **링크가 있는 모든 사용자 · 뷰어** → 링크 복사.
4. 링크 끝의 `/edit…` 를 `/copy` 로 바꾼 주소(`https://docs.google.com/spreadsheets/d/<ID>/copy`)를 `js/pendulum-config.js` 의 `templateCopyUrl` 에 넣는다(Claude 대화에 알려 주면 대신 넣음). 설정 화면 1번에 "📄 템플릿 시트 사본 만들기" 단추가 나온다.

## 순서 (코드 붙여 넣기로 직접 만들 때)

1. **구글 시트 만들기**: 학교 구글 계정으로 https://sheets.new → 이름 정하기 (예: "진자 실험")
2. **Apps Script 열기**: 시트 메뉴 `확장 프로그램` → `Apps Script`
3. **코드 붙여 넣기**: `Code.gs` 의 글을 모두 지우고, 저장소의 [`apps-script/Code.gs`](../apps-script/Code.gs) 내용을 붙여 넣은 뒤 저장
4. **웹 앱으로 배포**: `배포` → `새 배포` → 유형 `웹 앱`
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자** (학생이 로그인 없이 보내려면 꼭 이것)
   - `배포` → 액세스 승인 → 내 계정 → "고급" → "(안전하지 않음)으로 이동" → `허용` (내가 만든 코드라서 나오는 경고)
5. **웹 앱 URL 복사**: `https://script.google.com/macros/s/…/exec`
6. **주소 붙여 넣기**: 설정 화면(`pendulum-setup.html`) 3번 칸에 주소를 넣고 `연결 시험하고 저장` → "연결됨"
7. **우리 반 링크 받기**: 설정 화면에서 로그인한 채 "연결 시험하고 저장" → 나오는 링크·QR 을 학생 노트북에서 연다. 사이트 기본 시트로 쓰려면(링크 없이 열었을 때) [`js/pendulum-config.js`](../js/pendulum-config.js) 의 `appsScriptUrl` 에 주소를 넣는다(Claude 대화에 알려 주면 대신 넣음).

## 알아 두기

- 시트에 `measurements` 탭이 자동으로 생깁니다. 열: `timestamp, groupCode, L, amplitude, sensorAxis, nPeriods, T_mean, T_std, rawData, note` (명세서 4절) + `id, kind, source, T_sem, rate, device, measuredAt, rawInfo, rawData2~6`.
- 원본 센서 데이터는 글자 수를 줄여(정수로 바꾼 뒤 앞 값과의 차이를 36진수로) `rawData` 칸에 담고, 길면 `rawData2~6` 에 나눠 담습니다 (한 칸 45,000자). 그래도 넘치면 점을 고르게 줄이고 `rawInfo` 에 적습니다.
- 같은 측정을 폰에서 다시 보내면(계산 설정을 바꾼 뒤) 새 줄이 아니라 **같은 줄이 고쳐집니다**.
- 한 조에 측정은 200개까지 받습니다.
- 코드를 고치면 `배포` → `배포 관리` → 연필 → 버전 `새 버전` → `배포` 로 해야 적용됩니다 (주소는 그대로).
- 학교 인터넷에서 `script.google.com` 이 막혀 있으면 자동 연결이 안 됩니다. 그때는 폰에서 **CSV 저장** → 노트북 분석 화면에서 **CSV 불러오기**.
- 4단계(보고서·AI)에서 쓸 `reports`·`ai_logs`·`quiz` 탭 모양은 코드에 정해 두었고, Apps Script 편집기에서 `setupSheets` 를 한 번 실행하면 미리 만들어집니다 (안 해도 됨).
