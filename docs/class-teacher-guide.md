# 수업 연결 — 선생님 안내 (2026-11-18, Firebase 로 바꿈)

선생님은 **구글 로그인 한 번**, 학생은 **로그인 없이** 쓰는 수업 연결입니다. 교사 화면에서 수업을 만들면 조가 나뉘고, 학생은 QR 로 들어와 **조·번호**(이름 없음, 예 '3조 2번')를 고릅니다. 한 학생이 측정값을 보내면 같은 조 노트북과 선생님 화면에 **실시간**으로 공유되고, 선생님은 진행 상황을 보고 자료를 **CSV 로 내려받습니다**.

예전처럼 선생님 구글 시트(Apps Script)를 만들거나 업데이트할 필요가 없습니다. 자료는 사이트의 Firebase(Firestore, 프로젝트 `web-experiment-f9b24`)에 저장됩니다. 예전 시트에 있던 기록은 시트에 그대로 남아 있습니다.

## 교사 화면 모양 (2026-11-20)

- 로그인하면 바로 **📚 내 수업 목록**이에요(2026-11-20 바꿈, 예전 드롭다운 대신). 카드마다 실험(주제)·반·인원·수업 코드·📅 만든 날(요일·시각)·⏳ 진행 중 / ✅ 마침·단계 n / 전체. 최근 수업이 위, 마친 수업은 아래 '마친 수업' 접기. 맨 위 **➕ 새 수업 만들기**.
- 카드를 누르면 **큰 QR 화면**(학생 연결) → **다음 → 진행 보기**. 진행 화면에는 **오른쪽 위에 늘 QR**(폰 카메라로 찍을 만한 크기, 누르면 크게)이 떠 있어 늦게 온 학생도 바로 찍어요. 팀 결과판 크게 보기에도 QR 이 있어요. 폰 폭에서는 오른쪽 아래 작은 '📱 QR' 단추로.
- 주소에 수업이 담겨(`#class=…`) 새로고침해도 그 수업, 브라우저 뒤로 가기로 앞 화면.
- **🎬 발표 보기 (PPT 대신)**: 진행 화면의 **🎬 발표 보기 (학생 화면)** → 학생이 보는 실험 페이지가 크게 나와요(학생과 같은 단계까지만 열림). 프로젝터로 띄우고 설명하세요.
  - **→ · PageDown · Space** = 그 단계 안의 다음 작은 탭(이론·과정 등), **← · PageUp** = 이전. 발표용 리모컨(프레젠터)도 같은 키라 그대로 돼요. 이 화면에서 넘기는 탭은 **학생 폰에 영향이 없어요**.
  - 단계 끝에서 한 번 더 누르면 **'다음 단계를 열까요?'** → **Enter**(열기) / **Esc**(아니요). 열면 학생 폰과 발표 화면이 같이 넘어가요.
  - **⛶ 전체 화면**(Esc 로 나감), 오른쪽 위 QR·들어온 학생 수는 그대로 보여요. 발표 화면은 학생으로 참여하지 않아 '들어온 학생' 수가 늘지 않고, 카메라·센서도 켜지 않아요.
  - 필름통 로켓(행사)은 폰 모양 틀로 열린 단계의 첫 화면을 보여요.
- 수업이 끝나면 진행 화면의 **✅ 수업 마치기**(되돌릴 수 있음: '다시 진행 중으로'). 학생 자료는 그대로이고 목록에서만 아래로 내려가요.
- 수업 지우기(🗑)·코드 다시 열기(🔓)는 목록 카드 오른쪽에. 자료 내려받기·보고서 AI·계정은 **⚙ 설정** 안에 있어요.
- **학생에게 여는 단계**: 새 수업은 1단계(목적, 로켓은 '생각 열기')만 열린 채 시작해요. **▶ 다음 단계 열기**를 누르면 모든 학생 화면이 그 단계로 저절로 넘어가요. 먼저 끝낸 조도 다음 단계는 🔒 로 기다려요. **◀ 하나 되돌리기**, **모두 열기**도 있어요. 지난 단계는 학생이 다시 볼 수 있어요.
  - 잠그지 않는 것: 📱 폰 측정 화면(QR 로 연 측정용 폰), 수업 없이 연 실험 페이지, 이 기능 전에 만든 수업, 한 화면 실험(센서 값 보기)
- **📱 QR·수업 코드** 단추로 학생 연결 QR 을 다시 띄워요(🔍 QR 크게).

## 수업 시간에

1. 메인 페이지 → **교사로 시작** (`projects/class-teacher.html`) → **🔐 구글 계정으로 로그인** (이 계정이 수업 주인. 다른 컴퓨터에서 같은 계정으로 로그인하면 '내 수업'이 그대로 보여요)
2. ① 수업 만들기: 반·학생 수·조별 인원·실험 → 미리보기(예 26명·4명 → 4·4·4·4·4·3·3) → **수업 만들기**
   - 수업 코드(예 `2-4821`)와 QR 이 나옵니다. **🔍 QR 크게** 로 화면에 띄우세요
   - 학생은 QR 을 찍거나, 메인 페이지 → **학생으로 시작** 에서 수업 코드를 넣습니다 (**코드로 찾기는 만든 뒤 2일까지**, QR·주소는 학기 끝까지. 다시 코드로 들어오게 하려면 '내 수업'의 🔓 코드 다시 열기 = 지금부터 2일)
   - 각 조의 조 코드는 `반-조-같은 4자리`(예 `2-3-4821`)
3. 학생: 실험 페이지 맨 위 **🏫 수업 참여** 띠에서 조·번호를 고르고 **참여하기** → 조 코드가 채워지고 새 측정을 자동으로 받습니다
4. ② 진행 보기: 조별 카드에 조원마다 보고 있는 단계·잰 점 수·보냄 여부·마지막 활동. 학생이 움직이면 바로 바뀝니다. 5분 넘게 신호가 없으면 💤 쉬는 중. 학생을 누르면 자세히
5. **📥 자료 내려받기**: 수업 전체 또는 조 하나 → **CSV**(엑셀에서 바로 열림, 한글 안 깨짐, 한 줄 = 한 회차, 열 이름에 단위) 또는 **전체 자료(JSON, 원본 포함)**

## 학생 자료는 학기 끝에 저절로 지워져요

- 수업·제출·진행 기록에는 모두 **지워질 날(만든 날 + 183일)** 이 붙습니다. 교사 화면에 '이 수업의 학생 자료는 ○년 ○월 ○일에 지워져요' 가 나오니 그 전에 내려받아 두세요.
- 더 일찍 지우려면 '내 수업' 목록의 **🗑 지우기** (수업과 학생 자료를 모두 지움, 되돌릴 수 없음).
- 실제로 지우는 일은 Firestore 의 TTL 정책과 매일 도는 정리 작업(`.github/workflows/firestore-cleanup.yml`)이 합니다. 설정: `docs/DEPLOY.md`.

## 누가 무엇을 볼 수 있나 (firestore.rules)

| 누구 | 할 수 있는 것 |
|---|---|
| 학생(익명 로그인, 화면에 안 보임) | 링크·QR 의 수업 공간(추측하기 어려운 24자)에서 조 자료 읽고 쓰기, 진행 신호 보내기. 보고서 AI: 자기 기기의 질문·보고서만 읽고 쓰기(AI 답 칸은 못 씀, 최종 제출 뒤 못 고침) |
| 수업을 만든 선생님 | 그 수업의 진행·제출 모두 보기, 내려받기, 지우기. 보고서 AI 질문에 답 쓰기(답 칸만), 제출한 보고서 다시 열기 |
| 다른 선생님·사이트 관리자 | 남의 수업은 못 봄 |
| 수업 밖 사람 | 수업 목록을 훑을 수 없음 (공간 id 를 알아야 함). 수업 코드로 공간을 찾는 것도 찾기 기간(2일) 안에만 |

- 학생 이름·학번·이메일은 받지도 저장하지도 않습니다.
- 같은 수업 QR 을 가진 학생은 조를 스스로 고르므로 다른 조를 고르면 그 조 자료도 볼 수 있습니다(지금처럼).
- 수업 없이 **조 코드만 넣어** 노트북끼리 나누는 방법은 조 코드를 맞히면 남도 볼 수 있으니, 수업에서는 QR 을 쓰세요. 노트북 화면의 '📱 폰으로 측정해 보내기' QR 은 그 노트북·폰만 쓰는 공간을 따로 만들어 안전합니다.

## 🤖 보고서 AI 피드백 (2026-11-19)

7단계 보고서 실험(플랑크·이상기체·말루스·전자기 유도·자유낙하·진자 분석·퀀텀닷)의 **7. 결론** 단계에 **📝 보고서 쓰기 · AI 피드백** 칸이 있습니다. 학생은 항목(이론·방법·데이터 분석·결론 및 검토)마다 글을 쓰고, 묻고 싶은 것을 **프롬프트 칸**에 써야만 **🤖 AI에게 묻기**가 켜집니다. AI 는 대신 써 주지 않고 **피드백과 질문 2~3개**만 주며, **계산은 하지 않고** 페이지가 계산한 값만 인용하도록 정해져 있습니다(프롬프트는 `js/report-ai.js` 한 곳).

**어떻게 동작하나**: 요금제(Blaze)나 서버 없이 **선생님 개인 API 키**를 씁니다. 학생 질문은 Firestore 로 오고, **켜 둔 교사 화면이 선생님 키로 AI 를 불러** 답을 돌려줍니다. 키는 **선생님 브라우저에만** 있고 학생·사이트 저장소로 가지 않습니다. 그래서 **수업 중에는 교사 화면(탭)을 켜 두세요** — 꺼져 있으면 학생 화면에 '선생님 화면이 켜져 있어야 AI 답이 와요'가 나오고, 질문은 기다렸다가 켜지면 답이 갑니다.

1. **키 만들기** (한 번만, 쓴 만큼 요금. 무료 등급은 하루·분당 횟수가 적고 학생 글이 회사의 학습에 쓰일 수 있으니 약관을 확인하세요)
   - Gemini: [Google AI Studio](https://aistudio.google.com/app/apikey) → Create API key
   - Claude: [Anthropic 콘솔](https://console.anthropic.com/settings/keys) → Create Key (먼저 Billing 에서 충전)
   - GPT: [OpenAI 플랫폼](https://platform.openai.com/api-keys) → Create new secret key (먼저 Billing 에서 충전)
   - **키에 사용 한도(월 예산·알림)를 꼭 걸어 두세요.** 키가 새어도 피해가 한도 안에서 끝납니다
2. 교사 화면 → **③ 🤖 보고서 AI**: AI 회사 고르기 → 모델(기본값, 또는 🔑 키 시험 뒤 목록에서) → API 키 붙여 넣기 → **🔑 키 시험** (모델 목록을 받고 짧은 시험 질문 하나를 보냄)
   - 키는 기본으로 **이 탭에서만** 기억합니다(탭을 닫으면 잊음). '이 브라우저에 기억'을 켜면 다음에도 남습니다 — 교실 공용 컴퓨터에서는 켜지 마세요
   - '학생 질문에 AI 로 답하기 켜기'가 켜져 있고 이 화면이 열려 있는 동안, 내 수업(최근 12개)의 질문에 차례로 답합니다
3. **한도**: ① 수업 만들기의 **AI 질문 한도(조마다, 기본 20, 0 이면 끔)**. 넘으면 AI 를 부르지 않고 학생에게 '다 썼어요'라고 알립니다. 교사 화면은 부르기 전에 세 번 더 막아요: 이 수업에 없는 조 코드, 수업 전체 상한(조 한도 × 조 수), 한 기기가 조를 바꿔 가며 쓰기(기기마다 조 한도까지)
4. **보기·내려받기**: ③ 의 '조별 보고서 · AI 기록' → 조별 질문 수·보고서 제출 여부 → **보기**(보고서 글, 질문·함께 보낸 초안·계산 결과·AI 답·검증 메모, 외부 AI 기록), **📥 보고서 CSV · 📥 AI 기록 CSV · 전체(JSON)**. 최종 제출한 보고서는 학생이 못 고치고, 선생님이 **🔓 다시 열기**를 누르면 고칠 수 있습니다
5. 저장: 학생 보고서 글과 AI 기록(프롬프트·답·검증 메모)이 수업과 함께 저장되고 **6개월 뒤 저절로 지워집니다**(다른 자료와 같음). 보고서는 학생 기기마다 하나이고, 같은 조라도 다른 기기의 보고서·질문은 학생끼리 서로 못 봅니다
6. 키·한도 문제(키 틀림·충전 부족·분당 한도)로 답하지 못하면 학생 질문은 **그대로 기다리고**, 교사 화면에 오류가 나옵니다. 키를 고치면 이어서 답합니다

## 👨‍👩‍👧 가족 행사: 팀 이름으로 입장 (필름통 로켓, 2026-11-20)

1. ① 수업 만들기에서 실험 **🚀 발포비타민 필름통 로켓 (가족 행사)** 를 고르면 학생 수·조별 인원 대신 **팀 수(최대)** 와 **🧪 예비 실험 값**이 나와요.
   - 물의 양·발포비타민 양(¼ 알 단위)·물의 온도·조각 크기: 가족 화면의 +/− 와 고르기 범위, '기본'은 🔒 같게 할 값
   - 1차시 목표 시간·'맞췄다' 허용 오차(초)·같은 조건 반복 횟수(기본 3), 2차시 목표(아이 키의 %, 기본 100)·허용 오차(%)
2. QR 을 띄우면 가족이 팀마다 폰 1대로 찍고 **팀 이름(별명·가족 이름)** 을 정해 들어와요. 같은 이름은 안내가 나오고, 실명·학번은 받지 않아요.
3. ② 진행 보기에 **🏆 팀 결과판**(팀 점수·시간 도전 차이·최고 높이 %·높이 도전 차이)이 나와요. **🖥 크게 보기**로 프로젝터에 띄우세요.
   행사 중에 목표를 바꾸려면 결과판 아래 **예비 실험 값·목표 고치기** → 💾 (가족 화면은 도전 화면을 열 때 새 목표를 받아요).
4. 인터넷이 끊겨도 가족 폰에 저장되고, 연결되면 저절로 보내요. 영상과 아이 키(cm)는 폰에만 있어요.

## 무료 한도 (Firebase Spark)

하루 쓰기 2만 번, 읽기 5만 번까지 무료입니다. 30명 한 반 50분 수업에서 대략:
- 쓰기: 진행 신호(단계 바꿀 때 + 3분마다) 약 30명 × 30번 ≈ 900번 + 측정 보내기 수십~백 번 → **약 1,000번**
- 읽기: 교사 화면 실시간(신호 하나에 1번) ≈ 900번 + 학생 화면 실시간(같은 조 측정만) 수백 번 + 진행 신호 검사 900번 → **약 2,500번**

하루 5~6 반 수업이면 한도의 약 1/3 입니다.
