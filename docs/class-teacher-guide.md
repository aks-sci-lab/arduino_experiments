# 수업 연결 — 선생님 안내 (1단계, 2026-11-16)

교사·학생 모두 **구글 로그인 없이** 쓰는 수업 연결입니다. 선생님 구글 시트(Apps Script)에 수업을 만들면 조가 나뉘고, 학생은 QR 로 들어와 **조·번호**(이름 없음, 예 '3조 2번')를 고릅니다. 한 학생이 측정값을 보내면 같은 조 노트북과 선생님 시트에 자동으로 공유되고, 선생님은 진행 상황을 화면에서 봅니다. 지금은 **LED 플랑크 상수** 실험에서 씁니다.

## 처음 한 번: 시트 코드 4판으로 다시 배포

수업 연결은 Apps Script 코드 **4판** 이상이 필요합니다(진자·플랑크 조 공유와 같은 시트, 같은 코드).

1. https://aks-sci-lab.web.app/projects/pendulum-setup.html 에서 **📋 코드 복사**
2. 선생님 시트 → 확장 프로그램 → Apps Script → `Code.gs` 내용을 모두 지우고 붙여 넣기 → 저장
3. **배포 → 배포 관리 → ✏️(연필) → 버전: 새 버전 → 배포** (주소는 그대로)
4. 수업 연결 화면 ① 에서 연결 시험 → "✅ 연결됨 (4판)" 이 나오면 됩니다

시트가 아직 없다면 위 설정 화면의 1~5단계를 먼저 하세요.

## 수업 시간에

1. 메인 페이지 → **교사로 시작** (`projects/class-teacher.html`)
2. ① 시트 연결: 웹 앱 주소를 붙여 넣고 **연결 시험하고 기억하기** (이 브라우저가 기억, 다음부터는 건너뜀)
3. ② 수업 만들기: 반·학생 수·조별 인원 → 미리보기(예 26명·4명 → 4·4·4·4·4·3·3) → **수업 만들기**
   - 수업 코드(예 `2-4821`)와 QR 이 나옵니다. **🔍 QR 크게** 로 화면에 띄우세요
   - 학생은 QR 을 찍거나, 메인 페이지 → **학생으로 시작** 에서 수업 코드를 넣습니다 (코드만 넣는 방법은 학생 기기가 선생님 시트를 모를 수 있어 QR 을 권합니다)
   - 각 조의 조 코드는 `반-조-같은 4자리`(예 `2-3-4821`)라서 플랑크 페이지의 '👥 조 공유' 가 그대로 동작합니다
4. 학생: 실험 페이지 맨 위 **🏫 수업 참여** 띠에서 조·번호를 고르고 **참여하기** → 조 코드가 채워지고 자동 불러오기가 켜집니다
5. ③ 진행 보기: 10초마다 새로 봅니다. 조별 카드에 조원마다 보고 있는 단계·잰 점 수·보냄 여부·마지막 활동이 나오고, 5분 넘게 신호가 없으면 💤 쉬는 중으로 표시됩니다. 학생을 누르면 자세히 볼 수 있습니다.

## 교사 열쇠

- 수업을 만들 때 **교사 열쇠**(12자리)가 함께 만들어집니다. 진행 보기는 이 열쇠가 있어야 됩니다. 시트에는 열쇠의 해시(SHA-256)만 저장됩니다.
- 열쇠는 만든 브라우저에 저장됩니다. 다른 컴퓨터에서 보려면 ② 의 '🔑 교사 열쇠' 를 적어 두었다가 그 컴퓨터에서 '다른 기기에서 만든 수업 불러오기' 에 수업 코드와 함께 넣으세요. **학생에게 보여 주지 마세요.**
- 열쇠는 주소에 넣지 않고 보내는 내용(POST 본문)으로만 보냅니다.

## 시트에 생기는 탭

| 탭 | 내용 |
|---|---|
| `classes` | 수업 하나 = 한 줄 (수업 코드, 반, 학생 수, 조별 인원, 실험, 조 목록, 열쇠 해시) |
| `progress` | 학생 자리(수업·조·번호) 하나 = 한 줄 (보고 있는 단계, 잰 점 수, 보냄 여부, 마지막 신호 시각, 노트북 번호) |
| `planck` | (이미 있던 탭) 조가 보낸 LED 측정값 |

학생 이름·학번·이메일은 받지도 저장하지도 않습니다. 글자 값은 앞에 `'` 를 붙여 저장해 `2-4821` 같은 코드가 날짜로 바뀌지 않습니다.
