# 수업 연결 — 선생님 안내 (1단계, 2026-11-16)

교사·학생 모두 **구글 로그인 없이** 쓰는 수업 연결입니다. 선생님 구글 시트(Apps Script)에 수업을 만들면 조가 나뉘고, 학생은 QR 로 들어와 **조·번호**(이름 없음, 예 '3조 2번')를 고릅니다. 한 학생이 측정값을 보내면 같은 조 노트북과 선생님 시트에 자동으로 공유되고, 선생님은 진행 상황을 화면에서 봅니다. 지금은 **LED 플랑크 상수** 실험에서 씁니다.

## 처음 한 번: 시트 코드 5판으로 (손으로), 다음부터는 단추로

수업 연결은 Apps Script 코드 **4판** 이상, 단추로 스스로 업데이트하려면 **5판** 이상이 필요합니다(진자·플랑크 조 공유와 같은 시트, 같은 코드).

1. https://script.google.com/home/usersettings 에서 **Google Apps Script API** 를 사용으로 켜기 (한 번만)
2. 교사 화면 맨 위 '🛠 서버를 5판으로 바꿔 주세요' 의 **📋 Code.gs 복사** → 선생님 시트 → 확장 프로그램 → Apps Script → `Code.gs` 내용을 모두 지우고 붙여 넣기
3. ⚙ 프로젝트 설정 → **"appsscript.json" 매니페스트 파일을 편집기에 표시** 켜기 → **📋 appsscript.json 복사** → 편집기의 `appsscript.json` 에 붙여 넣기 → 저장
4. **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포** → 권한 확인 창에서 고급 → (안전하지 않음)으로 이동 → 허용 (주소는 그대로)
5. 교사 화면 ① 에서 연결 시험 → "✅ 연결됨 (5판)". 이때 이 시트의 **🔑 관리 열쇠**가 만들어져 이 브라우저에 저장됩니다

그 뒤로 사이트에 새 판이 올라오면 교사 화면에 **"🆕 새 서버 버전이 있어요 (5판 → 6판)"** 이 뜹니다. **🔄 업데이트** 를 누르면 시트의 스크립트가 사이트의 공식 코드를 받아(확인 값 SHA-256 비교) 스스로 바뀌고 같은 웹 앱 주소로 새 버전이 배포됩니다. 시트의 기록은 그대로이고, 문제가 있으면 **↩ 되돌리기**.

- 다른 컴퓨터에서 업데이트하려면 ① 시트 연결의 🔑 관리 열쇠를 적어 두었다가 업데이트 칸에 넣으세요. 잃어버리면 Apps Script 편집기 ⚙ 프로젝트 설정 → 스크립트 속성에서 `ADMIN_KEY_HASH` 를 지우고 다시 연결하면 새로 만들어집니다.
- 새 판이 **새 권한**(예: 다른 구글 서비스)을 필요로 하면 단추로는 바뀌지 않고 손으로 한 번 붙여 넣고 권한을 허용하라고 알려 줍니다.

## 수업 시간에

1. 메인 페이지 → **교사로 시작** (`projects/class-teacher.html`)
2. ① 시트 연결: 웹 앱 주소를 붙여 넣고 **연결 시험하고 기억하기** (이 브라우저가 기억, 다음부터는 건너뜀)
3. ② 수업 만들기: 반·학생 수·조별 인원 → 미리보기(예 26명·4명 → 4·4·4·4·4·3·3) → **수업 만들기**
   - 수업 코드(예 `2-4821`)와 QR 이 나옵니다. **🔍 QR 크게** 로 화면에 띄우세요
   - 학생은 QR 을 찍거나, 메인 페이지 → **학생으로 시작** 에서 수업 코드를 넣습니다 (코드만 넣는 방법은 학생 기기가 선생님 시트를 모를 수 있어 QR 을 권합니다)
   - 각 조의 조 코드는 `반-조-같은 4자리`(예 `2-3-4821`)라서 플랑크 페이지의 '👥 조 공유' 가 그대로 동작합니다
4. 학생: 실험 페이지 맨 위 **🏫 수업 참여** 띠에서 조·번호를 고르고 **참여하기** → 조 코드가 채워지고 자동 불러오기가 켜집니다
5. ③ 진행 보기: 10초마다 새로 봅니다. 조별 카드에 조원마다 보고 있는 단계·잰 점 수·보냄 여부·마지막 활동이 나오고, 5분 넘게 신호가 없으면 💤 쉬는 중으로 표시됩니다. 학생을 누르면 자세히 볼 수 있습니다.

## 교사 열쇠

- 수업을 만들 때 **교사 열쇠**(12자리)가 함께 만들어집니다. 진행 보기는 이 열쇠가 있어야 됩니다. 시트에는 열쇠의 해시(SHA-256)만 저장됩니다.
- 열쇠는 만든 브라우저에 저장됩니다. 다른 컴퓨터에서 보려면 ② 의 '🔑 교사 열쇠' 를 적어 두었다가 그 컴퓨터에서 '다른 기기에서 만든 수업 불러오기' 에 수업 코드와 함께 넣으세요. **학생에게 보여 주지 마세요.**
- 열쇠는 주소에 넣지 않고 보내는 내용(POST 본문)으로만 보냅니다.

## 시트에 생기는 탭

| 탭 | 내용 |
|---|---|
| `classes` | 수업 하나 = 한 줄 (수업 코드, 반, 학생 수, 조별 인원, 실험, 조 목록, 열쇠 해시) |
| `progress` | 학생 자리(수업·조·번호) 하나 = 한 줄 (보고 있는 단계, 잰 점 수, 보냄 여부, 마지막 신호 시각, 노트북 번호) |
| `planck` | (이미 있던 탭) 조가 보낸 LED 측정값 |

학생 이름·학번·이메일은 받지도 저장하지도 않습니다. 글자 값은 앞에 `'` 를 붙여 저장해 `2-4821` 같은 코드가 날짜로 바뀌지 않습니다.

## 다른 실험으로 수업 만들기 (6판)

② 수업 만들기의 **실험** 에서 모든 실험(진자, 이상기체, 말루스, … , 선생님이 만든 실험은 번호 넣기)을 고를 수 있습니다. 학생 QR 은 그 실험 페이지로 갑니다.
'(페이지 연결 준비 중)' 이 붙은 실험은 아직 그 페이지에 수업 참여 띠를 붙이는 중이라 학생 화면에 조·번호 고르기가 안 나올 수 있습니다(실험별로 차례로 붙임).
측정값은 선생님 시트의 `submissions` 탭(실험 이름 `exp` 칸으로 구분)에, 플랑크는 `planck` 탭, 진자는 `measurements` 탭에 쌓입니다. 서버가 5판이면 교사 화면에서 🔄 업데이트로 6판을 받으세요.
