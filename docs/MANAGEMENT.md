# 통합 관리 현황

이 문서는 **통합 관리 세션**(Claude Code 대화 "통합 관리 세션", 2026-11-03 지정)이 관리한다.
모든 세션(대화)과 GitHub 의 브랜치·PR 을 한곳에서 보고, 어느 쪽에도 짝이 없는 일을 놓치지 않기 위한 표다.

- **A. 세션 목록**: 지금 있는 대화와 각 대화가 맡은 일
- **B. 세션 없이 GitHub 에만 있는 것**: 맡은 대화가 없거나 끝난(보관된) 브랜치·PR
- **C. 정리해도 되는 브랜치**: 내용이 이미 `main` 에 다 들어간 브랜치

기준 시점: 2026-11-03. 열린 PR 5개(#33·#42·#49·#50·#51)는 사용자 지시("모든 PR 진행해")로 통합 관리 세션이 한 PR 에 모아 충돌을 풀고 머지했다.
머지·삭제는 사용자 승인 후에만 한다. 2026-11-11 부터 Claude Code 로만 작업한다. Claude Code 대화는 자기 브랜치 외에는 push·삭제 권한이 없으므로, 브랜치 삭제는 사용자가 GitHub 웹에서 한다 (`AGENTS.md` 역할 분담).

## A. 세션 목록 (통합 관리 세션의 하위 세션)

2026-11-04 사용자 지정으로 모든 세션을 **통합 관리 세션의 하위 세션**으로 분류했다.
세션의 "부모 세션"은 처음 만들 때 정해져 나중에 바꿀 수 없으므로, **태그**로 분류한다.

| 태그 | 뜻 |
|---|---|
| `통합관리` | 모든 하위 세션 공통 (목록에서 이 태그로 모아 보기) |
| `통합관리:본부` | 통합 관리 세션 (이 대화) |
| `통합관리:실험실` | 센서 기반 실험실(`sensor-lab`) 세션 |
| `통합관리:펌웨어` | 실험실 세션 중 센서 보드 펌웨어를 맡은 세션 (`통합관리:실험실` 과 함께 붙임) |
| `통합관리:교육과정` | 교육과정 관리 개발(별개 프로젝트) 세션 |
| `통합관리:그림도구` | 문항 그림 도구(`figure-maker`) 세션 |
| `통합관리:업무데스크` | 교사 업무 데스크(`teacher-desk`) 세션 |
| `통합관리:기타` | 위 저장소에 속하지 않는 세션 |

새 세션을 만들면 이 표의 태그를 붙이고 아래 목록에 한 줄 넣는다.

```
통합 관리 세션 (본부)
├─ 실험실 (sensor-lab)            ← 통합 관리 세션이 직접 관리
│   └─ 펌웨어 개발: 공용 센서 펌웨어   ← 통합 관리 세션이 만든 하위 세션
├─ 그림도구 (figure-maker)        ← 목록만 (그 저장소의 개발 세션이 작업)
├─ 업무데스크 (teacher-desk)      ← 목록만 (총괄 세션이 요청 배분·조율)
│   └─ 총괄: 업무 데스크
│       └─ 기능별 개발 세션들 · 머지 전용 세션
├─ 교육과정 (교육과정 관리 개발)   ← 목록만 (그 프로젝트의 개발 세션이 조율)
└─ 기타
```

## 관리 방법

- 새 대화를 만들거나 대화가 끝나면 A 표를 고친다.

- 대화 없이 남은 브랜치가 생기면 B 에 적는다.
