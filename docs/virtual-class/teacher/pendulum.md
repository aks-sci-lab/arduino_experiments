## 걸린 시간 (어림)

발표로 넘길 화면이 적음: 1~4 단계 모두 작은 탭 없이 한 장씩(글 181·366·105·308자) → 설명 10분이면 끝. 측정은 L 4가지 × (보정 3초 + 주기 10번 ≈ 20~25초 + 보내기) ≈ 15~20분. 1차시에 들어오지만 7 결론(질문 5개 + 보고서)은 다음 시간이나 과제로.

## 막힌 곳 · 헷갈린 곳 · 개선 제안

### 중

1. **4 과정 글이 수업 방식과 다르다** — "5. 데이터에서 반·조를 넣고 **조 코드를 만들어요**. 화면에 QR 코드가 떠요." 수업으로 들어오면 조 코드는 저절로 정해지고 5 데이터에는 '① 조 코드 만들기'가 없이 '② 측정할 폰으로 QR 찍기'부터 나옴(①이 빠진 ② ③ 번호). → 수업 중에는 '5. 데이터의 QR 을 폰으로 찍어요'로, 번호도 ①부터.
2. **매다는 법·흔드는 법 설명이 화면에 없다** — 3 준비물은 '튼튼한 줄 2개 (V자로 매달기)' 한 줄, 4 과정은 조 코드·QR·보내기 순서뿐. 폰을 어떻게 매달고(축 방향), 얼마나 당겨 놓는지(진폭), 주기를 몇 번 재는지는 발표 화면으로 보여 줄 그림이 없음(측정 화면 쪽에 있을 수 있음 — 학생 세션 확인). → 4 과정에 그림 1장.
3. **조별 g 를 모아 볼 화면이 없다** — 6 결과의 핵심(조마다 g 가 왜 다른가). 교사 조 카드 요약에 g·d 가 나오는지는 이번에 확인 못 함. → 플랑크의 '조별 결과' 같은 표(조 · 점 수 · g ± · d · 오차율) + 크게 보기.

### 하

4. 1 목적에 옛 안내가 남아 있음: "보고서 쓰기와 AI 피드백 칸은 **다음 업데이트에서** 이 단계들에 들어갈 예정이에요. 지금은 5. 데이터와 6. 결과를 써요." — 지금은 7 결론에 📝 보고서·AI 가 있음.
5. 발표 화면 제목이 '스마트폰 진자 – 분석 (노트북)', 맨 위 '« 메인 페이지로 돌아가기'(다른 실험은 '← 메인 페이지') — 모양이 조금 다름.

## 학생과의 상호작용

- 발표 화면 1~4 는 글이 짧고 물음이 0개(물음표 0). 교사가 말로 물어야 함 — 화면에 '줄이 길어지면 주기는? ( 길어진다 / 짧아진다 / 그대로 )' 한 줄이 있으면 손 들기로 바로 묻고 답할 수 있음.
- 5 데이터 발표 화면에는 QR·조 코드·빈 표가 나와 '이렇게 들어와요' 시범에 알맞음.
- 조별 결과를 함께 볼 화면이 없음(중 3). 반 전체 T²–L 점을 한 그래프에 겹치면 '어느 조가 직선에서 벗어났나'를 물을 수 있음.
- 말투는 '~해요/~예요'로 친근하고 짧음(다른 7단계 실험의 '~합니다/~한다'와 다름).

## 가설연역으로 만들었을 때 (이름·단계만)

- 수업 만들기에서 🔍 가설연역을 고를 수 있고, 교사 진행 화면·학생 탭 모두 ① 문제 인식 ~ ⑥ 결론 도출, 새 수업은 ① 만 열림, '모두 열기' 뒤 잠금 0(학생 화면은 ② 가설 설정으로 옮겨짐).
- 학생 화면: ① = 목적 + ✏️ 탐구 문제 · ② = 이론 + ✏️ 가설 · ③ = 준비물 + 과정 + ✏️ 탐구 설계 · ④ = 데이터 · ⑤ = 결과 · ⑥ = 결론 + ✏️ 결론·가설 판정. 맞음.
