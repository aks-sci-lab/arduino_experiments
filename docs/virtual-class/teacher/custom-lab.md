# 가상 수업 기록 (교사 역할) ⑩ 선생님이 만든 실험 (가설연역 6단계 · 7단계 방식)

- 돌린 날: 2026-11-20 · 기준: `main` 2aa3cd5 (PR #141·#144 머지 뒤)
- 방법: 교사 1920×1080(= 4K 배율 200 %), 조 노트북 1366×768. 다시 돌리기: `node tools/virtual-class/teacher-custom.cjs <그림 폴더>`
- **이 환경의 한계**: 진짜 Firebase 로그인이 안 되어 '➕ 새 실험 만들기'(만들기 화면 `?edit=new`)는 "인터넷에 연결할 수 없어 화면을 불러오지 못했습니다"로 열리지 않음. 그래서 **교사가 실험을 만드는 과정은 해 보지 못했고**, 실험 설정('옴의 법칙 확인', 번호 `ohm01`, 열 전압·전류, 비례 맞춤, 질문 1개, 이론·준비물·과정 글)을 학생 브라우저에 저장된 설정으로 넣어(기존 화면 시험과 같은 방법) 수업부터 진행함. 실험 제목·공개 여부를 Firestore 에서 읽는 부분도 이 환경에서는 실패함.

## 수업 시나리오 (중3~고1 24명 · 6조(노트북 1대) · 1차시 50분, 가설연역 방식 '옴의 법칙 확인')

| 분 | 교사가 하는 말·행동 (물음 → 힌트) | 학생(조) |
|---|---|---|
| 수업 전 | (실제) 메인 → 🔐 사이트 관리 → ➕ 새 실험 만들기: 제목·안내·열(전압, 전류)·맞춤(비례)·질문·'학생 화면 방식: 가설연역' → 공개 → 수업 만들기에서 '선생님이 만든 실험…' + **실험 번호** | – |
| 0~5 | 건전지 수를 늘리며 전구가 밝아지는 것을 보여 주고 **"무엇이 달라져서 밝아졌을까? 실험으로 답할 수 있는 질문으로 바꿔 보자"** | ① ✏️ 탐구 문제 쓰기 |
| 5~12 | **"전압을 2배로 하면 전류는?"** 힌트 1: 저항은 그대로 / 힌트 2: '만약 ~하면 ~할 것이다. 왜냐하면 ~' | ② ✏️ 가설 쓰기 |
| 12~20 | **"바꾸는 것·재는 것·같게 둘 것은?"** (저항을 바꾸지 않기) | ③ ✏️ 탐구 설계 쓰기 |
| 20~35 | 돌아다니며 회로 확인 | ④ 표에 전압·전류 넣기 → 📤 선생님께 보내기 |
| 35~42 | **"기울기는 무엇을 뜻하나? 점이 직선에서 벗어난 조는?"** | ⑤ 그래프·비례 맞춤(전류 = 1.03 × 전압, R² 0.9944) |
| 42~50 | 가설 판정 | ⑥ 지지/기각/판단하기 어려움 + 근거, 📝 보고서(AI), 제출 |

## 걸린 시간 (어림)

표 4~6줄이면 측정 15분. 쓰기 칸 4개(탐구 문제·가설·설계·판정) + 보고서까지 하면 1차시가 꽉 참. 교사가 단계를 열어 줄 수 없으므로(상 1) 시간 배분은 말로만.

## 막힌 곳 · 헷갈린 곳 · 개선 제안

### 상

1. **선생님이 만든 실험 수업에는 단계 열기도 🎬 발표 보기도 없다 — 학생 화면이 처음부터 모두 열려 있다**
   - 본 것: 진행 화면 윗줄이 '🔄 새로 보기 · 📱 QR 화면 · ✅ 수업 마치기'뿐, '학생 화면에서 지금 열린 단계' 카드 없음. 새로 만든 수업인데 학생 탭 ①~⑥(7단계 방식이면 1~7)에 🔒 가 하나도 없음. 학생은 가설(②)을 쓰기 전에 ⑤ 자료 해석·⑥ 결론을 먼저 볼 수 있음.
   - 왜 문제: 선생님 결정("학생의 다음 단계를 수업 연결(교사) 탭에서 활성화", "수업 진행하기에서는 학생의 화면이 보이도록")이 **선생님이 직접 만든 수업에는 빠져 있음**. 가설연역은 '가설 → 설계 → 수행' 순서가 생명인데 순서를 지킬 장치가 없음. 수업 원칙(인과관계에 맞춘 진행)과도 어긋남.
   - 제안: 실험 설정의 '학생 화면 방식'이 7단계·가설연역이면 다른 보고서 실험과 똑같이 단계 열기·발표 보기(한 화면 방식은 지금처럼 없음).

### 중

2. **수업을 만들 때 실험을 '번호'로 넣어야 한다** — '선생님이 만든 실험의 번호 (주소…)' 칸에 `aB3xY9…` 같은 글자를 붙여 넣어야 함. 교사는 메인 → 사이트 관리로 가서 번호(또는 학생 화면 주소)를 복사해 와야 함. → 로그인한 교사의 '내가 만든 실험' 목록에서 제목으로 고르기.
3. **수업 이름이 '선생님이 만든 실험 (ohm01)'** — 수업 목록·진행 화면·학생 띠에 제목('옴의 법칙 확인') 대신 번호가 보임. 같은 날 만든 실험 두 개를 수업 목록에서 구별하기 어려움. (이 환경에서는 Firestore 를 못 읽어 제목을 못 가져온 것일 수 있음 — **실제 확인 필요**. 보고서 AI 쪽은 PR #142 에서 제목을 쓰도록 고쳐짐.)
4. **학생 ① 화면에 '👤 학번·이름 (인쇄용, 선택)' 칸** — "인쇄·PDF 보고서에만 들어갑니다. 사이트 저장소로는 보내지 않습니다"라고 하지만, 수업으로 들어온 학생이 첫 화면에서 학번·이름 칸을 만남(이상기체 기록 '상 1'과 같은 종류). 바로 아래 보고서 칸에는 '🔒 이름·학번 같은 개인정보는 넣지 마세요'가 있어 서로 어긋나 보임. → 인쇄할 때만 묻기.
5. **수업 만들기에 진행 방법(7단계/가설연역)이 안 보인다** — 방식은 실험 설정에서 정해지므로 고르기가 없는 것은 맞지만, 이 수업이 어느 방식으로 열릴지 미리보기·수업 카드에 표시가 없음(다른 실험은 '🔍 가설연역' 표시). → 미리보기에 '이 실험은 🔍 가설연역 6단계로 열려요'.
6. **④ 탐구 수행 맨 위가 '👥 조 공유' 접기(반·조·🎲 새 조 코드 만들기·📥 불러오기…)이고 측정값 표는 그 아래(스크롤)** — 수업으로 들어온 조는 조 코드가 저절로 정해져 있는데 표보다 먼저 긴 설정이 나옴. ⑥ 에는 '📤 선생님께 보내기'가 두 번(조 공유 것 + 결론 것) + 보고서 '제출·인쇄'.

### 하

7. 학생 화면 첫 줄 "실험 설정을 새로 받지 못해 이 기기에 저장된 설정으로 엽니다. (인터넷 연결을 확인하세요)" — 이 환경 탓(Firestore 차단). 실제에서는 안 나올 것.
8. 공개 여부 안내 "ℹ️ 공개 여부를 확인하지 못했어요 (확인하지 못했어요 (Failed to fetch).)" — 같은 말이 두 번, 영어 오류가 그대로.
9. ⑤ 맞춤 결과 '전류 = 1.03 × 전압' — 단위(mA/V)가 없고, 가로·세로축을 학생이 바꿀 수 있어(전압↔전류) 기울기 뜻이 달라짐.

## 4K 프로젝터 (3840×2160)

발표 보기가 없어(상 1) 교사가 학생 페이지를 직접 띄우게 됨. 페이지는 다른 7단계 실험과 같은 틀(폭 860px·글자 16px)이라 `quantum-dot.md` 표의 '틀 안 글 폭·본문 글자'와 같은 비율: 배율 100 % 에서 화면 폭의 22 %·글자 0.7 %, 150 % 에서 34 %·1.1 %, 200 % 에서 45 %·1.5 %. 큰 QR·진행 화면은 로켓 기록의 표와 같음.

## 수업 원칙으로 본 화면 (인과관계 · 비계 · 과학적 사고력 · 변인 통제 · 문제 인식)

| 원칙 | 잘 된 곳 | 끊기는 곳 · 제안 |
|---|---|---|
| 인과관계 | 가설연역 방식이면 ① 문제 → ② 가설(이론 글 아래) → ③ 설계 → ④ 표 → ⑤ 그래프·맞춤 → ⑥ 판정이 원인 → 결과 순서 그대로 | 순서를 지킬 잠금이 없음(상 1). ② 에서 교사가 쓴 이론 글('옴의 법칙: V = IR')이 가설 쓰기 칸 **위**에 있어 답을 보고 가설을 씀 → 가설연역 방식에서는 이론 글을 가설을 쓴 뒤 펼치게(또는 만들기 화면에 '가설 전에 보여 줄 글 / 뒤에 보여 줄 글' 구분) |
| 비계 | 쓰기 칸마다 틀을 줌: 가설 '"만약 ~하면 ~할 것이다. 왜냐하면 ~" 꼴로', 판정 '지지 / 기각 / 판단하기 어려움 + 근거가 되는 데이터(숫자)', 보고서 AI 가 물음으로 답함 | 힌트 단계는 교사가 직접 넣을 방법이 없음(만들기 화면은 확인 못 함). 교사가 조별 가설·설계를 보려면 ⚙ 설정 → 보고서 AI → 조마다 '보기' |
| 변인 통제 | **③ 탐구 설계 쓰기 칸이 '바꾸는 것(독립 변인)·재는 것(종속 변인)·같게 할 것(통제 변인)과 실험 순서'를 직접 요구** — 본 실험 가운데 변인을 학생이 적게 하는 유일한 자리(가설연역 방식 공통) | 한 칸 자유 글이라 세 변인을 빠뜨려도 넘어감 → 세 칸으로 나누기. 표의 열(전압·전류)과 '바꾸는 것·재는 것'을 잇는 표시(가로축 = 바꾸는 것)가 있으면 ⑤ 그래프와 이어짐 |
| 문제 인식 | ① ✏️ 탐구 문제 쓰기 '관찰한 것·궁금한 점에서, 실험으로 답할 수 있는 질문 한 줄' | 그 위 '🎯 목적 · 실험 안내'에 교사가 '[목표] 전압과 전류의 관계를 알아본다'처럼 쓰면 곧 답이 됨 → 만들기 화면 안내에 '가설연역에서는 목적 대신 관찰 거리·현상을 쓰세요' |
| 과학적 사고 | 맞춤 결과에 R²·점 수, 판정에 근거 숫자 요구, '판단하기 어려움' 선택지 | 예측(가설)과 결과(기울기)를 나란히 보여 주지 않음 → ⑥ 에 '내 가설: … / 결과: 전류 = 1.03 × 전압' 두 줄 |

## 학생과의 상호작용

- **교사가 띄울 화면·모아 볼 화면이 없다**: 발표 보기 없음, 조별 가설·판정·기울기를 한 화면에 모아 보기 없음. 조 카드 요약('행 4, 기울기 1.03, R2 0.9944')은 좋지만 14px 작은 글씨로 조 카드 안에만. 6조의 기울기를 한 표로 띄우면 "왜 3조만 기울기가 다를까?"(저항이 달랐나?)를 물을 수 있음 → 플랑크 '조별 결과' 같은 표를 만든 실험에도(요약 숫자는 이미 옴).
- **물음**: 화면의 물음은 교사가 넣은 '생각해 볼 질문'(여기서는 1개)과 쓰기 칸 안내뿐 — 교사가 만들기 나름. 쓰기 칸 안내 말투('~쓰세요')는 중·고등학생에게 알맞음.
- **교사용이 섞인 곳**: ④ 위 조 공유 접기의 '🎲 새 조 코드 만들기', '학교 인터넷에서 보내기가 안 되면 …', 첫 화면의 학번·이름.
- **좋은 점**: 표에 값을 넣으면 그래프·맞춤이 바로 나오고, 보내면 교사 카드에 기울기·R² 가 뜸 → 교사가 돌아다니지 않고도 "2조 R² 가 낮네, 점 하나 다시 재 볼까?"라고 말을 걸 수 있음.

## 7단계 방식으로 만든 실험이면

- 같은 수업 주소로 설정만 7단계(`layout: 'steps'`)로 바꿔 열면 학생 탭이 1 목적 ~ 7 결론, 역시 잠금 없음. 7. 결론에 📝 보고서(7단계 항목), 단계 안 쓰기 칸(가설·설계·판정)은 없음(화면 시험으로 확인된 동작, 이번에는 탭만 봄).

## 잘 된 것

- 가설연역 쓰기 칸 네 개(탐구 문제·가설·탐구 설계·결론·가설 판정)가 보고서에 저장되어 ⚙ 설정 → 보고서 AI 조별 표에 '✏️ 쓰는 중'으로 보임.
- 표 붙여넣기 안내, 값 자동 저장, 📤 보내기 뒤 교사 카드 '📤 제출: 1개 (측정값 표) · 행 4, 기울기 1.03, R2 0.9944 · ④ 탐구 수행 · 점 4 · ✅'.

## 실제 기기 확인 필요

- **교사가 실험을 만드는 과정 전체**(구글 로그인 → 만들기 화면 → 공개 → 번호 찾기) — 이 환경에서 못 함. 통합 관리 세션이나 선생님이 실제 사이트에서 한 번 해 보는 것이 필요.
- 실제 Firestore 에서 수업 이름에 실험 제목이 나오는지, 비공개 실험으로 수업을 만들려 할 때 안내.
- 센서 기능(환경·전류·전압·버니어)을 넣은 만든 실험 수업.
