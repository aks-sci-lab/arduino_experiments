# 가상 수업 기록 (교사 역할) ⑤ 말루스 법칙 (폰 카메라 측정 · 노트북 분석)

- 돌린 날: 2026-11-20 · 기준: `main` 9a89865
- 방법: 교사 화면(메인 → 수업 진행 화면 → 로그인 → 새 수업 → 큰 QR → 진행 화면 → 🎬 발표 보기에서 리모컨 → 로 1~7 단계 끝까지 → 조 카드 → 같은 실험 가설연역 수업)을 `node tools/virtual-class/teacher-report.cjs malus <그림 폴더>` 로 진행하고 장면마다 화면을 찍어 읽음. 조 노트북 2대(1조·2조)가 참여해 단계가 열릴 때 따라오는지 봄. 단계별 화면 글은 실험 페이지를 열어 읽음.
- **이번에 하지 않은 것**: 폰 카메라로 각도별 밝기를 재서 회차를 보내는 일(가짜 카메라로도 이번에는 안 함) → 학생 세션 몫 또는 다음 차례. 그래서 '측정 자료가 들어온 뒤 교사 조 카드에 무엇이 보이는지'는 이 기록에 없음.
- 공통 문제(발표 글자 크기·잘림, 큰 QR 화면의 노트북용 주소, 보고서 AI 상태 표시, 조 카드가 한 화면에 안 들어옴 등)는 `quantum-dot.md`·`planck-led.md` 에 적었고 여기서는 **이 실험에서 다른 점**만 적음.

## 걸린 시간 (어림)

발표로 넘길 것: 2 이론 4탭 + 4 과정 3탭(각각 화면 2~2.5장 길이). 설명 35분 + 측정 35분(0~180° 15° 간격 13점 × 회차 2~3) + 분석 30분 → 2차시.

## 막힌 곳 · 헷갈린 곳 · 개선 제안

### 중

1. **4 과정의 예측·계획·판단 기준은 '학생이 직접 넣는 화면'인데 발표 보기에서는 길고(1429·1311·1186px) 입력 칸이 그대로 보인다** — 교사가 발표 화면에서 예측을 시범으로 넣으면 그 값이 어디에 남는지 안내가 없음(실제 확인 필요). → 발표용에서는 '예시로 넣어 보기(저장 안 됨)' 표시.
2. **7 결론에 내는 곳이 여럿** — '1. 결론 쓰기(주장·증거·추론)' + '📋 실험 기록 전체 복사' + '2. 📤 선생님께 보내기(조 공유)' + '📁 다른 내보내기(표 복사 · 내 구글 시트)' + 📝 보고서 쓰기·AI(최종 제출). 결론 글을 두 군데(1. 결론 쓰기 / 보고서 '결론 및 검토')에 쓰게 됨. → 한 곳으로.
3. **조별 예측·모델 판단을 모아 볼 화면이 없다** — 이 실험의 가장 좋은 토의 거리(조마다 고른 모델·R²·θ₀)가 교사 조 카드 요약에 어떻게 나오는지는 이번에 확인 못 함.

### 하

4. 학생 5 데이터의 안내 "사이트 저장소가 없거나 인터넷이 안 되면 … 이 기기가 노트북이 아니면 맨 위 '이 기기'를 바꾸세요" — 수업 중 학생에게는 긴 예외 안내(접기로).
5. 발표 화면 6 결과에 '데이터 모두 지우기' 단추가 보임(교사가 발표 화면에서 누를 일 없음).

## 4K 프로젝터 (3840×2160, 배율 100 · 150 · 200 %)

발표 보기 틀은 모든 7단계 실험이 같아 숫자도 `quantum-dot.md` 의 표와 같음: 본문 글자 = 화면 높이의 0.7 % / 1.1 % / 1.5 %(PPT 본문 ≈ 4.4 %), 글이 차지하는 폭 = 틀의 24 % / 37 % / 52 %. 발표 틀 높이는 약 2010 / 1290 / 930px 이므로 **이 실험에서 틀 아래로 잘리는 화면**(리모컨 → 로는 못 내림)은:

- 배율 100 %: 없음 · 150 %: 4 과정 ① 예측(1429px)·② 계획(1311px), 6 결과(1609px), 7 결론(1933px) · 200 %: 거기에 4 과정 ③(1186px)까지.

## 학생과의 상호작용

- **물음이 화면에 있는 드문 실험**: 4 과정 ① 예측('어떻게 변할까요?'), 6 결과 '어떤 모델이 맞을까?', 7 결론 '어떤 그래프와 값이 그 주장을 뒷받침하나요?'. 발표 보기로 띄워 놓고 손 들기·조별 답을 듣기에 알맞음.
- 다만 **조별 예측을 모아 띄울 수 없음** — "1조는 직선, 4조는 cos² 로 예측했네요"를 하려면 교사 화면에 조별 예측·고른 모델 표가 필요.
- 2 이론은 설명 글 4탭(물음표 0).
- 교사용이 섞인 곳: 7 결론의 '📁 다른 내보내기(내 구글 시트)', 5 데이터의 긴 예외 안내.

## 가설연역으로 만들었을 때 (이름·단계만)

- 수업 만들기에서 🔍 가설연역을 고를 수 있고, 교사 진행 화면·학생 탭 모두 ① 문제 인식 ~ ⑥ 결론 도출, 새 수업은 ① 만 열림, '모두 열기' 뒤 잠금 0(학생 화면은 ② 가설 설정으로 옮겨짐).
- 학생 화면: ① = 목적 + ✏️ 탐구 문제 · ② = 이론 + ✏️ 가설 · ③ = 준비물 + 과정 + ✏️ 탐구 설계 · ④ = 데이터 · ⑤ = 결과 · ⑥ = 결론 + ✏️ 결론·가설 판정. 맞음.
