# 수업 원칙 · 학생과의 상호작용 — 10개 수업 공통 정리 (가상 수업 교사)

선생님 원칙(2026-11-20): "수업은 인과관계에 맞춰서 학생에게 적절한 비계 설정(스캐폴딩)을 통해 과학적 사고력과 변인통제 능력을 길러주고 문제 인식능력을 향상시키는 것", "화면에 표시되는 내용이 학생과 상호작용하기 적절한지도 점검".
근거는 수업별 기록(`docs/virtual-class/teacher/*.md`)의 '수업 원칙으로 본 화면'·'학생과의 상호작용'. **본 범위가 수업마다 다름**(README 의 '한 범위'): ④~⑧ 은 발표 화면과 단계별 화면 글을 읽은 판단이고, 학생이 측정·분석하는 화면을 끝까지 조작해 본 것은 ①②⑨⑩ 뿐.

## 1. 실험별 표

○ = 화면이 그렇게 하도록 이끎 · △ = 일부만 / 교사가 말로 채워야 함 · ✕ = 화면에 없음 또는 거꾸로. 가설연역 방식으로 열면 달라지는 곳은 '(가설연역 △/○)'.

| 수업 | 인과관계 | 비계 | 변인 통제 | 문제 인식 | 과학적 사고 | 상호작용 |
|---|---|---|---|---|---|---|
| ① 필름통 로켓 | △ 조건 → 예측 → 측정 → 그래프 → '왜'가 이어지지만 단계가 열리면 끊김, 2차시는 발사 전에 '왜 솟나' 퀴즈 | △ 틀리면 한 번 더(10 → 5점)뿐, 힌트 없음. 교사는 어디서 막혔는지 못 봄 | ○ 하나를 고르면 나머지 🔒, 같은 조건 3번 | △ 처음 생각 고르기는 있으나 가족이 궁금한 것을 고르는 자리 없음 | ○ 예측(초) → 실제 → 차이, 처음 ↔ 마지막 생각 ✨ | △ 결과판은 점수·차이만(팀별 조건·열린 시간·예측 없음), 가족 화면 말투·글 양은 알맞음 |
| ② 탄소 양자점 | △ 1 목적·2 이론이 측정 전에 답('작을수록 파란 빛')을 말함 | △ 분석 질문 6개에 힌트 없음, AI 는 물음으로 답함 | ✕ 시료마다 여섯 값을 자유롭게 — 두 가지를 함께 바꿔도 알림 없음, 변인 적는 칸 없음 (가설연역 △ 자유 글) | ✕ 목적 읽기만 (가설연역 △ 칸 위에 답이 보임) | ○ 주장·증거·추론, '한계' 탭, 색 추정 ↔ 분광기 차이 | ✕ 발표 화면이 설명 글 6탭(물음 0), 반 전체 그래프·가설 모아 보기 없음 |
| ③ LED 플랑크 | △ 이론(eV₀ = hf)을 먼저 배운 뒤 확인 | △ 입력 순서를 이끌지만 튀는 LED 를 짚어 주지 않음 | △ 구조에 들어 있음(LED 색만 바꿈), 학생이 적지는 않음 | ✕ (가설연역 △) | ○ 직선 연장, 최소제곱, 오차 %, 기준 두 가지 비교 | △ 조별 h 표가 있으나 작고 크게 보기 없음, 학생 화면에는 다른 조 값 없음 |
| ④ 스마트폰 진자 | △ L → T² 직선 → g·d 는 좋으나 목적이 결론부터, 1~4 단계 글이 얇음 | △ '2개 이상 모이면 계산, 4개 이상이면 더 믿을 만' 정도 | △ L 만 표에 있고 진폭·매다는 법 같게 두기는 화면에 없음 | ✕ (가설연역 △) | ○ 'T 표준편차로 설명되는 크기인가', '어느 값이 근거인지' | ✕ 발표 화면 1~4 에 물음 0, 조별 g 모아 보기 없음 |
| ⑤ 말루스 | △ 예측 → 계획 → 측정 → 모델 비교는 가장 좋음, 다만 1 목적 첫 줄이 cos² 를 말함 | ○ 예측 그리기 → 계획표 → '이상한 값' 기준을 재기 전에 → ⚠·결측 사유 | △ 각도 계획·노출 고정은 있으나 '같게 둘 것'은 설정 접기 안 | △ 4-① 예측이 그 구실 | ○ 세 모델·잔차·결측 사유 | △ 화면에 물음이 있음(예측·'어떤 모델이 맞을까'), 조별 예측 모아 보기는 없음 |
| ⑥ 자유낙하 | △ 영상 → 점 → 포물선 → g 는 이어지나 목적이 방법·답 모양을 먼저 | △ 순서는 이끌지만 질문 17개가 한꺼번에 | △ 기준 길이·카메라 고정은 글로만, 공을 바꿔 보는 설계 칸 없음 | ✕ (가설연역 △) | ○ 상대 오차, 직선 ↔ 포물선, 간격 차이 | △ 7 결론 물음은 많음(너무 많음), 반 전체 g 없음, 합성 사진을 교사가 못 띄움 |
| ⑦ 이상기체 | ○ 실험 1(T 일정) → 실험 2(V 일정) → 종합, 1 목표에 가설 | ○ 가설 칸, 역할 나누기, 검토 질문이 볼 곳을 짚음 | ○ 실험 설계 자체가 변인 통제(학생이 적는 칸은 없음) | △ 가설은 쓰지만 문제는 주어짐 | ○ 직선 연장 절대 영도·표준오차, PV 변동 % | △ 물음은 화면에 있음, 조별 절대 영도 모아 보기 없음, 학번·이름 칸 |
| ⑧ 전자기 유도 | △ 선속 → 기전력 → 방향 → 넓이는 좋으나 목적이 법칙·식을 먼저 | △ 검증 탭·영점·자동 봉우리 표시, 질문 8개에 힌트 없음 | △ '바꿔 가며 저장·비교' 표는 있으나 한 가지만 바꾸게 하지는 않음 | ✕ (가설연역 △) | ○ '속도를 바꿔도 넓이가 같은 이유는?' | △ 파형 그래프는 좋은 물음 거리, 1~4 는 설명·표·코드 |
| ⑨ 숨 참기 탐구 | ○ 안정 → 숨 참기 → 회복이 한 곡선 | △ 안전 확인·카운트다운은 좋음, '왜 그럴까' 자리 없음 | △ 30/60초만 바꿈·쉬는 시간 안내, 같게 둔 것 적는 칸 없음 | ✕ 예측 고르기 없음 | ○ 신뢰도 낮은 구간 빼기, 멈춘 것도 자료, 손목 비교 | ✕ 발표 보기·단계 열기 없음, 반 전체(익명) 그래프 없음 |
| ⑨ 데이터 가공 실험실 | ○ 설정 하나 → 아래 단계·최종 값이 바로 바뀜 | ○ 전·후 그래프, '무엇을 골랐고 왜' (단, '배울 점'이 조작 전에 보임) | ○ 한 번에 설정 하나 | ○ 어긋난 값(37 ↔ 77)에서 시작 | ○ 원본도 요약, 기본 설정과 비교 | ✕ 수업으로 만들 수 없음 — 교사가 모아 볼 것이 없음 |
| ⑩ 선생님이 만든 실험 (가설연역) | △ 순서는 맞지만 잠금이 없어 ⑤ ⑥ 을 먼저 볼 수 있음, 이론 글이 가설 칸 위 | △ 쓰기 칸마다 틀('만약 ~하면'), 힌트는 교사가 넣을 길 없음 | ○ ③ 이 바꾸는 것·재는 것·같게 할 것을 직접 요구(자유 글 한 칸) | ○ ① 탐구 문제 칸(목적 글이 답이 될 수 있음) | ○ R²·점 수, 지지/기각/판단하기 어려움 + 근거 | ✕ 발표 보기·단계 열기 없음, 조별 기울기 모아 보기 없음 |

한눈에: **과학적 사고(근거로 주장·오차)는 거의 모든 실험이 ○**, **문제 인식과 변인 통제(학생이 스스로 정해 적기)가 가장 약함**, **상호작용(교사가 띄워 놓고 묻고·모아 보기)은 ○ 가 하나도 없음**. 인과관계는 대부분 △ — 까닭은 한 가지, '목적·이론이 답을 먼저 말한다'.

## 2. 모든 실험에 같은 틀로 넣을 수 있는 개선 후보

| # | 무엇을 | 어느 단계에 | 학생이 하게 되는 것 | 교사 화면에 생기는 것 | 지금 본보기 |
|---|---|---|---|---|---|
| A | **'먼저 보고 묻기' 한 장** — 현상 사진·짧은 관찰 거리 + "무엇이 다른가요? 왜일까요?" 고르기/한 줄. 목적 글(결론·법칙 이름)은 그 뒤에 펼침 | 1 목적 맨 위 (가설연역 ① 에서는 목적 글 대신 이것만 + ✏️ 탐구 문제) | 설명을 읽기 전에 스스로 물음을 만듦 | 발표 화면 첫 장이 '물음'이 됨 | 데이터 가공 실험실 첫 화면(37 ↔ 77), 로켓 '생각 열기' |
| B | **예측 한 번** — 방향·숫자를 고르기(커진다/작아진다/그대로, 또는 값) | 5 데이터 바로 앞(4 과정 끝) | 측정 전에 예측을 남기고, 6 결과·7 결론에서 '내 예측 ↔ 결과'가 나란히 보임 | 조별 예측 분포(예: 커진다 4조 · 그대로 2조)를 띄워 토의 | 로켓(예측 초 → '예측보다 9.1초 빨랐어요'), 말루스 4-① |
| C | **변인 카드** — 바꾸는 것 1개 · 재는 것 · 같게 둘 것을 고르거나 세 칸에 적기. 측정 때 두 가지가 함께 바뀌면 ⚠ | 4 과정(가설연역 ③ 탐구 설계 — 지금의 자유 글 한 칸을 세 칸으로) | 변인을 스스로 정하고, 지키지 않으면 화면이 알려 줌 | 조별 '바꾼 것'이 조 카드에 보임 | 로켓 '한 가지만 바꾸기 🔒', ⑩ 의 ③ 쓰기 칸 안내 |
| D | **힌트 사다리** — 분석 질문·퀴즈마다 '힌트 1(어디를 볼지) → 힌트 2(무엇과 무엇을 견줄지)' 접기, 연 횟수 기록 | 7 결론 분석 질문, 로켓 퀴즈 | 막혔을 때 답이 아니라 한 단계 도움을 받음(그다음이 AI) | 조별 '힌트 연 수·막힌 질문' → 교사가 그 조에 가서 물을 수 있음 | 이상기체 검토 질문(물음 안에 볼 곳이 들어 있음) |
| E | **반 전체 모아 보기 (크게)** — 조별 결과 요약(이미 교사에게 오는 숫자)을 표·점 그래프로, 프로젝터 크기로. 예측(B)·가설·변인(C)도 같은 자리에서 | 6 결과를 열 때 교사 진행 화면·발표 보기 | 다른 조와 견주어 "왜 우리만 다를까"를 따짐 | 한 조를 짚어 물을 근거 화면 | 플랑크 '조별 결과'(작음), 로켓 🏆 결과판(점수뿐) |

덧붙여 틀 차원에서 정리할 것(원칙이라기보다 화면 정돈):
- **'내는 곳'을 하나로** — 7 결론에 분석 질문(이 브라우저에만)·측정값 보내기·페이지 자체 결론 글(인쇄)·📝 보고서(제출)가 따로 있는 실험: 양자점, 말루스, 이상기체(가장 심함), 선생님이 만든 실험. '선생님께 내는 글 = 📝 보고서 하나, 측정값은 저절로'로.
- **발표 화면은 물음 먼저** — 이론 작은 탭마다 첫 줄에 물음 하나, → 를 누르면 설명(답)이 나오게(A 와 같은 생각을 탭마다).
- **교사용 글 빼기** — 함께 보는 화면의 긴 주소·'2일까지'·지워지는 날·CSV·조 코드 만들기(이번에 '접속 안내·교사용 글 정리'로 맡기신 것과 이어짐).

## 3. 실험마다 따로 고칠 것 (수업 원칙·상호작용 쪽만, 화면 버그는 수업별 기록에)

| 수업 | 따로 고칠 것 |
|---|---|
| ① 로켓 | 2차시 '왜 솟을까' 퀴즈를 발사 뒤로 / 결과판에 팀별 조건·열린 시간(반 전체 그래프) / 퀴즈 두 번 틀린 팀·측정 0 팀 표시 |
| ② 양자점 | 시료 정보에서 두 값이 함께 바뀌면 ⚠ / 가설연역 ② 에서 가설에 AI 피드백 / 가열을 이론 전에 시작할 수 있게(식히기 5분) |
| ③ 플랑크 | 조별 결과 크게 보기 + 튀는 LED ⚠ / 1 목적에 '빨강·파랑 LED 를 같은 전압에서' 관찰 |
| ④ 진자 | 1~4 단계 글 보강(매다는 법 그림, 진폭) / 표에 진폭 열 / 옛 안내 문장 지우기 |
| ⑤ 말루스 | 1 목적에서 cos² 식 빼기(4-① 예측 뒤로) / 조별 예측·고른 모델 표 |
| ⑥ 자유낙하 | 분석 질문 17개 → 필수 3~4 + 더 생각해 보기 / 실험 종류(자유낙하·2차원)를 수업 만들 때 정하기 / 공을 바꾸는 설계 |
| ⑦ 이상기체 | 보고서 두 벌 정리 / 실험 1·2 위에 '같게 둔 것' 칸 / 학번·이름 칸 |
| ⑧ 전자기 유도 | 저장할 때 '바꾼 것' 고르기 / 넓이 예측 / 2 이론을 작은 탭으로 |
| ⑨ 숨 참기 | 예측 고르기(빨라질까/느려질까) + '왜 그랬을까' 한 칸 / 익명 반 전체 그래프 / (원칙 밖: 동의 전 원본) |
| ⑨ 데이터 가공 | '배울 점'을 한 번 조작한 뒤 펼치기 / 수업으로 만들 수 있게(단계별 '무엇을 골랐고 왜' 모아 보기) |
| ⑩ 만든 실험 | 단계 잠금(가설 전에 결과를 못 보게) / 가설연역이면 이론 글을 가설 뒤에 / 탐구 설계 세 칸 / 조별 기울기 표 |

## 4. 학생 세션이 보내온 '막힌 곳'을 교사 화면에서 다시 본 것

**① 로켓** (학생 기록 `docs/virtual-class/student/film-rocket.md`)

| 학생 쪽에서 막힌 곳 | 교사 화면에서 알 수 있나 |
