## 여러 수업에 걸쳐 나온 것 (급한 순)

1. **단계가 열릴 때 하고 있던 학생·팀까지 옮겨진다**(로켓에서 측정이 사라짐) — 로켓 세션이 고치는 중.
2. **4K 프로젝터에서 모든 화면이 가운데에 작게 몰린다** — 발표 본문 글자가 화면 높이의 0.7 %(배율 100 %)~1.5 %(200 %), PPT 본문은 약 4.4 %. 발표 보기·결과판은 화면 높이 기준 글자가 필요. 글자를 키우면 '틀 아래 잘림 + 리모컨이 내리지 못함'을 함께 고쳐야 함.
3. **개인정보·동의**: 심박수 원본이 학생 동의 전에 교사 내려받기에 들어옴(⑨ 상 1) / 이상기체·선생님이 만든 실험의 '학번·이름' 칸(이 노트북에만 저장).
4. **교사 진행 화면이 알려 주지 않는 것**: 끝내고 기다리는 조 수, 와이파이 끊긴 팀, 보고서 AI 꺼짐·기다리는 질문·오류, 아무도 안 들어온 조.
5. **발표 보기·단계 열기가 없는 수업**: 심박수, 선생님이 만든 실험(데이터 가공 실험실은 수업 자체가 없음).
6. **조별 결과·예측·가설을 한 화면에 모아 띄워 토의할 화면**이 플랑크 말고는 없음(로켓 결과판은 점수뿐).
7. **수업 원칙**: 대부분 1 목적이 결론·법칙을 먼저 말함(현상 → "왜?" 순서가 아님), 7단계 방식에는 탐구 문제·변인을 학생이 적는 칸이 없음, 도움이 '물음 → 정답' 두 단계(힌트 없음). 잘 맞는 본보기: 말루스(예측 → 계획 → 판단 기준), 데이터 가공 실험실, 로켓의 '한 가지만 바꾸기'.
8. **조 노트북이 들어올 사이트 주소**가 큰 QR 화면에 크게 없음, 7 결론에 '보내기·제출'이 여러 개.
