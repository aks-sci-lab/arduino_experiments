- 돌린 날: 2026-11-20 · 기준: `main` 9a89865
- 방법: 교사 화면(메인 → 수업 진행 화면 → 로그인 → 새 수업 → 큰 QR → 진행 화면 → 🎬 발표 보기에서 리모컨 → 로 1~7 단계 끝까지 → 조 카드 → 같은 실험 가설연역 수업)을 `node tools/virtual-class/teacher-report.cjs idealgas <그림 폴더>` 로 진행하고 장면마다 화면을 찍어 읽음. 조 노트북 2대(1조·2조)가 참여해 단계가 열릴 때 따라오는지 봄. 단계별 화면 글은 실험 페이지를 열어 읽음.

- 공통 문제(발표 글자 크기·잘림, 큰 QR 화면의 노트북용 주소, 보고서 AI 상태 표시, 조 카드가 한 화면에 안 들어옴 등)는 `quantum-dot.md`·`planck-led.md` 에 적었고 여기서는 **이 실험에서 다른 점**만 적음.

## 걸린 시간 (어림)

발표로 넘길 것이 가장 많음: 2 이론 4탭 + 4 과정 4탭, 그리고 3 준비물(1052px)·5 데이터(1473px)·6 결과(1848px)·7 결론(2723px)이 모두 길다. 실험 2 는 데우고 식히는 데만 15~20분 → 2차시도 빠듯.

## 막힌 곳 · 헷갈린 곳 · 개선 제안

### 상

1. **7 결론·검토에 '인쇄할 보고서에 넣을 학번·이름' 칸이 있다** — "(이 노트북에만 저장)"이라고 적혀 있지만, 사이트 원칙('학생 이름·학번은 받지 않아요', 메인 화면 아래 글)과 화면이 어긋나 보이고, 교실 공용 노트북이면 다음 반 학생에게 남음. 발표 보기로 띄우면 그 칸이 그대로 보임. → 인쇄 직전에만 묻고 저장하지 않기, 또는 인쇄물에 손으로 쓰기.

### 중

2. **보고서가 두 벌** — 이 페이지의 '결론'·'검토(분석 질문)' 글쓰기 + '🖨️ 보고서 미리보기·인쇄'("보고서(쓴 글)는 보내지 않습니다")와, 그 아래 📝 보고서 쓰기·AI 피드백("선생님께 저장돼요", 최종 제출). 같은 결론을 어디에 써야 하는지, 어느 것이 제출인지 화면만으로 알 수 없음(양자점 중 12 와 같은 종류, 여기가 가장 심함 — 7 결론 길이 2723px).
3. **단계 이름이 다르다** — 학생 탭 '1 목표'·'7 결론·검토' ↔ 교사 진행 화면·발표 띠 '1 목적'·'7 결론'.
4. **5 데이터가 실험 1·실험 2 를 한 장에(1473px)** — 발표로 보여 줄 때 실험 2 는 스크롤해야 나옴. 작은 탭(실험 1 / 실험 2)으로.

### 하

5. 5 데이터 맨 위가 '👥 조 공유' 접기(반·조·🎲 새 조 코드 만들기) — 수업으로 들어온 조에는 필요 없는 칸이 측정보다 먼저 나옴.
6. 3 준비물 글자 14px, 1 목표 15px.

## 4K 프로젝터 (3840×2160, 배율 100 · 150 · 200 %)

발표 보기 틀은 모든 7단계 실험이 같아 숫자도 `quantum-dot.md` 의 표와 같음: 본문 글자 = 화면 높이의 0.7 % / 1.1 % / 1.5 %(PPT 본문 ≈ 4.4 %), 글이 차지하는 폭 = 틀의 24 % / 37 % / 52 %. 발표 틀 높이는 약 2010 / 1290 / 930px 이므로 **이 실험에서 틀 아래로 잘리는 화면**(리모컨 → 로는 못 내림)은:

- 배율 100 %: 7 결론·검토(2723px) · 150 %: 5 데이터(1473px), 6 결과(1848px), 7 · 200 %: 거기에 3 준비물(1052px), 4 과정 '준비'(1027px)까지. **4K 100 % 에서도 잘리는 유일한 실험**(7 결론).

## 학생과의 상호작용

- 1 목표의 가설 물음, 7 검토의 '~했는가?' 물음은 발표로 띄워 묻기에 알맞음. 2 이론은 설명 글.
- **조별 결과 모아 보기 없음**: 조마다 절대 영도 추정값(−273 과의 차이)을 한 표로 띄우면 가장 좋은 토의 재료. 교사 조 카드 요약에 나오는지 이번에 확인 못 함.
- 교사용·개발용이 섞인 곳: 5 데이터 '이 브라우저는 블루투스 연결을 지원하지 않습니다 (Android·PC 의 Chrome·Edge, https 필요)', 조 공유 접기의 '🎲 새 조 코드 만들기'.
- 학번·이름 칸(상 1)은 함께 보는 화면에 나오면 안 되는 것.

## 가설연역으로 만들었을 때 (이름·단계만)

- 수업 만들기에서 🔍 가설연역을 고를 수 있고, 교사 진행 화면·학생 탭 모두 ① 문제 인식 ~ ⑥ 결론 도출, 새 수업은 ① 만 열림, '모두 열기' 뒤 잠금 0(학생 화면은 ② 가설 설정으로 옮겨짐).
- 학생 화면: ① = 목적 + ✏️ 탐구 문제 · ② = 이론 + ✏️ 가설 · ③ = 준비물 + 과정 + ✏️ 탐구 설계 · ④ = 데이터 · ⑤ = 결과 · ⑥ = 결론 + ✏️ 결론·가설 판정. 맞음.
