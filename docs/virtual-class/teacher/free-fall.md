## 막힌 곳 · 헷갈린 곳 · 개선 제안

### 중

1. **1 목적에서 학생이 '할 실험'(자유낙하 / 2차원 운동)을 고른다** — "먼저 할 실험을 고르세요. 고른 실험은 이 브라우저에 기억됩니다." 교사가 수업을 만들 때 정할 수 없고, 조마다 다른 것을 고르면 5 데이터·6 결과 화면이 달라짐. 발표 화면도 교사가 직접 눌러 맞춰야 함. → 수업 만들기에서 실험 종류를 정하고 학생 화면은 그것으로 고정(수업 없이 열 때만 고르기).
2. **7 결론 분석 질문이 너무 많다** — 한 화면에 물음표 17개(다른 실험은 4~8개). 무엇이 꼭 답할 것인지 구별이 없음. → 필수 3~4개 + '더 생각해 보기' 접기.
3. **4 과정이 한 장으로 길다(1095px)** — 다른 실험처럼 작은 탭(① 촬영 / ② 영상 올리기 / ③ 점 찍기 …)으로 나뉘어 있지 않아 리모컨으로 못 넘김(공통 잘림 문제가 여기서는 탭도 없음).

### 하

4. 3 준비물 표 글자 13px(다른 단계 16px).
5. 학생 6 결과가 비었을 때 "5. 데이터에서 점을 찍고 '✓ 합성 실행'을 누르세요" — 노트북은 분석만 하므로 '폰에서 보낸 회차가 들어오면 여기에 나와요'가 맞음.

## 학생과의 상호작용

- 발표 화면 1~4 는 '~한다' 체의 설명·순서 글(물음표 0). 7 결론은 물음이 많아 **발표 화면에 띄워 놓고 조별로 답하게 하기에는 좋음**(다만 한 화면에 17개).
- 6 결과의 '조 결과 모아 보기'(같은 조 기기끼리)·g 평균은 조 안에서만. **반 전체 g 분포**는 교사 화면에 없음.
- 다중섬광사진(합성 그림)은 학생에게 보여 주기 가장 좋은 결과물인데 폰·조 노트북에만 있고 교사가 띄울 수 없음(영상·그림은 보내지 않음).

## 가설연역으로 만들었을 때 (이름·단계만)

- 수업 만들기에서 🔍 가설연역을 고를 수 있고, 교사 진행 화면·학생 탭 모두 ① 문제 인식 ~ ⑥ 결론 도출, 새 수업은 ① 만 열림, '모두 열기' 뒤 잠금 0(학생 화면은 ② 가설 설정으로 옮겨짐).
- 학생 화면: ① = 목적 + ✏️ 탐구 문제 · ② = 이론 + ✏️ 가설 · ③ = 준비물 + 과정 + ✏️ 탐구 설계 · ④ = 데이터 · ⑤ = 결과 · ⑥ = 결론 + ✏️ 결론·가설 판정. 맞음.
