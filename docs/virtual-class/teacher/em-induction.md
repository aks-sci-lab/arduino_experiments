# 가상 수업 기록 (교사 역할) ⑧ 전자기 유도 전압·전류 측정 (아두이노 USB)

- 돌린 날: 2026-11-20 · 기준: `main` 9a89865
- 방법: 교사 화면(메인 → 수업 진행 화면 → 로그인 → 새 수업 → 큰 QR → 진행 화면 → 🎬 발표 보기에서 리모컨 → 로 1~7 단계 끝까지 → 조 카드 → 같은 실험 가설연역 수업)을 `node tools/virtual-class/teacher-report.cjs eminduction <그림 폴더>` 로 진행하고 장면마다 화면을 찍어 읽음. 조 노트북 2대(1조·2조)가 참여해 단계가 열릴 때 따라오는지 봄. 단계별 화면 글은 실험 페이지를 열어 읽음.
- **이번에 하지 않은 것**: 아두이노(USB 시리얼) 측정 — 🧪 시뮬레이션으로 측정을 저장·보내는 일도 이번에는 안 함 → 학생 세션 몫 또는 다음 차례. 그래서 '측정 자료가 들어온 뒤 교사 조 카드에 무엇이 보이는지'는 이 기록에 없음.
- 공통 문제(발표 글자 크기·잘림, 큰 QR 화면의 노트북용 주소, 보고서 AI 상태 표시, 조 카드가 한 화면에 안 들어옴 등)는 `quantum-dot.md`·`planck-led.md` 에 적었고 여기서는 **이 실험에서 다른 점**만 적음.

## 걸린 시간 (어림)

회로·스케치 올리기(아두이노 IDE)가 수업 시간의 가장 큰 변수 — 미리 올려 둔 보드를 나눠 주지 않으면 4 과정에서 20분 이상. 측정 자체는 한 번에 몇 초.

## 막힌 곳 · 헷갈린 곳 · 개선 제안

### 중

1. **2 이론이 작은 탭 없이 한 장(955px), 5 데이터도 한 장(1071px)** — 자기 선속·패러데이·렌츠가 한 화면에 이어져 리모컨으로 나눠 넘길 수 없음. → 다른 실험처럼 작은 탭으로.
2. **4 과정 '스케치' 탭(아두이노 코드 올리기)은 수업 중 학생이 할 일인지 교사 준비인지 구별이 없음** — 발표로 띄우면 코드·IDE 설명이 학생에게 그대로. → '선생님 준비(미리)' 표시 또는 접기.
3. **센서가 없을 때 '🧪 시뮬레이션'으로 저장한 측정도 선생님께 보낼 수 있는지·교사 화면에서 구별되는지** 확인 못 함(학생 세션에 부탁).

### 하

4. 7 결론에 "속도·높이·N 을 바꾼 측정을 각각 저장해 6. 결과 표에서 비교했다." 같은 점검 목록 — 좋은 내용이지만 보고서 칸·분석 질문·점검 목록이 한 화면에 이어져 김(1795px).
5. 3 준비물 '(휴대폰에서는 시뮬레이션만 가능)' — 이 실험은 노트북 측정이라 폰 안내는 예외로.

## 4K 프로젝터 (3840×2160, 배율 100 · 150 · 200 %)

발표 보기 틀은 모든 7단계 실험이 같아 숫자도 `quantum-dot.md` 의 표와 같음: 본문 글자 = 화면 높이의 0.7 % / 1.1 % / 1.5 %(PPT 본문 ≈ 4.4 %), 글이 차지하는 폭 = 틀의 24 % / 37 % / 52 %. 발표 틀 높이는 약 2010 / 1290 / 930px 이므로 **이 실험에서 틀 아래로 잘리는 화면**(리모컨 → 로는 못 내림)은:

- 배율 100 %: 없음 · 150 %: 7 결론(1795px) · 200 %: 2 이론(955px), 5 데이터(1071px), 7 결론. (4 과정 '회로' 925px 는 200 % 에서 경계)

## 수업 원칙으로 본 화면 (인과관계 · 비계 · 과학적 사고력 · 변인 통제 · 문제 인식)

| 원칙 | 잘 된 곳 | 끊기는 곳 · 제안 |
|---|---|---|
| 인과관계 | 선속 변화 → 기전력(패러데이) → 방향(렌츠) → 넓이 = 선속 변화량, 측정도 '들어갈 때 +, 나올 때 −' 봉우리로 바로 보임 | 1 목적이 법칙 이름과 식(ε = −N·dΦ/dt), '부호가 반대인 것으로 렌츠 법칙을 확인'까지 먼저 말함 → 자석을 넣었다 빼는 파형을 먼저 보고 '왜 두 봉우리의 부호가 다를까?'부터 |
| 비계 | 검증·측정 탭(건전지로 먼저 확인), 영점 보정, 6 결과가 봉우리·넓이를 자동으로 표시, 저장한 측정 비교 표 | 분석 질문 8개에 힌트 없음. 교사가 조별 측정 수·무엇을 바꿨는지 볼 화면(조 카드 요약: 최대 ε·∫ε dt·N)은 이번에 확인 못 함 |
| 변인 통제 | **'속도, 감은 수 등을 바꿔가며 저장하고 비교'**, 저장 때 이름과 N 을 적음 — 비교 표가 변인별 비교를 도움 | 한 번에 한 가지만 바꾸도록 화면이 막거나 알려 주지는 않음(이름을 자유롭게 적음). 저장할 때 '바꾼 것: 속도 / 높이 / N' 고르기 + 나머지는 '앞 측정과 같게' 확인 |
| 문제 인식 | (가설연역 ① ✏️ 탐구 문제) | 7단계에는 없음 |
| 과학적 사고 | '속도를 바꿔도 ∫ε dt 와 ΔΦ 가 거의 같게 나온 이유는?' — 예상과 다른 결과를 설명하게 하는 좋은 물음, 들어갈 때·나올 때 넓이 비교 | 측정 전에 '빨리 넣으면 넓이는 ( 커진다 / 같다 / 작아진다 )' 예측을 남기면 이 물음이 더 살아남 |

## 학생과의 상호작용

- 6 결과의 '마지막 측정 그래프'(전압·전류 파형, 봉우리 ●, 넓이 색칠)는 교사가 한 조를 짚어 "왜 두 번째 봉우리가 더 클까?"를 묻기 좋은 화면. 발표 보기에서 🧪 시뮬레이션으로 파형을 띄울 수 있으면 물음 → 예측 → 확인이 됨(발표용에서 측정·시뮬레이션이 켜지는지 실제 확인 필요).
- 1~4 는 설명·표·코드(물음표 0). 4 과정 '회로' 표(연결점·ADS1115·의미)는 프로젝터 글자 크기에서 읽기 어려움.
- 조별 저장 측정을 반 전체로 모아 보는 화면 없음.

## 가설연역으로 만들었을 때 (이름·단계만)

- 수업 만들기에서 🔍 가설연역을 고를 수 있고, 교사 진행 화면·학생 탭 모두 ① 문제 인식 ~ ⑥ 결론 도출, 새 수업은 ① 만 열림, '모두 열기' 뒤 잠금 0(학생 화면은 ② 가설 설정으로 옮겨짐).
- 학생 화면: ① = 목적 + ✏️ 탐구 문제 · ② = 이론 + ✏️ 가설 · ③ = 준비물 + 과정 + ✏️ 탐구 설계 · ④ = 데이터 · ⑤ = 결과 · ⑥ = 결론 + ✏️ 결론·가설 판정. 맞음.
