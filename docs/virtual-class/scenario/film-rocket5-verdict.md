## 4. 의견

- 이번 변경의 목표(21장 · 90분 · 🛠 · 계획 🔮 폰 응답 · 측정 장 안 그림 · 학생 화면 단독 없음)는 **거의 다 됐다**. 4차 '상' 셋(폰 도전, 2차시 정리 칸, 새로고침 되돌아감)도 풀렸다.
- 남은 큰 것은 **원칙 쪽**: 팀끼리 숫자를 견주는 말이 4차에 이어 0, 프로젝터 결과판이 점수 순위를 띄운다. 답 모음은 바꿀 것별로 묶였지만, 교사 대본이 팀 **안** 까닭만 물었다. 다음에는 "물의 양을 바꾼 두 팀의 예측이 달라요" 같은 **팀 사이 물음**을 대본에 넣고, 결과판은 순위 대신 '바꾼 것 → 숫자'만 보이는 쪽이 좋다.
- 시간 #1 은 시간표 분 판정이라 낙관이다. 실제 🛠 12분 · 2차시 11분은 실제 기기에서만 알 수 있다.
- #13·#10 은 도우미가 누른 결과라 '사람이 헷갈렸을지'는 약하게만 말해 준다.
