## 3. 교사 대본

**5차 `film-rocket5.md` 3장 대본을 그대로 쓴다.** 6차에서 더하는 것만 적는다.

- 교사는 **📋 진행 상황을 차례마다 한 번 연다**(스크린샷 b). '챙길 팀'에 누가 보이는지를 기록하고, 보이는 팀에만 말로 돕는다(한 번에 한 마디, 정답 먼저 말하지 않기).
- 늦게 온 E(30분): 교사는 "번개팀 어서 와요! 폰이 알려 주는 대로 먼저 계획을 정하고 재요"라고 한 마디만 한다.
- 끊긴 F: 📋 에 보이면 "하늘 팀, 와이파이가 다시 되면 저절로 보내져요"라고 한다. 보이지 않으면 말하지 않는다(그것이 지표다).
- D ② 한 번(30분대): 📋 에 보이거나 D 가 결과판에 한 번만 잰 것으로 보이면 "티격태격 팀, 같은 조건으로 몇 번 쟀어요?"라고 한다.
- C 만들기(56분): 📋 '만들기 미완'이 보이면 "할머니 팀, 다 만들면 폰이 지금 문제로 데려가요"라고 한다.
- ⑩·⑯·⑳ 에서 **팀 사이 물음** 한 번씩: "같은 것을 바꾼 두 팀의 숫자를 보면 어때요?"(선생님용 글에 다른 말이 있으면 그 말).

### 5-4. 스크린샷 (판정 지표가 아니라 기록의 완결성)

- 차례는 18 ↔ 18 이다(5차 16차례에 ⑨·⑰ 측정 중 교사 차례 T07b·T12b 를 더함 — 문제 인식 물음·📋 확인).
- 교사: 차례마다 **a 프로젝터**(배율 150 %)와 **b 📋 진행 상황**. 18차례 × 2 = 36장 안팎이다. 장이 바뀌거나 결과판을 띄우는 등 중요한 장면은 더 찍는다.
- 학생: 차례마다 **여섯 폰 전부**. 18차례 × 6 = 108장 안팎이다. 흔들리는 장면(뒤로 가기·끊김·지우기 등)은 그 순간 그 폰을 한 장 더 찍는다.
- 판정에 쓸 장면이 빠졌으면 그 지표를 '판정 못 함'으로 둔다.

## 6. 진행 방법 — 차례 묶음은 파일로 (이번에 바뀜)

5차에서는 묶음 JSON 을 메시지 본문에 붙였다. 그러다 잘리거나 손으로 옮기다 틀려, 교사 세션이 다시 만들어 넣어야 했다. **이번에는 기록 브랜치에 파일로 push 하고 메시지에는 경로만 적는다.**

| | 교사 | 학생 |
|---|---|---|
| 기록 브랜치 | `claude/virtual-class-teacher-rocket6` (`origin/claude/virtual-class-teacher-rocket5` 에서) | `claude/virtual-class-student-rocket6` (`origin/claude/virtual-class-student-rocket5` 에서) |
| 기록 worktree | `/tmp/rec6` | `/tmp/rec6` |
| 묶음 파일 | `docs/virtual-class/turns/film-rocket6/T<NN>.json` | `docs/virtual-class/turns/film-rocket6/S<NN>.json` |
| 스크린샷 | `docs/virtual-class/screens/film-rocket6/teacher/NN-a-설명.jpg`·`NN-b-진행상황.jpg` | `docs/virtual-class/screens/film-rocket6/student/NN-팀-설명.jpg` |

내 차례 끝 — 보내는 쪽:

```bash
# 걸음: return S.out('T03 메모')  → 돌려준 file 을 묶음 이름으로 복사
cp /tmp/vc-rocket6/out-teacher-3.json /tmp/rec6/docs/virtual-class/turns/film-rocket6/T03.json
cd /tmp/rec6 && git add docs/virtual-class/turns docs/virtual-class/screens && git commit -qm "6차 T03" && git push -q origin HEAD:claude/virtual-class-teacher-rocket6 && git rev-parse --short HEAD
```

메시지 본문은 사람 말 요약(교사가 한 말·띄운 장·기다림, 또는 팀마다 한 일), 묶음 경로, 커밋 번호 한 줄만 적는다.

받는 쪽:

```bash
git -C /home/user/arduino_experiments fetch -q origin claude/virtual-class-teacher-rocket6
git -C /home/user/arduino_experiments show origin/claude/virtual-class-teacher-rocket6:docs/virtual-class/turns/film-rocket6/T03.json > /tmp/vc-rocket6/in-T03.json
# 걸음: return S.in('/tmp/vc-rocket6/in-T03.json')
```

- 묶음 파일은 손대지 않는다. 기록 PR 에 함께 남긴다(다시 돌릴 때 씀).
- 스크린샷 용량: 교사 한 장 약 200 KB, 폰 한 장 약 25 KB(JPEG 70 으로 잼). 모두 합쳐 약 10 MB 다. PNG 대신 JPEG(.jpg)를 쓴다(통합 관리 세션의 '가능하면 JPEG').
- `tools/virtual-class/` 는 커밋하지 않는다.

## 7. 수업 전에 본 것 (이 세션이 도구로 확인함)

- 도우미 확인: 폰 배율 1 로 열면 화면 폭 390·배율 1이다. 교사 150 % 스크린샷은 192 KB, 폰은 25 KB(JPEG 70)다. `R.mash`·`R.reload`·`R.forward` 는 동작한다.
- 브라우저 **뒤로 가기**는 사이트를 떠난다(가상 폰은 그 앞 페이지가 빈 페이지다). 사람처럼 '앞으로 가기' 또는 QR 다시 찍기(수업 주소 다시 열기)로 돌아온다. 둘 다 같은 팀으로 이어지는 것을 확인했다. 이 수업에서는 **QR 다시 찍기**로 한다.
- `R.mash` 는 '지우기'·'처음부터'·'저장'·'공유'·외부 링크를 누르지 않는다. D 가 결과를 지우는 장면은 학생 지시문에 따로 적었다(확인창은 도구가 '예'로 받음 = 엄마가 확인을 누름).
- 고친 판 커밋이 오면 이 세션이 smoke 를 한 번 더 돌린다.

### 7-1. 수업 중 알게 된 것 (2026-11-28, 통합 관리 세션 알림 — 판정 때 반영)

- 학생 서버가 S07a(31분)에서 **도구 사고**로 꺼져 폰 기억(localStorage)이 사라졌다. 통합 관리 세션이 예전 uid 를 다시 넣어 S07b 부터 이어 갔다. 그 앞뒤 장면은 도구 탓으로 보고 F1(떨어져 나간 시간)에 넣지 않는다.
