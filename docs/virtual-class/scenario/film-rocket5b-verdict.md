## 2. 로켓 세션이 물은 것 — '만들기를 끝내지 않은 팀은 그동안 다음 응답 장에 답하지 못함(다 만들면 지금 장으로)'

**적절하다 (그대로 두기 추천).** C 는 만들기 화면에 머물렀고, 다 만든 뒤 바로 지금 장의 퀴즈로 갔다. 교사는 📋 '챙길 팀'에서 C 를 볼 수 있었다. 이번에는 다 만든 뒤 쌓인 퀴즈가 둘(작용 반작용·질량)이라 부담이 작았다. 가족은 "퀴즈는?" 하고 한 번 물었다. 만들기 화면 위에 "다 만들면 지금 문제로 가요" 한 줄을 두면 이 물음이 줄겠다(하 4).

## 4. 의견

- 5차의 상·중 묶음은 이번 판에서 대부분 풀렸다. 행사(12-12) 전에 남은 중요한 것은 **중 1(놓친 퀴즈가 사라짐)** 과 **중 3(숫자와 반대 결과)** 둘이다. 둘 다 작은 고침으로 보인다. 중 4 는 원칙(상호작용) 쪽이다. 대본과 장 한 장으로 다룰 수 있어 행사 뒤로 미뤄도 수업은 된다.
- K4·K7·K10 은 기능 문제가 아니라 '못 본 장면' 때문에 절반·판정 못 함이 됐다. 학생 기록이 오면 K10 을 다시 보고, 그 밖의 이유로 다시 수업할 필요는 없다고 본다.
- 머지 판단은 통합 관리 세션과 선생님 몫이다. 이 판정만 보면 **PR #212 는 중 1·중 3 을 고친 뒤 머지해도 된다**. 그 둘은 화면 시험으로 확인하면 되고, 가상 수업을 또 할 필요는 없다.
