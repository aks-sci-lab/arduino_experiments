### 6-1. 준비 (각 세션 한 번)

걸음 보내기: 걸음은 async 함수 몸통(`S` 도우미, `pg` = 열린 화면들, `R` = team.cjs). 파일로 써서 보낸다.

```bash

```

`S.look(화면, 이름)` → [주소, 그림 파일, 보이는 글]. **판단은 보이는 글과 그림으로만**(사람처럼). 그림은 `Read` 로 본다. 폰은 `S.scr(폰)` → { 화면 id, 글, 단추 } 가 더 짧다.

### 6-2. 차례 주고받기

- 차례 끝마다 `return S.out('메모')` → 작업 폴더에 `out-<역할>-<n>.json`(바뀐 문서만). 그 **파일 내용 그대로**를 상대 세션에 `send_message` 로(64 KB 아래, 넘으면 둘로). 요약·부분 필드 금지(열평형 1차에서 배움).
- 받은 쪽: 내용을 `/tmp/vc-rocket5/in-<n>.json` 으로 저장 → `return S.in('/tmp/vc-rocket5/in-<n>.json')` → 5초 기다린 뒤 자기 화면을 다시 본다(폰·교사 화면은 몇 초마다 저장소를 다시 읽음, 안 바뀌면 `await pg.X.reload()`).
- 메시지 맨 위에는 사람 말로 '이번 차례에 일어난 일'(교사가 한 말·띄운 장·기다림, 또는 팀마다 한 말·한 일·막힌 곳). 상대는 그 말과 자기 화면을 보고 **사람처럼** 반응한다.
- 차례 수: 교사 16 ↔ 학생 16 (8-1 표). 서버가 죽으면 같은 명령으로 다시 켠다(문서는 `state.json` 에서 이어짐, 화면은 다시 열어야 함).
