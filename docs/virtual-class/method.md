# 가상 수업 기록 틀

- 만든 세션: 가상 수업 · 과학교육학 교수 (2026-11-22, 통합 관리 세션 부탁)
- 쓰는 곳: 교사 세션 `docs/virtual-class/teacher/<실험>.md`, 학생 세션 `docs/virtual-class/student/<실험>.md` 의 **차수마다 한 절**. 11월 27일 다시 시작하는 수업부터 이 틀을 쓴다.
- 바탕: `AGENTS.md` '가상 수업' 의 '가상 수업 방법 보완' ①~⑧, 교수 세션 `docs/virtual-class/professor/common.md` 4장.
- 아래 틀을 복사해 `{ }` 를 채운다. 칸을 비울 때는 '해당 없음'이나 '기록 못 함'과 까닭을 적는다(빈칸으로 두지 않기).

## 0. 순서 한눈에

| 언제 | 누가 | 무엇을 |
|---|---|---|
| 수업 전 | 교수 세션 | 성공 기준(진행 조건·지표·목표값) — `docs/virtual-class/professor/<실험>.md` 의 '○차 성공 기준' 절 |
| 수업 전 | 교사 세션 | 아래 1·2장(판·인물·짠 측정값)을 채우고, 학생 세션에는 **인물 설명과 시나리오만** 보낸다(무엇을 고쳤는지 알리지 않음 — 보완 ②) |
| 수업 중 | 두 세션 | 차례마다 **바뀐 문서만** 주고받고(보완 ⑧), 판정에 필요한 장면만 찍는다. 대화는 4장 표에 바로 적는다 |
| 수업 뒤 | 교사·학생 세션 | 3장 판정표를 **성공 기준에 적힌 값 그대로** 채운다. 의견은 판정 칸이 아니라 '의견' 칸에 |
| 수업 뒤 | 교수 세션 | 판정표를 읽고 다음 개선 후보(상·중·하)를 낸다 |

## 틀 (차수마다 복사)

```markdown
## {실험} 합동 가상 수업 {N}차 ({날짜})

### 1. 진행 조건

| 항목 | 값 |
|---|---|
| 판 (main 커밋 + 들어간 PR) | {예: main 96b9620 + #167} |
| 성공 기준 문서 | {docs/virtual-class/professor/<실험>.md ○장} |
| 진행 방식 | {7단계 / 가설연역 / 둘 다(조 나눔)} — 가설연역도 할 것(보완 ⑥) |
| 교사 화면 크기 | {3840×2160 배율 ○% / 1920×1080} |
| 차례 수 | {교사 ○ ↔ 학생 ○} |
| 학생 세션에 알린 것 | {인물 설명·시나리오만 / 그 밖에 알린 것이 있으면 적음} |
| 일부러 하지 않은 것 | {예: 교사 '덮개 반쯤' 안 씀, 분광기 건너뜀} |

### 2. 인물과 짠 측정값

#### 2-1. 인물 (3장·4장의 '누가' 는 이 이름으로)

| 조·팀 | 사람 (나이·학년) | 이해 수준 | 성격·버릇 | 어려운 인물? (보완 ④) |
|---|---|---|---|---|
| {1조} | {고2 ×4} | {상} | {풀이 전에 답함} | {예: 먼저 답해 버림} |
| | | | | |

- 어려운 인물(화면을 안 읽음 · 어른만 누름 · 먼저 답해 버림 중 하나 이상)이 **최소 한 팀**인지: {예/아니오}

#### 2-2. 짠 측정값 (보완 ③ — 가짜 장치 값에 맡기지 않음)

| 조·팀 | 바꾼 것 | 값 | 넣은 측정값 (반복 모두) | 범위 (최소~최대) | 이 조에 심어 둔 상황 |
|---|---|---|---|---|---|
| {1조} | {가열 시간} | {60 s} | {470, 474, 468 nm} | {468~474} | {경향 보임} |
| {2조} | {가열 시간} | {120 → 180 s} | {490, 493 / 492, 495} | {겹침} | {'차이 < 흔들림'} |
| {3조} | {가열 + 요소} | {…} | {…} | | {두 가지 함께 바뀜} |

- 네 가지가 다 들어 있는지: 경향 {✓} · 흔들림(같은 조건 반복) {✓} · '차이 < 흔들림' 조 {✓} · 두 가지 바뀐 경우 {✓}
- 이 값을 어떻게 넣었나: {예: 가짜 카메라 색 덮어쓰기 / 초시계 값 입력 / 스크립트 `tools/virtual-class/…` 의 어느 줄}

### 3. 성공 기준 판정표

성공 기준 문서의 표를 **그대로** 옮기고 오른쪽 세 칸만 채운다. 판정은 기준에 적힌 대로: **풀림 / 절반 / 그대로 / 기준선**.
- **기준선** = 그 지표가 달린 기능이 아직 이 판에 없음 → 판정하지 않고 값만 적는다(다음 판과 견줄 출발점).

| # | 관찰할 것 | 지난 값 | 목표값 | **이번 값** | **판정** | **근거 장면** (누가·어느 화면·한 말, 한 줄) |
|---|---|---|---|---|---|---|
| 1 | {…} | {…} | {…} | | | |

#### 3-1. 나빠지지 않았는지 (회귀)

| 관찰할 것 | 지난 값 | 기준 | **이번 값** | **판정** |
|---|---|---|---|---|
| {수업 시간} | {95분} | {100분 안} | | |

#### 3-2. 다섯 원칙 지표 (모든 수업 같은 표)

| 원칙 | 지표 (이 수업에서 센 것) | 지난 값 | 목표 | **이번 값** |
|---|---|---|---|---|
| 문제 인식 | {예: 우리 팀 물음을 자기 말로 말한 조} | | | |
| 변인 통제 | {예: 값을 두 가지 넘게 잰 조 / 같게 둘 것을 적은 조} | | | |
| 인과관계 | {예: 까닭을 적은 조 수} | | | |
| 과학적 사고 | {예: 예측↔결과 또는 흔들림↔효과를 말로 견준 조} | | | |
| 비계 | {교사가 따로 찾아가 도운 횟수} | | | |
| 상호작용 | {다른 조 자료·생각을 근거로 한 발언 수} | | | |

#### 3-3. 의견 (판정과 다르게 느낀 것)

- {예: 기준 5 는 '풀림'이지만, 인물이 문구를 읽자마자 따른 것이라 실제 학생에게는 낙관적일 수 있음}

### 4. 대화 기록 (보완 ⑤)

판정표의 근거가 되는 장면, 또는 까닭·반박·기다림이 드러난 장면을 시간 순서로. **한 장면 = 한 줄.**

| 분 | 조·팀 | 무엇에 대해 (화면·물음) | 누가 까닭을 말했나 | 반박·다른 생각이 나왔나 | 교사가 물은 뒤 기다렸나 | 한 말 (짧게) |
|---|---|---|---|---|---|---|
| {12} | {2조} | {1 목적 '왜 색이 다를까'} | {학생 B(중)} | {있음 — 학생 C "진해져서 아냐?"} | {예, 약 5초 뒤 조 지명} | {"더 타서 갈색, 물감처럼"} |
| | | | {아이 / 어른 / 교사 / 아무도} | {없음 / 있음 — 누가 무엇} | {예(몇 초) / 아니오(바로 답을 말함) / 해당 없음} | |

마무리 셈 (수업 끝에 한 번):
- 까닭을 말한 사람: 학생(아이) {○}번 · 어른 {○}번 · 교사 {○}번
- 반박·다른 생각이 나온 장면: {○}번
- 교사가 물은 뒤 3초 넘게 기다린 물음 / 바로 답을 말한 물음: {○} / {○}
- 증거를 묻는 발문("어느 숫자를 보고 알았어요?" 같은 것): {○}번

### 5. 막힌 곳 · 새로 보인 것

성공 기준 표에 없는 발견만. 상·중·하와 '실제 기기 확인 필요'를 나눠 적는다(지금 기록 방식 그대로).

| 상·중·하 | 무엇 | 누가·어느 화면 | 고칠 곳 제안 (화면/설명 장/교사 화면/운영) |
|---|---|---|---|

- 실제 기기 확인 필요: {…}

### 6. 실제 시범과 견주기 (보완 ⑦ — 실제 학생·가족 시범을 했을 때만)

가상 수업과 **같은 지표**로 센다. 시범 기록은 선생님이 준 것만(아이 이름·얼굴·목소리는 적지 않음).

| 지표 (3장·3-2 와 같은 번호) | 가상 수업 값 | 실제 시범 값 | 차이 | 다음 가상 수업 인물·짠 값에 고칠 것 |
|---|---|---|---|---|
| {3b 한 값 팀이 값을 바꿔 잼} | {D 팀 바꿈} | {2팀 중 1팀} | {가상이 낙관} | {'어려운 인물'에 '안내를 읽고도 넘어감' 추가} |

- 시범 조건: {날짜 · 몇 팀 · 나이 · 실물 재료 · 누가 기록}
- 가상 수업에서 못 본 것 중 시범에서 보인 것: {…}

### 7. 차례 기록 (세션 한도 아끼기, 보완 ⑧)

| 차례 | 누구 | 주고받은 바뀐 문서 (경로·필드만) | 찍은 화면 (판정 # 와 짝) |
|---|---|---|---|
| {1} | {교사} | {labClasses/{수업}: stage 1→2, lesson.i 3} | {#5 근거 1장} |
```

## 쓰는 법 메모

- **판정은 기준 문서의 값 그대로.** 수업을 해 보니 기준이 이상하면 판정은 기준대로 하고 3-3 '의견'에 적는다. 다음 차수 기준을 고칠 때 근거가 된다.
- **'기준선'** 은 기능이 아직 없을 때만 쓴다(예: 양자점 3차의 반 전체 그래프·흔들림 범위 — 선생님이 이번에 고르지 않아 지금 판에 없음). 기능이 있는데 결과가 나쁘면 '그대로'다.
- **대화 기록은 짧게.** 모든 말을 옮기지 말고 판정 근거가 되는 장면, 또는 까닭·반박·기다림이 드러난 장면만. 장면당 한 줄.
- **인물 말은 연기**임을 잊지 않는다. 고친 곳에 인물이 '바로' 반응했다면 3-3 에 그렇게 적는다(낙관 가능성).
- 학생 이름·학번은 쓰지 않는다. 인물은 '1조 학생 B(중)', '팀 A 엄마'처럼.
- 교사 기록과 학생 기록은 같은 판정표를 각자 채운다. 두 기록의 판정이 다르면 교수 세션이 장면을 보고 정리한다.
