## 잘 된 것

- 375px 가로 스크롤 없음, 본문 단추 56px 이상(위쪽 단계 탭·추천 이름 칩만 44px). 화면 길이는 대부분 1~1.4장.
- 단계가 열리면 기다리던 폰이 2~3초 안에 저절로 넘어가고 '▶ 선생님이 … 열었어요' 띠가 보임.
- 같은 팀 이름·빈 이름·없는 수업 코드의 안내 글이 쉬운 말.
- 인터넷이 끊겨도 측정이 폰에 남고(새로고침해도), 다시 연결되면 약 19초 뒤 저절로 보내며 띠가 '✅ 선생님께 보냄'으로 바뀜.
- 수업 없이 열면 'ℹ️ 선생님 QR 로 들어오지 않았어요. 결과는 이 폰에만 저장돼요', 조 공유 칸 없음.
- 퀴즈: 오답에 줄이 그어지고 바로 반응, 예측 → 측정 → '예측보다 ○초 빨랐어요' → 왜? 순서가 화면으로 지켜짐.

## 고칠 점

### 상

1. **측정하는 도중에 선생님이 다음 단계를 열면 측정이 사라지고 새 단계 첫 화면으로 끌려감.** 초시계가 가는 중(1초)에 2차시가 열리자 바로 2차시 소개 화면이 됨. 묻는 말 없음. 발포비타민은 이미 넣었는데 기록할 곳이 없어짐. → 측정·녹화·장면 고르기 화면에서는 옮기지 말고 '선생님이 2차시를 열었어요. 이 측정을 마치면 넘어가요 [지금 가기]' 띠만.
2. **늦게 온 가족·느린 가족이 앞 단계를 하나도 안 했는데 새 단계로 끌려감.** B 는 생각 열기 첫 화면에 있다가 2차시로 옮겨짐(생각 열기 0문제, 1차시 측정 0개). 위 탭으로 되돌아갈 수는 있지만 그걸 알려 주는 글이 없음. → 아직 앞 단계를 안 끝낸 팀에는 '앞 단계가 남았어요: [1차시 이어서 하기] / [2차시로 가기]' 고르기.
3. **단계로 '돌아가기'를 누르면 그 단계 맨 처음부터 다시 걸어야 함.** 잠김 화면의 '← 1차시으로 돌아가기'나 위 탭 '1차시'를 누르면 소개 → 안전 확인 → 퀴즈(이미 푼 것) → 조건 고르기 → 퀴즈 → 값 → 예측 → 방법 고르기까지 8화면을 지나야 다시 잴 수 있음. 하던 결과·그래프 화면으로 바로 못 감. 일찍 끝내고 더 재 보려는 가족(가장 흔한 '기다리는 시간')에게 큰 걸림. → 그 단계에서 마지막에 보던 화면으로 돌아가거나, 단계 첫 화면에 '이어서 하기(그래프·더 재기)' 단추.

### 중

4. **녹화 영상이 맨 앞(0초)에서 열림.** '펑'은 영상 끝 쪽인데 ⏩ 가 0.5초씩이라 15초 실험이면 30번쯤 눌러야 함(또는 가는 막대를 끌기 — 젖은 손으로 어려움). 시계가 시작되기 전 구간에서는 ⏩ 를 눌러도 '⏱ 0.00초' 그대로라 고장처럼 보임. → 끝에서 1~2초 앞에서 열기, ±5초 단추, 시계 시작 전 구간은 건너뛰기.
5. **같은 조건으로 한 번 더 잴 때마다 예측 화면·방법 고르기(녹화/초시계) 화면을 또 지남.** 한 번 재는 데 누름 6번. 예측 값은 늘 10초로 돌아가 있어(직전에 2.7초가 나왔어도) 대부분 그냥 넘김 → 예측의 뜻이 흐려짐. → 같은 조건 반복은 예측을 한 번만, 방법은 직전 것을 기억('다른 방법으로' 작은 링크).
6. **조건 값 화면의 '이 조건은 지금까지 ○번 쟀어요'가 값을 바꿔도 안 바뀜.** 10 mL 를 3번 잰 뒤 +로 20 mL 로 바꿔도 '3번 쟀어요'(20 mL 는 0번). 변인 통제를 배우는 화면에서 틀린 정보.
7. **인터넷이 끊긴 채 새로고침하면 잠금이 다 풀림.** 2차시·정리 탭이 열려 선생님보다 먼저 갈 수 있음(다시 연결되면 약 19초 뒤 다시 잠김 — 그때 2차시에 있던 화면이 어떻게 되는지는 못 봄). → 마지막으로 받은 열린 단계를 폰에 기억.
8. **수업 뒤 주소만으로(QR·코드 없이) 다시 열면 팀 이름 입장 화면이 나옴.** 같은 폰인데 내 점수·그래프·결과 카드를 볼 길이 안 보임(QR 주소로 열면 그대로 보임). 집에 가서 방문 기록·메인 화면으로 여는 가족이 해당. 수업 코드로 찾기는 2일뿐. → 이 폰에 남은 지난 기록이 있으면 '지난 기록 보기: 무지개 팀 (11/20)' 단추.
9. **늦게 온 가족에게 '지금 수업은 1차시예요'라는 안내가 없음.** 입장하면 생각 열기 소개가 나오고, 위 탭만 봐서는 다른 팀이 어디를 하는지 모름.
10. **생각 열기 화면에서 보기를 고르면 '다음' 단추가 화면 아래로 밀려 반쯤 가려짐**(iPhone 13, 설명이 펼쳐지면서). 한 화면 한 가지 일 원칙에서 아쉬움. 퀴즈 풀이가 펼쳐질 때도 1.1~1.5장.
11. **2차시 첫 발사까지 화면 13장**(소개·퀴즈·설계 기록 5칸·퀴즈·조건·값·안전·촬영 안내). 35분 가운데 폰만 보는 시간이 김. 설계 기록 화면은 −/+ 단추가 10개.
12. **측정 중 '보내는 중 ⏳' 띠가 여러 화면 동안 이어짐**(몇 초 뒤 ✅). 가족이 '안 보내졌나?' 하고 멈출 수 있음(급한 것은 아님).

### 하

13. 조사: '‘1차시’ 은 아직 잠겨 있어요', '‘생각 열기’ 으로 돌아가기', '물의 양을(를)', '몸체 무게을(를)', '목표와 11.6초 빠름'.
14. 두 번 틀린 뒤 맞히면 '⭕ 맞았어요! +0점' — 그 앞 안내는 여전히 '(맞히면 5점)'.
15. 수업 코드를 줄표 없이(예: 15000) 넣으면 '반-숫자 4개 모양이에요'만 — 저절로 줄표를 넣어 주면 좋음.
16. 팀 이름이 12글자를 넘으면 말없이 잘림('…가족팀짱짱' → '…가족').
17. '결과 · 0개', '몸체 무게 0개' — 무엇이 0개인지(클립? 찰흙?) 화면에 없음.
18. 결과 카드의 '🚀 가장 높이 133%'는 목표(딱 아이 키만큼)와 반대 방향을 칭찬함 → '아이 키에 가장 가까운 기록'.
19. 정리에서 생각 열기를 건너뛴 팀은 '처음 –' 로만 나옴(왜 비었는지 설명 없음). '지금' 칸에는 마지막에 맞힌 답이 아니라 처음 누른(틀린) 답이 적힘 — 뜻은 맞지만 아이가 '나 맞혔는데?' 할 수 있음.
20. '▶ 선생님이 ‘2차시’ 단계를 열었어요' 띠가 그 뒤 6화면 동안 남음.
21. 결과 카드 저장 파일 이름이 시험 브라우저에서 `download` (실제 기기 확인 필요).

## 수업 원칙으로 본 것 (선생님 원칙: 인과관계 · 비계 · 변인 통제 · 문제 인식)

1. **왜 이 측정을 하는지 화면만 보고 알았나** — 1차시 소개('조건을 바꾸면 열리는 시간이 어떻게 달라질까요? 목표 시간에 맞추기')로 알 수 있음. 2차시도 '아이 키만큼'으로 분명.
2. **막혔을 때 화면의 도움** — 퀴즈 오답은 '한 번 더'(물음), 맞히면 정의를 바로 보여 줌. '왜 달랐을까'는 보기 5개에서 고르면 풀이를 바로 줌(스스로 말해 볼 틈은 없음). 장면 고르기·세 곳 누르기에서 막히면 도움말 없음.
3. **무엇을 바꾸고 같게 둘지 스스로 정했나** — 바꿀 조건 하나를 스스로 고르고 나머지가 🔒 로 보임(좋음). 다만 같게 둘 값은 이미 채워져 있어 '왜 같게 두나'는 퀴즈로만 지나감. 6번(횟수 글이 틀림)이 이 배움을 흐림.
4. **스스로 궁금한 점·탐구 문제를 만들 기회** — 없음. 문제는 화면이 줌. (행사형이라 쓰기 칸 대신 '다음에 바꿔 보고 싶은 것' 고르기 한 화면 정도면 될 듯.)
5. **예측 → 관찰 → 설명** — 틀은 잘 잡혀 있음. 다만 5번(예측이 늘 10초로 되돌아감) 때문에 두 번째부터는 예측이 형식이 됨. 그래프 화면에는 '많을수록 빨라졌나요/느려졌나요' 같은 물음에 답하는 곳이 없어 보고 넘김.

## 상호작용

- **화면이 말을 거는가**: 가족 A 가 본 약 45화면 가운데 읽기만 하는 화면은 소개·촬영 안내 등 5장쯤, 나머지는 고르기·+/−·누르기. 한 화면 글은 2~4줄. 말투는 초3 눈높이(쉬운 말 먼저, 용어는 괄호). 누르면 바로 반응(⭕❌, 점수, '예측보다 ○초'). 저장됐는지는 위 띠(✅/⏳/📶)로 늘 보임.
- **가족끼리**: '가족과 이야기해서 정해요'는 예측 화면 한 곳뿐. 누가 뚜껑을 닫고 누가 단추를 누르는지 역할 안내가 없음(녹화는 폰을 세워 두고 노란 단추를 눌러야 해서 두 사람이 필요) — 실제 기기 확인 필요.
- **다른 팀과 견주기**: 가족 폰에서는 다른 팀 점수·결과를 볼 수 없음(교사 결과판만). 일찍 끝낸 팀이 기다리는 동안 볼 것이 '⏳ 아직 잠겨 있어요' 뿐.
- **선생님 설명과 같은 화면인가**: 선생님이 단계를 열면 첫 화면으로 모이므로 그 순간은 같음. 그 뒤는 가족마다 다른 화면.
- **맞지 않는 말**: 교사용·개발 용어·오류 코드는 못 봄. '🏫 선생님 연결 · 도움말'은 모든 화면 아래에 있으나 열어 보지 않음. '질량이 작을수록 가속도가 커지는 점을 이용해 … 조절한다'(운영계획서 문장 그대로)는 초3 에게 어려움.

## 실제 기기 확인 필요

- 진짜 카메라 권한 창, 세로 영상에서 세 곳 누르기 정밀도(젖은 손, 확대 없음), 큰 시계가 겹친 영상의 앞뒤 넘기기 속도(아이폰 사파리)
- 다른 앱 갔다 오기·화면 꺼짐 뒤 초시계/녹화가 어떻게 되는지(여기서는 새로고침만 흉내)
- 행사장 와이파이, QR 찍기, 결과 카드가 사진첩에 들어가는지

## 12월 12일 행사 전에 꼭 고칠 것

1. **단계가 열려도 결과·퀴즈 화면에 있던 팀은 스스로 눌러야 넘어감(띠에 단추 없음).** 띠 글('지금 단계를 끝내면 넘어가요')을 안 읽는 가족은 그 자리에 머묾 — B 는 1차시 결과만 보고 있었고, C·D 는 정리를 못 하고 끝남. 결과 화면에는 '끝내기'가 따로 없어 '끝내면'이 무슨 뜻인지 모호. → 띠에 '[2차시로 가기 →]' 단추.

### 설명 장이 있어서 나아진 것

1. 물음이 장면이라 초3 도 답함 — 폰 보기(낱말 뜻 문장)는 아무거나 누르던 아이가 프로젝터 물음에는 입을 뗌.
2. 계획표 + 교사의 "하나만 바꿔 한 번 더" 뒤에 **값을 바꿔 견준 팀이 0팀(1차시) → 2팀(2차시)**. 정리 장 2 문장 틀로 초3 이 원인 문장을 말함(이번 수업에서 가장 잘 된 곳).
3. '같은 조건인데 달라요'·'왜 % 로 잴까요'는 폰에 없는 물음이라 겹치지 않고 팀마다 다른 답이 나옴.
4. 안전 장을 다 같이 소리 내어 읽음(폰 체크는 아이가 혼자 눌러 버림).
5. 단계가 열릴 때 하던 화면이 안 끊기고 띠 단추만 뜸(고친 판 2 그대로 잘 됨).

### 고칠 점

**상**

1. **답이 두 곳(폰 📘 · 프로젝터 풀이)에서 나오고 누가 먼저인지가 팀마다 다름.** 생각 열기는 폰에서 보기를 누르자마자 프로젝터 풀이와 같은 글이 떠 '물음 → 풀이'가 힘을 못 씀. 1·2차시 점수 퀴즈는 거꾸로 프로젝터 풀이가 먼저 나와, 앞을 본 팀은 듣고 골라 처음에 다 맞힘(2차시 A·C·D). → 생각 열기에서는 폰이 고른 것만 저장하고 📘 는 교사가 풀이를 연 뒤(또는 정리에서) 보이기 / 점수 퀴즈와 같은 물음의 장은 '퀴즈를 푼 팀 N / 4'를 보고 풀이 열기.
2. **폰이 교사 장과 묶여 있지 않고 '앞을 보세요' 신호가 없음.** 폰에는 늘 큰 '다음 →'이 켜져 있어 먼저 누르는 팀은 설명 내내 폰에 있고(생각 열기를 5초에 끝내고 8분 기다림), 활동 중 띄운 장(35·42분)은 네 팀 다 못 봄. → 교사가 설명 장을 띄운 동안 폰 위에 '👀 앞(큰 화면)을 봐요' 띠, 기다림 화면에도 같은 말.
3. **1차시 장 1 선생님용 글이 가리키는 폰 퀴즈('기체 발생과 압력')는 그 자리에 없음** — 폰에서는 세 번 재고 그래프·'왜 달랐을까' 뒤. 장 1 풀이가 그 퀴즈 답을 20분 먼저 알려 줌(폰도 바로 앞 화면 📘 에서 답 문장을 먼저 보여 줌).
4. **값을 바꿔 보지 않아도 폰이 그래프(점 하나) → 도전으로 보내 줌.** 1차시 50분에 값을 바꾼 팀 0, 2차시도 첫 발에 목표를 맞힌 팀·먼저 누르는 팀은 한 조건으로 끝 → 정리 장 2 문장을 말할 수 없음. → 조건이 2개가 되기 전에는 도전 단추 대신 '값을 하나 바꿔 한 번 더 재면 견줄 수 있어요'.

**중**

5. 장의 예측 물음(1차시 '따뜻하게 하면 길어질까 짧아질까? 왜?', 2차시 '점토를 하나 더 붙이면 몇 %쯤?')을 적을 곳이 폰에 없음(1차시 폰 예측은 '몇 초' 숫자, 2차시는 예측 화면 없음). 1차시 물음은 물의 온도를 고른 팀에게만 자기 일 → '우리 팀이 바꿀 것을 늘리면 길어질까 짧아질까' + 폰에 길어져요/짧아져요 고르기.
6. 2차시 장 1 그림에 '몸통 ↑ · 물·기체 ↓'가 풀이 전부터 보임 — 초3 이 그림 글을 읽어 답함("그림에 그렇게 돼 있어요").
7. 2차시 장 4 표의 '앞코 모양'은 폰 바꿀 것 보기(4개)에 없음. 폰 '로켓 설계 기록'은 장에 없어 초3 팀은 기본값 그대로 넘김. 폰은 안전이 계획 뒤, 장은 앞.
8. 같은 정의 문장이 하루에 네다섯 번 나오지만 초3 은 끝까지 가속도·압력 보기를 못 가림. 2차시 풀이 '질량이 클수록 가속도가 작아져'가 아침의 '가속도 = 속도가 변하는 정도'와 이어지지 않음("가속도는 아까 그 0?") → 초3 말 한 줄('가속도 = 빨라지거나 느려지는 것', '무거우면 같은 힘으로 덜 빨라져요').
9. 프로젝터 물음(장면)과 폰 보기(낱말 뜻)가 다른 이야기 — 폰 보기에도 같은 장면 한 줄을.
10. 교사 말 "폰에서는 '시작'만 누르고 기다려요"의 '시작'이 '시작하기'(입장)인지 '시작 →'(문제로)인지 헷갈림 → 장 1 에 폰 화면 그림.
11. 2차시 결과 안내 '무게를 줄이거나 …'가 몸체 무게 0개일 때도 나옴. 눈으로 고르기는 120 / 100 / 70 세 값뿐이라 점토 하나 차이를 못 봄(D: 70 → 70).
12. 중2 는 답을 다 알아 심드렁 — 장에 한 걸음 더 묻는 거리(왜 세 번 재나, 눈으로 고르면 왜 차이가 안 보이나)가 없음.

**하**

13. '⭕ 맞았어요! +0점'(세 번째에 맞힘) — "맞았는데 왜 0점이야?".
14. 처음부터 맞힌 팀은 정리에서 ✨ 가 0 이라 실망(B) — '처음부터 맞았어요 👍' 표시.
15. 다시 풀기에서 맞던 것이 틀리게 바뀐 것(C 힘)은 아무 표시가 없음.
16. 부모·할머니가 '일정한 넓이'·'변인 통제'를 아이에게 풀어 주지 못함 — 장 아래 '집에서는 이렇게 말해요' 한 줄.

### 교사 쪽에서 돌아온 것(교사 세션 기록에 자세히)

- 🎬 발표 보기 위 띠는 '단계 · 팀 수'뿐 — 설명 중에는 기다리는 팀, 안 고른 팀, 값을 안 바꾼 팀, 점 하나로 도전에 간 팀을 알 수 없었음.
- 활동 중 '📖 설명'으로 돌아가면 그 단계 장 1 부터 다시 시작(장 6 까지 → 를 여러 번).
