## 여러 수업에서 되풀이된 것 (공통 부품 쪽)

- **단계 열기**: 하던 측정이 끊김(①) · 잇달아 열면 가장 새 단계까지 못 따라옴(②) · 늦게 온 학생은 1 목적에 머물고 지금 단계 안내가 없음(전부)
- **조 공유 칸**: 수업으로 들어왔는데 5 데이터 맨 위에 긴 칸(🎲 새 조 코드 만들기 포함)이 펼쳐져 측정이 아래로 밀림(②③⑤⑥⑦⑧⑨)
- **'자동으로 나눠요'**: 노트북에서 재는 실험은 '📤 선생님께 보내기'를 눌러야 감(③⑦⑧)
- **7 결론**: 예전 분석 질문·결론 칸(이 기기에만 저장)과 새 📝 보고서(선생님께 저장)가 겹침(②③⑤⑦, ④ 진자만 정리되어 있음)
- **이상한 값이 그냥 통과**: 18 V(③) · 5.5 kPa(⑦) · 기준 길이 없이 1 px = 1 mm(⑥) · 시뮬레이션 자료(④⑧) · 손가락 없이 잰 심박수(⑨)
- **예측·변인 적기**: 7단계에는 거의 없음(⑦ 가설 칸, ⑤ 예측·계획, ① 예측만) — 가설연역(②)에는 있음
- **견주기**: 학생 화면에서 반 전체·다른 조 결과를 볼 수 없음(전부)
