## 잘 된 것

- 안전: 숨 참기는 '의자에 앉아 있어요 / 지켜볼 조원 / 몸 상태' 셋을 체크해야 시작, '힘들면 언제든 멈춤 — 멈춘 것도 정상 자료', 숨을 참지 않는 학생의 역할(관찰·기록) 안내.
- 폰 → 노트북: 측정이 끝나면 저절로 회차가 되고(따로 저장 누름 없음) 보내면 노트북 목록·데이터 가공 실험실 '자료' 목록에 '📱 폰 5BUF · 1회차'로 들어옴.
- 데이터 가공 실험실: 단계마다 '전 → 후' 그림, 설정을 바꾸면 맨 위 '최종 심박수'가 바뀜, '💡 배울 점', '✏️ 무엇을 골랐고 왜? (한 줄)' — 학생이 고르고 까닭을 적게 하는 틀이 여덟 수업 가운데 가장 분명.

## 고칠 점

### 상

1. **수업으로 들어온 학생이 '데이터 가공 실험실'로 가는 길이 화면에 안 보임.** 수업 코드를 넣으면 `heart-rate.html`(심박수 재기 / 숨 참기 탐구)만 열리고, 데이터 가공 실험실은 메인 화면 실험 목록에서 따로 찾아 들어가야 함(가상 학생은 주소를 직접 넣었음). 같은 조 코드로 폰 자료가 두 페이지에 다 들어오는데 그 사실을 알려 주는 글·단추가 심박수 페이지에 없음. → 노트북 회차 목록 옆에 '🧪 이 회차를 데이터 가공 실험실에서 열기'.
2. **손가락을 안 덮어도 측정이 되고 그럴듯한 심박수가 나옴.** '☝ 손가락으로 카메라를 완전히 덮어 주세요 (빨강/초록 0.11)', 신호 품질 🔴 인 채로 ▶ 측정 시작이 눌리고, 끝나면 '✅ 저장했어요: 101 회/분 🟡 (신뢰도 95%)'. 같은 화면에 🔴(덮어 주세요)와 🟡 신뢰도 95% 가 함께 있음. (가짜 카메라의 깜빡이는 그림 탓일 수 있음 — 실제 기기 확인 필요. 그래도 '덮이지 않음'이면 결과를 내지 않거나 '손가락 없이 잰 값'이라고 표시해야 함.)

### 중

3. **결과 글이 학생 말이 아님**: '노출 값이 측정 동안 바뀌지 않음 → 보정 없이 그대로 계산 (잠그면 잠그기 전 밝기로 맞출 수 없어(셔터·ISO 범위 끝) 자동 노출로 측정)', '계산에 쓴 신호: 초록(G) · 보정 전 — 실시간 그래프(빨강 · 보정 전)와 달라요', '(빨강/초록 0.11)', 회차 목록 아래 '원본 CSV 열: t_s(초), R, G, Y … phyphox CSV …'. 개발하면서 붙인 풀이가 학생 화면에 그대로.
4. **폰 화면이 2.2장(숨 참기 3.7장).** 연결 띠·수업 띠·소개 글 아래에 카메라 단추가 있고, 숨 참기 칸은 한 번 재기 결과·그래프 아래 맨 끝에 붙음. '숨 참기 탐구'를 눌러도 화면이 그 칸으로 내려가지 않아 바뀐 것을 모를 수 있음.
5. **노트북 숨 참기 화면에 긴 '조 공유' 칸**(🎲 새 조 코드 만들기 등)과 '📤 동의한 회차 선생님께 보내기' / '📤 선생님께 보내기' 두 보내기 — 어느 것을 눌러야 하는지 헷갈림. '불러온 값 303개'(프레임 수로 보임).
6. **심박수 수업은 단계(열기·잠금)가 없는 한 화면** — 선생님이 '지금은 한 번 재기, 다음은 숨 참기'로 이끌 길이 학생 화면에 없음(두 카드가 처음부터 다 열려 있음). 숨 참기를 선생님 설명 전에 시작하는 조가 나올 수 있음(안전 확인은 있음).
7. **데이터 가공 실험실을 열면 고른 자료가 '선생님 실측 2'** — 방금 폰에서 받은 내 측정이 아님. '🆕 … 위 자료 목록에서 고르세요' 안내는 있음. 폰 측정이 15초면 단계별로 자르고 나면 남는 구간이 짧음(권장 길이 안내가 폰 화면에 없음 — 기본 30초, 가상 학생은 15초를 고름).

### 하

8. 폰 띠 '☑ 전체 선택 / ☐ 전체 해제'가 회차 0~1개일 때도 큼.
9. 노트북 심박수 페이지의 '🧪 카메라 없이 시뮬레이션 / 가짜 측정 만들기'가 학생에게도 보임(가짜 회차를 만들어 낼 수 있음 — ④⑧ 과 같은 문제, 여기서는 눌러 보지 않음).
10. 데이터 가공 실험실 숫자 표기 '숫자 약 187백만 개'.

## 수업 원칙으로 본 것

1. **왜 이 측정을 하는지** — 소개 두 줄('심장이 뛸 때마다 밝기가 아주 조금 오르내립니다')로 원리까지 알 수 있음. 숨 참기는 '안정 → 숨 참기 → 회복'이 제목에 있으나 '무엇이 궁금해서 하는지'(숨을 참으면 심박수가 어떻게 될까?)를 묻는 글은 없음.
2. **막혔을 때 도움** — 덮이지 않음·어두움을 바로 알려 줌(답을 줌: '창가에서 하거나 플래시를 켜세요'). 데이터 가공 실험실은 '배울 점'을 단계마다 줌(물음보다는 설명).
3. **변인을 스스로** — 숨 참기 30초/60초를 고름. 같게 둘 것(자세·쉬는 시간)은 안내 글에 있고 적는 곳은 '함께 적는 항목'(선택). 데이터 가공 실험실은 단계마다 설정을 스스로 고르고 까닭을 한 줄 적음(가장 좋음).
4. **탐구 문제를 스스로** — 없음. 숨 참기 전에 '심박수가 오를까 내릴까' 예측을 적는 칸이 없음.
5. **예측 → 관찰 → 설명** — 관찰(곡선·지표)은 풍부하나 예측 자리가 없고, 설명을 쓰는 곳도 보고서(ReportAI)가 붙지 않은 페이지라 없음(7단계가 아님).

## 상호작용

- **화면이 말을 거는가**: 폰은 덮기·시작·기다리기(15~60초 동안 '움직이지 마세요'), 끝나면 바로 숫자. 데이터 가공 실험실은 미는 막대·고르기·한 줄 쓰기가 단계마다 있음.
- **조원끼리**: 숨 참기에 '옆에서 지켜볼 조원'·관찰 역할이 화면에 적혀 있음(여덟 수업 가운데 역할이 화면에 나오는 유일한 곳). 재는 사람이 바뀌어도 한 폰·한 자리(1조 1번)로 쌓여 누구 회차인지는 메모 칸에 스스로 적어야 함(이름은 적지 않음 — 번호 고르기가 있으면 좋음).
- **다른 조와 견주기**: 없음. 숨 참기는 반 전체 변화율을 견주면 좋은 주제인데 학생 화면에는 내 회차만.
- **맞지 않는 말**: 3번, '사이트 저장소', '이 수업 공간', 'phyphox'.
