# 웹앱 제작 과제 보고서 — LED 플랑크 상수 실험 웹앱 (Google Apps Script)

## 1. 목적

고등학교 물리 'LED 로 플랑크 상수 구하기' 실험에서 학생들이 측정값을 종이에 적고 계산기로 그래프·기울기를 구하던 과정을 웹앱 하나로 옮긴다.

- 학생은 측정하는 그 자리에서 스마트폰으로 값을 넣고 **문턱 전압 V₀ 와 플랑크 상수 h 를 바로 확인**해, 이상한 값이면 다시 잴 수 있다.
- 선생님은 학생 제출물을 **구글 스프레드시트 한 곳**에 모아 **조별로** 결과를 비교하고 CSV 로 내려받아 평가·피드백에 쓴다.
- 별도 서버·비용 없이 구글 계정만으로 운영한다 (Google Apps Script 웹앱 + 스프레드시트).

## 2. 기능

| 구분 | 기능 |
|---|---|
| 학생 화면 | 조·이름(번호) 입력 / 측정 방식 고르기: 전류 기준(고정 저항 전압으로 전류 계산 또는 전류계 직접) · 빛 기준 / LED 별 측정값 기록·삭제, LED 추가·이름·파장 변경 / LED 마다 I–V 그래프와 직선 연장으로 V₀ / 모든 LED 의 V₀–진동수 그래프, 최소제곱 직선, h·불확도·오차율 / 입력 값 자동 저장(새로 고침해도 남음) / [제출] |
| 서버 (Code.gs) | 제출 값 검사(글자 수·숫자 범위·점 개수), 시트 수식 주입 막기, 동시 제출 잠금(LockService), LED 하나당 한 줄 저장(제출 시각·제출 번호 포함) / 교사 암호 확인(스크립트 속성), 틀린 횟수 잠금 |
| 선생님 화면 | 교사 암호로 들어가기 / 조별 요약 표(학생 수, 조 h, 오차, 학생 h 평균, 마지막 제출) / 조 고르기 → 통계·V₀–f 그래프·제출 줄 표 / 측정값으로 V₀ 다시 계산해 학생 값과 다르면 ⚠ / 이 조·전체 CSV 내려받기, CSV 글자 보기 / 새로 고침 |
| 공통 | 스마트폰 폭 기준 화면, 한국어 문구, 프로젝터용 크게 보기(Alt+B), 외부 라이브러리 없음(그래프는 캔버스로 직접 그림) |

## 3. 사용 흐름

```
선생님: 스프레드시트 만들기 → Apps Script 에 파일 붙여 넣기 → 교사 암호(스크립트 속성) → 웹 앱으로 배포
   ↓ 웹앱 주소(QR) 나눠 주기
학생: 주소 열기 → ① 조·이름 → ② 측정 방식 → ③ LED 별 측정값 기록 → ④ V₀·h·그래프 확인 → ⑤ 제출
   ↓ google.script.run.submitMeasurement(…)  →  '제출' 시트에 LED 하나당 한 줄
선생님: 주소?page=teacher → 암호 → 조별 요약 → 조 고르기 → 그래프·h 비교 → CSV
```

## 4. 구조

| 파일 | 하는 일 |
|---|---|
| `Code.gs` | `doGet`: 주소에 `?page=teacher` 가 있으면 선생님 화면, 없으면 학생 화면 / `submitMeasurement`: 학생 제출 검사·저장 / `teacherLogin`·`teacherData`: 교사 암호 확인 뒤 시트 자료 / `include`: HTML 파일 끼워 넣기 |
| `Index.html` | 학생 화면 |
| `Teacher.html` | 선생님 화면 |
| `PlanckMath.html` | 계산(최소제곱 직선, 직선 연장 문턱 전압, 빛 기준 평균, 플랑크 상수 적합). 실험실 사이트의 계산 코드를 그대로 옮김 |
| `Common.html` | 두 화면 공통 모양(CSS)·그래프 그리기·CSV 만들기 |
| `appsscript.json` | 시간대(서울)·웹앱 실행 설정 |

**보안 설계**
- 학생 화면이 부를 수 있는 서버 함수는 저장만 하고 저장 결과(줄 수·시각·제출 번호)만 돌려준다. 다른 학생 자료는 서버가 주지 않는다.
- 선생님 자료를 주는 함수는 매번 스크립트 속성 `TEACHER_PASSWORD` 와 비교한다. 암호는 코드에 쓰지 않는다. 10번 틀리면 5분 잠기고, 맞는 암호가 들어오면 횟수를 지운다. 스프레드시트를 만든 선생님 계정으로 연 브라우저는 잠겨 있어도 암호만 맞으면 들어간다(학생 장난으로 선생님이 막히지 않게).
- `@OnlyCurrentDoc`: 이 스크립트가 붙은 스프레드시트 하나만 다룬다.

## 5. 시트 구조 ('제출' 시트)

| 열 | 이름 | 내용 |
|---|---|---|
| A | 제출 시각 | 서버가 받은 시각 |
| B | 조 | 예: 3반 2조 |
| C | 이름(번호) | 예: 10307 김과학 |
| D | 제출 번호 | 한 번 제출한 LED 들을 묶는 8자리 기호 |
| E | LED | LED 이름 |
| F | 파장(nm) | LED 파장 |
| G | 진동수(10^14 Hz) | c ÷ 파장 |
| H | 문턱 기준 | 전류(직선 연장) 또는 빛 |
| I | 문턱 전압 V0(V) | 학생 화면 계산값 |
| J | 점 개수 | 측정점 수 |
| K | 전류 입력 방식 | 고정 저항 전압 / 전류계 |
| L | 고정 저항(Ω) | R |
| M | 학생 h(10^-34 J·s) | 학생이 구한 h |
| N | 학생 LED 수 | 그 제출의 LED 수 |
| O | 측정값(JSON) | 원래 측정값 (선생님 화면이 다시 계산할 때 씀) |
| P | 메모 | 학생 메모 |

## 6. 화면 설명

**학생 화면** (위에서 아래로 한 화면, 휴대폰 폭)
1. **① 조와 이름** — 조 이름을 같게 써야 한 조로 묶인다는 안내.
2. **② 측정 방식** — '전류 기준 / 빛 기준' 단추, 전류 기준이면 '고정 저항 전압으로 전류 계산 / 전류계로 전류 직접' 단추와 R·직선 구간 최소 전류 칸.
3. **③ LED 별 측정** — 빨강·주황·노랑·초록·파랑 단추(기록 수 표시)와 '+ LED 더하기'. 고른 LED 의 이름·파장, 측정값 칸과 [기록], 측정값 표(직선에 쓴 점 ●), I–V 그래프(점선 = 직선 연장), "문턱 전압 V₀ = … V".
4. **④ 결과** — LED 별 λ·f·V₀ 표, V₀–f 그래프(색 점 = LED, 파란 선 = 내 직선, 회색 점선 = 참값), "h = e × 기울기 = … J·s", 오차율·R²·절편.
5. **⑤ 제출** — 메모 칸, [📤 제출], 성공하면 "✅ 제출했습니다. LED 3개 · 시각 · 제출 번호", 실패하면 이유와 "입력한 값은 이 기기에 남아 있습니다".

**선생님 화면** (`?page=teacher`, 노트북 폭)
1. **🔒 교사 암호** — 암호를 넣고 [들어가기].
2. **조 고르기 · 🔄 새로 고침 · ⬇ 전체 CSV**.
3. **조별 요약** — 조마다 학생 수, LED 줄 수, 조 h(그 조 모든 LED 로 그은 직선), 오차, 학생 h 평균 ± 표준편차, 마지막 제출. 줄을 누르면 그 조로.
4. **조 상세** — 통계 카드 6개, V₀–f 그래프, 제출 줄 표(시각·이름·LED·λ·기준·점 수·다시 계산한 V₀·학생 h·메모), [⬇ 이 조 CSV], [CSV 글자로 보기].

## 7. 시험

Apps Script 를 컴퓨터에서 실제로 배포할 수는 없어서, Apps Script 의 SpreadsheetApp·HtmlService 등을 흉내 낸 가짜 환경에서 `Code.gs` 를 그대로 실행해 시험했다.

- 서버 시험 9개: 제출 저장·열 순서, 잘못된 값 거절, 수식 주입 막기, 교사 암호·잠금·잠금 완화, 조별로 다시 계산한 h 가 참값과 0.5 % 안.
- 화면 시험(Playwright, 휴대폰 390px·노트북 1366px): 학생 입력 → 계산 → 새로 고침 뒤 유지 → 제출 → 선생님 암호 → 조별 요약·상세·CSV, 가로 스크롤 없음.
