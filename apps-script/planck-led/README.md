# LED 플랑크 상수 실험 — Google Apps Script 웹앱

**무엇을 만들었나** — 고등학교 물리 'LED 로 플랑크 상수 구하기' 실험을 구글 Apps Script 웹앱으로 만들었습니다. 학생은 스마트폰 브라우저에서 조·이름을 적고, LED 마다 멀티미터로 잰 전압·전류(또는 고정 저항 전압)를 넣으면 웹앱이 바로 I–V 그래프와 **문턱 전압 V₀**(직선 연장 또는 빛 기준)를 구하고, 여러 LED 의 V₀–진동수 직선의 기울기로 **플랑크 상수 h 와 오차**를 계산합니다. **[제출]** 을 누르면 `google.script.run` 으로 구글 스프레드시트에 LED 하나당 한 줄(제출 시각 포함)이 저장됩니다. 선생님은 같은 웹앱 주소 끝에 `?page=teacher` 를 붙여 교사 암호로 들어가 **조별로 묶은 표·V₀–f 그래프·조 h·학생 h 평균**을 보고 CSV 로 내려받습니다.
**사용 흐름** — 선생님이 스프레드시트에 스크립트를 붙여 배포 → 학생에게 웹앱 주소(QR) 배포 → 학생 측정·계산·제출 → 선생님 화면에서 조별 확인·CSV.
**구조** — `Code.gs`(서버: 화면 열기·제출 검사와 저장·교사 암호 확인) / `Index.html`(학생 화면) / `Teacher.html`(선생님 화면) / `PlanckMath.html`(계산: 실험실 사이트의 `js/planck-math.js` 를 그대로 옮긴 것) / `Common.html`(공통 모양·그래프·CSV) / `appsscript.json`(설정). 외부 라이브러리 없이 그래프는 캔버스로 직접 그립니다.

---

## 1. 스프레드시트 만들고 스크립트 붙여 넣기

1. 구글 드라이브 → **새로 만들기** → **Google 스프레드시트** → 이름 예: `플랑크 상수 제출`
2. 메뉴 **확장 프로그램** → **Apps Script** (새 탭이 열림). 프로젝트 이름(왼쪽 위 '제목 없는 프로젝트')을 `플랑크 상수 웹앱` 으로 바꿉니다.
3. 왼쪽 **파일** 목록의 `Code.gs` 내용을 모두 지우고, 이 폴더의 `Code.gs` 내용을 통째로 붙여 넣습니다.
4. **파일** 옆 **＋** → **HTML** 을 눌러 아래 이름으로 파일 4개를 만들고(이름 끝 `.html` 은 자동으로 붙으니 빼고 입력), 각각 같은 이름 파일의 내용을 통째로 붙여 넣습니다. 이름이 한 글자라도 다르면 화면이 열리지 않습니다.
   - `Index`
   - `Teacher`
   - `Common`
   - `PlanckMath`
5. 💾 **프로젝트 저장** (Ctrl+S)
6. (선택) 왼쪽 ⚙ **프로젝트 설정** → **"appsscript.json" 매니페스트 파일을 편집기에 표시** 를 켜고, 생긴 `appsscript.json` 에 이 폴더의 같은 파일 내용을 붙여 넣습니다. 시간대(서울)를 맞추는 것이며, 건너뛰어도 동작합니다. 이때 시간대는 **프로젝트 설정** 의 **시간대** 에서 `(GMT+09:00) 서울` 로 바꿔도 됩니다.

## 2. 교사 암호 정하기 (꼭 필요)

1. 왼쪽 ⚙ **프로젝트 설정** → 아래쪽 **스크립트 속성** → **스크립트 속성 추가**
2. **속성**: `TEACHER_PASSWORD` , **값**: 학생이 짐작하기 어려운 6글자 이상 암호 → **스크립트 속성 저장**

암호를 바꾸려면 같은 곳에서 값을 고치면 바로 적용됩니다(다시 배포할 필요 없음).

## 3. 배포하기

1. 오른쪽 위 **배포** → **새 배포**
2. **유형 선택**(⚙) → **웹 앱**
3. 설명: `1차`, **다음 사용자 인증 정보로 실행**: **나**, **액세스 권한이 있는 사용자**: **모든 사용자**
   (학교 구글 계정으로만 쓰게 하려면 **Google 계정이 있는 모든 사용자** 를 골라도 됩니다)
4. **배포** → 처음에는 **액세스 승인** → 내 구글 계정 선택 → "Google에서 확인하지 않은 앱" 이 나오면 **고급** → **플랑크 상수 웹앱(으)로 이동(안전하지 않음)** → **허용**
   (선생님이 직접 만든 스크립트라서 나오는 안내입니다. 이 스크립트는 붙어 있는 스프레드시트 하나만 다룹니다)
5. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 **복사**

코드를 고친 뒤에는 **배포** → **배포 관리** → ✏️(수정) → **버전**: **새 버전** → **배포** 를 해야 학생 화면에 반영됩니다. 이렇게 하면 주소는 그대로입니다.

## 4. 학생에게 주소 나눠 주기

- 복사한 웹 앱 URL 을 그대로 학생에게 보냅니다(클래스룸 글, QR 코드 등).
- 학생 화면 순서: ① 조·이름 → ② 측정 방식 → ③ LED 별 측정값 기록 → ④ 결과(V₀·h·그래프) 확인 → ⑤ **제출**
- 같은 조는 **조 이름을 똑같이**(예: `3반 2조`) 써야 선생님 화면에서 한 조로 묶입니다.
- 입력한 값은 학생 기기에 자동으로 남아 새로 고침해도 지워지지 않습니다. 다시 제출하면 새 줄로 더해집니다.
- 학생 화면은 저장만 하고, 다른 학생의 자료는 보여 주지 않습니다.

## 5. 선생님 화면 열기

- 웹 앱 URL 끝에 `?page=teacher` 를 붙여 엽니다.
  예: `https://script.google.com/macros/s/…/exec?page=teacher`
- 2단계에서 정한 암호 → **들어가기**
- **조별 요약** 표의 줄을 누르거나 **조 고르기** 에서 조를 고르면: 그 조의 학생 수, 조 h(그 조의 모든 LED 로 그은 직선), 오차, 학생 h 평균 ± 표준편차, V₀–f 그래프, 제출 줄 목록.
- **⬇ 이 조 CSV** / **⬇ 전체 CSV** 로 내려받습니다(엑셀에서 한글이 깨지지 않게 만듦). 내려받기가 막히면 **CSV 글자로 보기 (복사용)** 를 눌러 복사합니다.
- 학생이 새로 제출하면 **🔄 새로 고침** 을 누릅니다.
- 원본은 스프레드시트의 **제출** 시트에 그대로 있습니다. 잘못 낸 줄은 시트에서 지우면 됩니다.

### 교사 화면 보호 방법을 '교사 암호' 로 고른 이유

- **암호 방식(이 웹앱)**: 배포 1번, 주소 1개로 끝납니다. 선생님 자료를 주는 서버 함수(`teacherData`)가 매번 스크립트 속성의 암호와 비교하므로, 학생이 `?page=teacher` 주소를 알아도 암호 없이는 자료를 받을 수 없습니다. 암호는 코드에 적지 않아 코드를 공유·제출해도 드러나지 않고, 10번 틀리면 10분 동안 잠깁니다.
- **'나만 접근' 배포를 따로 두는 방식**: 같은 프로젝트의 배포는 모두 같은 코드(`doGet`)를 쓰므로, 학생용 배포(모든 사용자)에서도 선생님 함수가 그대로 열려 있게 됩니다. 막으려면 별도 프로젝트로 나누고 같은 시트를 다루게 해야 해서, 처음 쓰는 분에게 단계가 많고 실수하기 쉽습니다.

## 시트 열 구조 ('제출' 시트, 첫 제출 때 자동으로 생김)

| 열 | 이름 | 내용 |
|---|---|---|
| A | 제출 시각 | 서버가 받은 시각 (날짜·시간) |
| B | 조 | 학생이 쓴 조 이름 (20자까지) |
| C | 이름(번호) | 학생 이름 또는 번호 (20자까지) |
| D | 제출 번호 | 한 번의 제출을 묶는 8자리 기호 (같은 제출의 LED 들은 같음) |
| E | LED | LED 이름 (예: 빨강) |
| F | 파장(nm) | 학생이 넣은 LED 파장 |
| G | 진동수(10^14 Hz) | c ÷ 파장 |
| H | 문턱 기준 | `전류(직선 연장, 1 mA 이상)` 또는 `빛` |
| I | 문턱 전압 V0(V) | 학생 화면이 계산한 V₀ (구하지 못하면 빈칸) |
| J | 점 개수 | (V, I) 점 수, 빛 기준이면 기록 횟수 |
| K | 전류 입력 방식 | `고정 저항 전압` 또는 `전류계` (빛 기준이면 빈칸) |
| L | 고정 저항(Ω) | 고정 저항 전압 방식일 때 R |
| M | 학생 h(10^-34 J·s) | 그 학생이 자기 LED 들로 구한 h (LED 2개 미만이면 빈칸) |
| N | 학생 LED 수 | 그 제출에 들어 있던 LED 수 |
| O | 측정값(JSON) | 원래 측정값 `{"method","iMin","iv":[{"v","i","vr"}],"glow":[…]}` — 선생님 화면은 이것으로 V₀ 를 다시 계산 |
| P | 메모 | 학생 메모 (200자까지) |

- `= + - @` 로 시작하는 글은 시트에서 수식으로 실행되지 않도록 앞에 `'` 를 붙여 저장합니다.
- 시트가 2만 줄을 넘으면 제출을 막습니다(새 시트로 옮기거나 지난 줄을 지우면 다시 됩니다).

## 계산 방법 (사이트 실험과 같음)

- **전류 기준(직선 연장)**: 전류가 정한 값(기본 1 mA) 이상인 점으로 I = aV + b 최소제곱 직선을 긋고 I = 0 이 되는 전압 V₀ = −b/a.
- **빛 기준**: 빛이 나기 시작한 전압 여러 번의 평균.
- **고정 저항 방식**: I = V_R ÷ R.
- **플랑크 상수**: 여러 LED 의 (진동수 f, V₀) 로 V₀ = (h/e)f − W/e 직선 → h = e × 기울기, 참값 6.626 × 10⁻³⁴ J·s 와 오차(%).

## 개발자용: 고치고 시험하기

- `PlanckMath.html` 은 사이트의 `js/planck-math.js` 로 자동 생성합니다. 계산을 고치면 `js/planck-math.js` 를 고친 뒤 `node tools/build-planck-apps-script.cjs`.
- 시험: `node --test tests/planck-apps-script.test.cjs` (서버: 가짜 Apps Script 로 Code.gs 실행), `node --test tests/planck-apps-script-ui.test.cjs` (화면: Playwright 로 390px·1366px, `google.script.run` 을 가짜로 바꿔 Code.gs 와 연결). 실제 Apps Script 배포는 시험하지 못합니다.
