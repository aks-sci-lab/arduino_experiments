💡 LED 플랑크 상수 실험

LED 마다 전압과 전류를 재어 넣으면 문턱 전압 V₀ 와 플랑크 상수 h 를 계산합니다. 다 하면 맨 아래 [제출]을 누르세요. 입력한 값은 이 기기에 자동으로 남습니다.

① 조와 이름

같은 조는 조 이름을 똑같이 써야 선생님 화면에서 한 조로 묶입니다.

② 측정 방식

전압을 천천히 올리면서 LED 가 처음 빛나 보이는 순간의 LED 전압을 여러 번 기록합니다. 평균이 문턱 전압입니다.

③ LED 별 측정

파장은 LED 설명서(데이터시트)의 값을 쓰세요. 모르면 기본값을 둡니다.

측정값 넣기

빛이 나기 시작한 전압

④ 결과: 문턱 전압과 플랑크 상수

● 내 측정, 파란 선 = 최소제곱 직선, 회색 점선 = 참값 h 로 그린 직선. 기울기 = h / e.

⑤ 제출

제출하면 LED 하나당 한 줄씩 선생님 구글 시트에 저장됩니다. 다시 제출하면 새 줄로 더해집니다.
