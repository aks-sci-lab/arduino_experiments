# 아두이노 Nano 33 BLE Sense Rev2 펌웨어 (센서 기반 실험실)

보드 안에 들어 있는 센서 값을 블루투스로 웹 페이지
[`projects/arduino-nano-lab.html`](../../projects/arduino-nano-lab.html)
(https://aks-sci-lab.web.app/projects/arduino-nano-lab.html)에 보냅니다.

| 측정 | 센서 칩 | 값 | 범위·속도 |
|---|---|---|---|
| 가속도 | BMI270 | x, y, z (단위 g, 1 g ≈ 9.8 m/s²) | **±16 g, 1초에 최대 100번(100 Hz)**. 25·50·100 Hz 중 고름 |
| 온도·습도 | HS3003 | °C, % | 1·2·5초마다 |
| 기압 | LPS22HB | kPa (101.3 kPa ≈ 1기압) | 1·2·5초마다 |

> ⚠️ **Rev2 전용**입니다. 상자나 보드 뒷면에 "Rev2" 가 없는 예전 Nano 33 BLE Sense 는 센서 칩이 달라(LSM9DS1, HTS221) 이 펌웨어로는 가속도·온습도가 나오지 않습니다.

## 1. 준비물

- Arduino Nano 33 BLE Sense **Rev2** 보드
- 데이터가 되는 마이크로 USB 케이블 (충전 전용 케이블은 컴퓨터가 보드를 못 찾습니다)
- PC (윈도우·맥) — 펌웨어를 한 번 올릴 때만 필요합니다

## 2. 아두이노 IDE 설치

1. https://www.arduino.cc/en/software 에서 **Arduino IDE 2** 를 내려받아 설치합니다.
2. 처음 실행할 때 드라이버 설치 창이 뜨면 모두 "설치"를 누릅니다.

## 3. 보드 패키지 설치 (한 번만)

1. 아두이노 IDE 왼쪽 세로 막대의 **보드 관리자** 아이콘(두 번째, 보드 모양)을 누릅니다.
2. 검색 칸에 `nano 33` 을 입력합니다.
3. **Arduino Mbed OS Nano Boards** 를 찾아 **설치**를 누릅니다. (몇 분 걸립니다)

## 4. 라이브러리 설치 (한 번만)

1. 왼쪽 세로 막대의 **라이브러리 관리자** 아이콘(세 번째, 책 모양)을 누릅니다.
2. 아래 네 개를 하나씩 검색해서 **설치**를 누릅니다. 이름이 정확히 같은 것을 고르세요 (만든 곳: Arduino).

| 검색어 | 설치할 라이브러리 | 하는 일 |
|---|---|---|
| `ArduinoBLE` | ArduinoBLE | 블루투스 |
| `BMI270` | Arduino_BMI270_BMM150 | 가속도 (BMI270) |
| `HS300x` | Arduino_HS300x | 온도·습도 (HS3003) |
| `LPS22HB` | Arduino_LPS22HB | 기압 (LPS22HB) |

"함께 필요한 라이브러리도 설치할까요?" 창이 뜨면 **모두 설치(Install all)** 를 누릅니다.

## 5. 펌웨어 올리기 (보드마다 한 번)

1. 실험 페이지의 "처음 쓸 때" 안에서 **NanoSenseLab.ino 내려받기**를 누르거나, 이 폴더의
   [`NanoSenseLab/NanoSenseLab.ino`](NanoSenseLab/NanoSenseLab.ino) 를 받습니다.
2. 받은 파일을 **`NanoSenseLab` 라는 이름의 폴더 안에** 넣습니다. (아두이노 IDE 는 파일 이름과 폴더 이름이 같아야 엽니다. 열 때 "폴더를 만들까요?" 라고 물으면 "확인")
3. 아두이노 IDE 에서 **파일 → 열기** 로 `NanoSenseLab.ino` 를 엽니다.
4. 보드를 USB 로 PC 에 꽂습니다.
5. 위쪽의 보드 고르기 칸에서 **Arduino Nano 33 BLE** 와 그 옆의 포트(COM3 같은 것)를 고릅니다.
   (Sense Rev2 도 보드 이름은 "Arduino Nano 33 BLE" 로 같습니다)
6. **→ (업로드)** 단추를 누릅니다. 아래에 "업로드 완료" 가 나오면 끝입니다.
   - 업로드가 안 되면 보드의 흰 리셋 단추를 **빠르게 두 번** 눌러 주황 LED 가 천천히 깜빡일 때 다시 업로드합니다.
7. (확인) 오른쪽 위 **시리얼 모니터**(돋보기)를 열고 속도를 `115200` 으로 고르면
   `[SENSOR] BMI270=OK HS3003=OK LPS22HB=OK`, `[IMU] ... +/-16 g VERIFIED` 와 `[BLE] Advertising: NanoSense-A3F1` 같은 줄이 보입니다.
   여기 나온 **NanoSense-XXXX** 가 그 보드의 블루투스 이름입니다. 보드에 스티커로 붙여 두면 편합니다.

## 6. 블루투스 이름

- 이름은 보드 칩 주소(블루투스 주소) 끝 네 자리로 **저절로** 정해집니다. 예: 주소 `…:A3:F1` → `NanoSense-A3F1`.
- 보드마다 손으로 이름을 정하거나 번호 파일을 만들 필요가 없습니다. 같은 보드는 다시 올려도 이름이 같습니다.
- 페이지에서 연결한 뒤 **💡 어느 보드인지 깜빡이기**를 누르면 그 보드의 주황 LED 가 깜빡입니다.

## 7. 수업에서 쓰기

1. 보드를 USB 나 보조배터리로 켭니다. (PC 가 없어도 됩니다)
2. **PC 나 안드로이드 휴대폰의 크롬·엣지**로 https://aks-sci-lab.web.app/projects/arduino-nano-lab.html 을 엽니다.
   - 아이폰·아이패드(사파리, 크롬 앱 포함)와 파이어폭스는 웹 블루투스가 안 됩니다.
   - 안드로이드는 블루투스와 위치(GPS)를 켜야 목록에 보드가 나옵니다.
3. **블루투스 연결** → 목록에서 `NanoSense-XXXX` 고르기 → **페어링/연결**.
   연결되면 보드의 **파란 LED** 가 켜지고 주황 LED 가 몇 번 깜빡입니다.
4. **가속도** 또는 **환경** 을 고르고 측정 간격을 정한 뒤 **▶ 측정 시작**.
5. 끝나면 **■ 측정 중지** → **CSV 저장** (엑셀에서 바로 열립니다).

### LED 뜻

| LED | 뜻 |
|---|---|
| 파란색 켜짐 | 블루투스로 연결되어 있음 |
| 주황색 몇 번 깜빡임 | 방금 연결됨, 또는 "어느 보드인지 깜빡이기" |
| 빨간색 계속 깜빡임 | 블루투스를 켜지 못함 → USB 를 뺐다 다시 꽂기 |

## 8. 알아 둘 점

- **온도가 실제보다 높게** 나올 수 있습니다. 온도 센서가 보드 위에 있어 보드(특히 블루투스 칩)가 내는 열을 받기 때문입니다(보통 1~3 °C). 켜고 5분쯤 지나 안정된 뒤 재고, 정확한 기온이 필요하면 온도계와 비교해 차이를 빼 주세요. 습도는 온도에 따라 달라지므로 같은 이유로 조금 낮게 나올 수 있습니다.
- **가속도 범위는 ±16 g** 입니다 (Pico 보드와 같음). 센서 라이브러리는 ±4 g 로 켜지만, 펌웨어가 켠 뒤 ±16 g 로 바꾸고 다시 읽어 확인합니다. 확인에 실패하면 가속도를 보내지 않고 "±16 g 로 바꾸지 못했습니다" 라고 알려 줍니다. 범위가 넓은 대신 가장 작은 눈금은 약 0.0005 g (1/2048 g) 입니다.
- 가속도는 **1초에 최대 100번**입니다. 200 Hz 를 고르면 보드가 "100 Hz 이하로 고르세요" 라고 알려 줍니다.
- 가만히 놓으면 중력 때문에 크기 |a| 가 약 1 g 입니다. 자유 낙하하는 동안은 0 g 에 가까워집니다.
- 블루투스는 보통 5 m 안에서 잘 됩니다. 값이 15초 동안 안 오면 페이지에 안내가 나옵니다.

## 9. 통신 약속 (개발자용)

Pico 센서 보드 펌웨어(`firmware/pico2w-environment/main.py`)와 같은 서비스·특성 UUID 와 명령을 씁니다.

| 항목 | 값 |
|---|---|
| 서비스 | `19b10000-e8f2-537e-4f6c-d104768a1214` |
| TX (알림, JSON 한 줄을 20바이트씩) | `19b10001-…` |
| CMD (쓰기, 글자 명령) | `19b10002-…` |
| ACCEL (알림, 측정 하나에 16바이트 `<Ifff` = ms, x, y, z g) | `19b10004-…` |

| 명령 | 하는 일 |
|---|---|
| `START:ENV` | 환경 값 `{"type":"env","ts":ms,"seq":n,"data":{"temp","humidity","pressure"(kPa)}}` |
| `START:IMU` | 가속도 16바이트 알림 |
| `STOP`, `STOP:ENV` | 멈춤 |
| `SET_SENSOR_RATE:1000\|2000\|5000` (`SET_ENV_RATE:` 도 됨) | 환경 값 간격 (ms) |
| `SET_IMU_RATE:25\|50\|100` | 가속도 속도 (Hz). 200 은 오류 |
| `GET_BOARD` | `{"type":"board",...,"data":{"name","board":null,"id"(칩 주소),"fw","saved":false,"model"}}` |
| `IDENTIFY` | 주황 LED 깜빡임 |

가속도 ±16 g: `Arduino_BMI270_BMM150` 의 `IMU.begin()` 으로 센서를 켜고(설정 파일 올리기) 나서, 보드 안쪽 I2C(`Wire1`, 주소 0x68)로 `PWR_CONF(0x7C)=0x00`, `ACC_CONF(0x40)=0xA8`(100 Hz), `ACC_RANGE(0x41)=0x03`(±16 g)을 쓰고 다시 읽어 확인합니다. 값은 `STATUS(0x03)` 7번 비트가 켜졌을 때 `0x0C` 부터 6바이트를 읽어 2048 로 나눕니다. 라이브러리의 `readAcceleration()` 은 ±4 g 기준(8192)으로 나누므로 쓰지 않습니다. `GET_BOARD` 응답의 `accelRange` 가 16 이면 확인된 것입니다.

Pico 와 다른 점

- 이름이 칩 주소로 고정이라 `SET_BOARD:`·`CLEAR_BOARD` 는 오류로 답합니다 ("바꿀 수 없음").
- 가속도 묶음 전송 `START:IMU_BATCH`(200 Hz)는 없습니다. 센서 라이브러리 기본 출력 속도가 100 Hz 이기 때문입니다.
- 조도·자외선·VOC 센서가 없어 `START:LIGHT`·`START:UV`·`START:VOC`·`START:ENV_VOC` 는 오류로 답합니다.
- JSON 메시지의 `seq` 는 환경 값과 보드 정보가 같은 번호를 이어서 씁니다 (페이지의 순서 검사 때문).
