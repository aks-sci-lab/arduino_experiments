센서 기반 웹실험실

환영합니다! 아래에서 수행할 실험 프로젝트를 선택하세요.

센서 실험은 Bluetooth 지원 제어 보드 + Pico-Environment-Sensor를 사용합니다. 각 실험 페이지의 Thonny 준비 안내에서 동일한 MicroPython 파일 네 개를 다운로드하세요. 한 실험의 연결을 해제한 뒤 다른 실험에 연결합니다. 기존 아두이노 펌웨어 업로더는 사용하지 않습니다.

프로젝트 목록

  • ➡️ 가속도계 데이터 분석 (Thonny)
  • ➡️ 환경 센서 실시간 모니터 (VOC Index 포함)
  • ➡️ 조도 센서 측정 (TSL2591)
  • ➡️ 자외선 센서 측정 (LTR390)
  • ➡️ 자유낙하 궤적 분석 (스마트폰 영상)
  • ➡️ 스마트폰 가속도 센서 실험
  • ➡️ 말루스 법칙 실험 (스마트폰 카메라)
  • ➡️ LED 로 플랑크 상수 측정 (멀티미터)
  • ➡️ 이상기체 상태 방정식 검증 (감압 용기 + 환경 센서)
