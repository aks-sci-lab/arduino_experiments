👩‍🏫 수업 연결 (교사)

구글 로그인 없이 씁니다. 선생님 구글 시트(Apps Script)에 수업을 만들면 조가 나뉘고, 학생은 QR 로 들어와 조·번호(이름 없음)를 고릅니다. 측정값은 조원과 선생님께 자동으로 공유되고, 여기서 진행 상황을 봅니다.

손으로 업데이트하는 법 (처음 5판으로 바꿀 때 · 단추가 안 될 때)
  1. Apps Script 설정에서 Google Apps Script API 를 사용으로 켜요 (다음부터 단추로 업데이트하려면 필요, 한 번만).
  2. 선생님 시트 → 확장 프로그램 → Apps Script → Code.gs 내용을 모두 지우고 새 코드를 붙여 넣어요.
  3. 왼쪽 ⚙ 프로젝트 설정 → "appsscript.json" 매니페스트 파일을 편집기에 표시 켜기 → 편집기에 생긴 appsscript.json 내용을 모두 지우고 붙여 넣어요.
  4. 저장(Ctrl+S) → 배포 → 배포 관리 → ✏️ → 버전 새 버전 → 배포 → 권한 확인 창이 나오면 고급 → (안전하지 않음)으로 이동 → 허용 (새 권한: 스스로 업데이트용).
  5. 여기서 지금 시트 연결 시험을 누르면 새 판이 보여요. 주소는 그대로예요.

① 선생님 시트 연결

  1. 구글 시트에 Apps Script(진자·플랑크와 같은 코드)를 붙여 웹 앱으로 배포합니다. 처음이면 시트 만들기 자세한 안내를 따라 하세요.
  2. 서버 코드가 새로 나오면 이 화면 맨 위에 안내가 떠요. 5판부터는 🔄 업데이트 단추로 끝나고, 4판 이하는 처음 한 번만 손으로 바꿔요(수업 연결은 4판, 스스로 업데이트는 5판 이상).
  3. 웹 앱 주소(https://script.google.com/macros/s/…/exec)를 아래에 붙여 넣고 연결 시험을 누르세요. 이 브라우저가 기억합니다.

🔑 관리 열쇠 (서버 업데이트용)

이 시트의 관리 열쇠 — 이 브라우저에 저장되어 있어요. 다른 컴퓨터에서 업데이트하려면 그 컴퓨터의 업데이트 칸에 넣으세요. 학생에게 보여 주지 마세요. 잃어버리면 Apps Script 편집기 ⚙ 프로젝트 설정 → 스크립트 속성에서 ADMIN_KEY_HASH 를 지우고 다시 연결하면 새로 만들어져요.

학생 연결

학생은 QR 을 찍거나, 메인 페이지 → 학생으로 시작에서 아래 수업 코드를 넣어요.

🔑 교사 열쇠 (다른 기기에서 이 수업을 볼 때)

열쇠 — 이 브라우저에는 저장되어 있어요. 다른 컴퓨터에서 보려면 그 컴퓨터의 이 화면에서 '수업 불러오기'에 수업 코드와 열쇠를 넣으세요. 학생에게 보여 주지 마세요.
