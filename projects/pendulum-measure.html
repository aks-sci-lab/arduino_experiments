스마트폰 진자 – 주기 측정

스마트폰을 줄에 매달아 흔들면, 폰 안의 센서(가속도·회전 속도)로 진자가 한 번 왕복하는 시간(주기 T)을 잽니다.

⚠️ 먼저 읽어요: 안전하게 매달기

  • 폰에 케이스를 씌우고, 줄 두 개를 V자로 매달아 단단히 묶어요 (폰이 빙글빙글 돌지 않게).
  • 바닥 가까이에서 흔들고, 아래에 매트를 깔아요.
  • 진폭(처음 당기는 각도)은 10° 이하로 작게 해요.
  1. 아래 실험 조건을 적어요 (이름은 적지 않아요).
  2. ▶ 측정 시작을 누르고, 폰을 매단 채 3초 동안 가만히 둬요 (센서 방향 확인).
  3. "흔드세요" 가 나오면 작은 각도로 당겼다 살짝 놓아요. 정한 주기 수보다 조금 더 흔들리게 기다려요.
  4. ■ 중지를 누르면 주기가 자동으로 계산돼요. 결과를 확인하고 CSV 저장을 눌러요.

실험 조건

L 은 줄을 매단 곳부터 폰까지의 길이예요. 폰의 무게중심까지 정확히 몰라도 괜찮아요 (여러 길이로 재면 2단계 분석에서 그래프 기울기로 g 를 구해요).

주기 계산

어떻게 계산하나요?
  1. 이동평균: 이웃한 점 몇 개의 평균으로 바꿔 잡음을 줄여요. '자동'은 신호가 한 번 오르내리는 시간의 약 0.4배 동안의 점을 평균해요.
  2. 평균 빼기: 신호가 0 을 중심으로 오르내리게 맞춰요.
  3. 0 통과 시각: 신호가 아래에서 위로 0 을 지나는 순간을 두 점 사이 직선(선형 보간)으로 정확히 구해요.
  4. 이웃한 통과 시각의 간격이 주기 T 예요. 여러 주기의 평균과 표준편차를 구해요.

회전 속도는 진자와 같은 빠르기로 한 번 오르내려요. 가속도(줄 방향)는 폰이 맨 아래를 지날 때마다 가장 커지므로 한 주기에 두 번 최대가 돼요 (최대점 간격 = T/2). 그래서 가속도로 계산할 때는 0 통과 두 번을 한 주기로 셉니다.

손으로 놓는 순간처럼 다른 주기와 25% 넘게 다른 값은 자동으로 빼요. 샘플 간격은 기기마다 고르지 않아서, 매 샘플의 실제 시각으로 계산해요.

도움말: 센서·권한·화면 꺼짐
  • 아이폰(사파리): '측정 시작'을 누르면 "동작 및 방향 접근" 허용 창이 떠요. 허용을 눌러야 해요. 실수로 거부했다면 사파리를 완전히 닫았다가 다시 열어요.
  • 안드로이드(크롬): 따로 묻지 않고 바로 측정돼요. 안 되면 크롬 설정 → 사이트 설정 → 동작 센서를 '허용'으로 바꿔요.
  • 화면 꺼짐: 측정하는 동안 화면이 꺼지지 않게 막아요(화면 켜짐 유지). 지원하지 않는 브라우저에서는 안내가 나오니, 폰 설정에서 화면 자동 꺼짐 시간을 길게 해 두세요.
  • 축 방향: 폰을 세워 매달면 보통 가속도 y 가 줄 방향, 회전 속도 α 가 흔들림 방향이에요. '축'을 자동으로 두면 가장 크게 흔들린 축을 골라요. 안드로이드와 아이폰은 가속도 부호가 반대일 수 있지만 주기 계산에는 영향이 없어요.
  • 센서는 https 주소에서만 동작해요.
