보드 번호 정하기 (선생님용)

센서 보드마다 번호를 정해 두면, 학생이 블루투스 목록에서 PicoEnv-07 처럼 보드에 붙은 스티커와 같은 이름을 고를 수 있습니다. 번호는 보드 안에 저장되어 전원을 껐다 켜도 남습니다.

하는 순서
  1. 번호를 정할 보드 하나만 전원을 켭니다.
  2. 아래 보드 연결을 누르고 목록에서 PicoEnv- 로 시작하는 이름을 고릅니다. 연결되면 그 보드의 LED 가 세 번 깜빡입니다.
  3. 번호를 확인합니다. 아직 쓰지 않은 가장 작은 번호가 미리 적혀 있습니다.
  4. 보드의 BOOTSEL 단추(보드 위의 작은 단추)를 누른 채로 번호 저장을 누릅니다.
  5. "저장했습니다"가 보이면 보드에 같은 번호의 스티커를 붙이고 연결 끊기를 누릅니다.
  6. 다음 보드로 1번부터 되풀이합니다.

PC 나 안드로이드의 크롬·엣지에서만 됩니다 (아이폰·아이패드는 안 됩니다). 예전 펌웨어가 든 보드는 먼저 아래 🔌 USB 로 펌웨어 올리기로 새 펌웨어를 올리세요.

🔌 USB 로 펌웨어 올리기 (PC 크롬·엣지)

보드를 USB 케이블로 PC 에 꽂고 단추 하나만 누르면, 사이트의 최신 펌웨어() 파일 네 개 (bme280.py·imu.py·extra_sensors.py·main.py)를 한 번에 올리고 확인합니다. 보드 번호(board.json)는 그대로 남습니다.

  1. 위의 블루투스 연결은 끊고, Thonny 는 닫습니다 (보드를 같이 쓰면 안 됩니다).
  2. 보드를 데이터용 USB 케이블로 PC 에 꽂습니다 (BOOTSEL 단추는 누르지 않습니다).
  3. 아래 단추를 누르고 목록에서 보드(「Board CDC」 또는 「Pico」 같은 이름)를 고릅니다.
  4. 「✅ 다 됐어요」가 보일 때까지 USB 를 뽑지 않습니다 (1분쯤).

    MicroPython 이 없는 보드 (처음 쓰는 보드)
    1. Pico 2 W 용 MicroPython 페이지에서 안정 버전 .uf2 파일을 받습니다 (다른 보드용을 받지 마세요).
    2. 보드의 BOOTSEL 단추를 누른 채로 USB 를 꽂으면 PC 에 RP2350 같은 이름의 드라이브가 생깁니다.
    3. 받은 .uf2 파일을 그 드라이브에 끌어다 놓습니다. 드라이브가 사라지면 끝입니다.
    4. USB 를 뽑았다가 (단추 누르지 않고) 다시 꽂은 뒤 위의 단추를 누릅니다.

    이 화면을 쓸 수 없으면 Thonny 설치 안내대로 파일을 하나씩 올려도 됩니다.

    번호를 정한 보드 목록

    이 브라우저에만 기억해 둡니다. 다른 PC 에서 이어서 하려면 목록 내보내기로 파일을 받아 두세요. 이미 번호가 있는 보드를 연결하면 목록에 자동으로 적힙니다.
