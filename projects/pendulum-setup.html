스마트폰 진자 – 선생님 설정 (한 번만)

학생 폰의 측정값이 선생님의 구글 시트에 저장되고, 같은 조 노트북에 자동으로 나타나게 하는 설정이에요. 15분쯤 걸려요. 학생은 로그인하지 않고, 이름도 저장되지 않아요 (조 코드로만 구분).

따라 하기

  1. 구글 시트 만들기: 학교 구글 계정으로 sheets.new 를 열어 새 시트를 만들고 이름을 "진자 실험" 처럼 정해요.
  2. Apps Script 열기: 시트 위 메뉴 확장 프로그램 → Apps Script. 새 탭이 열려요.
  3. 코드 붙여 넣기: 왼쪽 Code.gs 에 있는 글을 모두 지우고, 아래 📋 코드 복사를 눌러 붙여 넣은 뒤 💾 저장(Ctrl+S)해요.
    코드 내용 보기
    불러오는 중…
  4. 웹 앱으로 배포: 오른쪽 위 배포 → 새 배포 → 톱니바퀴(유형 선택)에서 웹 앱.
    • 다음 사용자 인증 정보로 실행: 나
    • 액세스 권한이 있는 사용자: 모든 사용자 (학생이 로그인 없이 보내려면 꼭 이것)
    배포 → "액세스 승인" → 내 계정 고르기 → "고급" → "(안전하지 않음)으로 이동" → 허용. 내가 만든 코드라서 나오는 경고예요.
  5. 웹 앱 주소 복사: 배포가 끝나면 나오는 웹 앱 URL(https://script.google.com/macros/s/…/exec)을 복사해요.
  6. 연결 시험: 아래 칸에 붙여 넣고 연결 시험을 눌러요. "연결됨" 이 나오면 성공!

  7. 사이트에 주소 넣기: 저장소의 js/pendulum-config.js 파일의 appsScriptUrl: '' 의 따옴표 사이에 주소를 넣어요. 어렵다면 Claude 대화(통합 관리 세션)에 주소를 알려 주면 대신 넣고 PR 을 만들어 줘요. 머지(배포)되면 모든 학생 화면에 적용돼요.

알아 두기

  • 시트에 measurements 탭이 자동으로 생기고, 측정 한 번이 한 줄로 쌓여요 (조 코드·L·진폭·축·주기 수·T 평균·표준편차·원본 데이터·비고).
  • 원본 센서 데이터는 글자 수를 줄여 rawData 칸(필요하면 rawData2~6)에 담아요. 노트북 표의 '원본' 단추로 CSV 로 다시 받을 수 있어요.
  • 코드를 고친 뒤에는 배포 → 배포 관리 → 연필 → 버전 '새 버전' → 배포 로 해야 바뀐 코드가 적용돼요 (주소는 그대로).
  • 학교 인터넷에서 script.google.com 이 막혀 있으면 자동 연결이 안 돼요. 그때는 폰에서 CSV 저장 → 노트북에서 불러오기로 해요.
