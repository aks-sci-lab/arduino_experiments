스마트폰 진자 – 선생님 설정 (한 번만)

학생 폰의 측정값이 선생님 자기 구글 시트에 저장되고, 같은 조 노트북에 자동으로 나타나게 하는 설정이에요. 학생은 로그인하지 않고, 이름도 저장되지 않아요 (조 코드로만 구분).

0. 구글 로그인 (추천)

로그인하면 내 시트 주소가 내 계정에 저장되어, 다음에 이 화면을 열면 "우리 반 링크"가 바로 나와요.

✅ 우리 반 링크

학생 노트북에서 아래 링크(또는 QR)로 진자 분석 화면을 열면, 그 노트북은 이 시트를 기억하고 폰 QR 에도 자동으로 넣어 줘요.

1. 내 시트 만들기

아래 단추를 누르면 코드가 이미 들어 있는 시트의 사본이 내 구글 드라이브에 만들어져요. "사본 만들기"를 누르면 끝!

📄 템플릿 시트 사본 만들기

사본은 선생님 소유예요. 다른 사람(템플릿을 만든 선생님 포함)은 볼 수 없어요.

템플릿 없이 직접 만들기 (코드 붙여 넣기)
  1. 학교 구글 계정으로 sheets.new 를 열어 새 시트를 만들어요.
  2. 메뉴 확장 프로그램 → Apps Script
  3. Code.gs 의 글을 모두 지우고, 📋 코드 복사를 눌러 붙여 넣은 뒤 저장(Ctrl+S)

2. 웹 앱으로 배포

  1. 시트 메뉴 확장 프로그램 → Apps Script (템플릿 사본이면 코드가 이미 있어요)
  2. 오른쪽 위 배포 → 새 배포 → 톱니바퀴에서 웹 앱
    • 다음 사용자 인증 정보로 실행: 나
    • 액세스 권한이 있는 사용자: 모든 사용자 (학생이 로그인 없이 보내려면 꼭 이것)
  3. 배포 → "액세스 승인" → 내 계정 → "고급" → "(안전하지 않음)으로 이동" → 허용. 내 코드라서 나오는 경고예요.
  4. 나오는 웹 앱 URL(https://script.google.com/macros/s/…/exec)을 복사해요.

3. 주소 붙여 넣기

알아 두기

  • 시트에 measurements 탭이 자동으로 생기고, 측정 한 번이 한 줄로 쌓여요 (조 코드·L·진폭·축·주기 수·T 평균·표준편차·원본 데이터·비고).
  • 로그인하지 않아도 "연결 시험"이 되면 우리 반 링크를 쓸 수 있어요. 다만 링크가 이 화면에만 나오니 따로 적어 두세요.
  • Code.gs 가 바뀌면(사이트 업데이트 안내가 있을 때) 코드를 다시 붙여 넣고 배포 → 배포 관리 → 연필 → 버전 '새 버전' → 배포. 주소는 그대로예요.
  • 학교 인터넷에서 script.google.com 이 막혀 있으면 자동 연결이 안 돼요. 그때는 폰에서 CSV 저장 → 노트북에서 불러오기로 해요.
(사이트 관리자용) 템플릿 시트 만들어 공유하기
  1. 새 시트(sheets.new)를 만들고 이름을 "진자 실험 템플릿"으로 정해요. 학생 데이터가 들어 있는 내 시트를 쓰면 안 돼요.
  2. 확장 프로그램 → Apps Script 에 Code.gs 를 붙여 넣고 저장해요 (배포는 하지 않아도 돼요).
  3. 시트 오른쪽 위 공유 → 일반 액세스: 링크가 있는 모든 사용자 · 뷰어 → 링크 복사
  4. 링크 끝의 /edit… 를 /copy 로 바꾼 주소를 js/pendulum-config.js 의 templateCopyUrl 에 넣어요 (Claude 대화에 주소를 알려 주면 대신 넣어 줘요). 그러면 위 1번에 "템플릿 시트 사본 만들기" 단추가 나와요.
