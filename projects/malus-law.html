🔦 말루스 법칙 실험 (스마트폰 카메라)

레이저 → 편광판(회전) → 종이/휴지 스크린 → 카메라 순으로 놓고, 편광판을 돌릴 때 스크린의 밝기가 어떻게 변하는지 탐구합니다. 카메라 접근은 https 주소에서만 동작합니다.

1. 실험 목적

  1. 편광판을 돌린 각도 θ 에 따라 통과한 빛의 세기가 I = I₀ cos²θ (말루스 법칙)로 변하는지 스마트폰 카메라로 확인한다.
  2. 직선, |cos θ|, cos²θ 세 가지 모델을 측정값에 맞춰 보고, 잔차를 보며 어느 모델이 가장 잘 맞는지 근거를 들어 판단한다.
  3. 회차마다 빛의 세기·카메라 위치가 달라도 정규화 (I − B) / A 로 여러 회차를 공정하게 비교하는 방법을 이해한다.

이 실험에서 하는 일

  1. 예측 — 각도에 따라 밝기가 어떻게 변할지 그래프로 그려 둔다.
  2. 계획 — 잴 각도·반복 횟수·배경광 처리·이상한 값 기준을 미리 정한다.
  3. 측정 — 카메라로 스크린의 밝기를 각도마다 기록한다.
  4. 분석 — 데이터를 점검하고, 모델을 비교하고, 정규화 전후를 비교한다.
  5. 결론 — 주장·증거·추론으로 결론을 쓰고 기록을 내보낸다.

2-1. 빛의 편광

빛은 전기장과 자기장이 진행 방향에 수직으로 진동하며 나아가는 전자기파(횡파)입니다. 햇빛이나 전구 빛은 전기장의 진동 방향이 여러 방향으로 섞여 있는데, 이런 빛을 편광되지 않은 빛이라고 합니다.

편광판은 한 방향(투과축)으로 진동하는 성분만 통과시킵니다. 편광판을 지난 빛은 진동 방향이 한 방향으로 정해진 선편광이 됩니다. 편광되지 않은 빛이 편광판 하나를 지나면 세기가 약 절반으로 줄어듭니다.

레이저 포인터의 빛은 대부분 이미 한 방향으로 편광되어 있어서, 편광판 하나만 돌려도 실험할 수 있습니다. 레이저 빛이 편광되어 있지 않으면 레이저 바로 앞에 편광판 하나를 고정해 두고, 두 번째 편광판을 돌립니다.

2-2. 말루스 법칙

💡 4. 과정의 '예측하기'를 먼저 하고 싶다면, 아래를 펼치기 전에 예측부터 해 보세요.

말루스 법칙 펼쳐 보기

세기가 I₀ 인 선편광 빛이 편광판에 들어갈 때, 빛의 진동 방향과 편광판 투과축 사이의 각을 θ 라고 합시다. 전기장의 진폭 E₀ 중 투과축 방향 성분 E₀ cos θ 만 통과합니다. 빛의 세기는 진폭의 제곱에 비례하므로

I = I₀ cos²θ

  • θ = 0° (투과축과 진동 방향이 나란함): 가장 밝다 (I = I₀)
  • θ = 45°: 절반 (cos²45° = 0.5)
  • θ = 90° (수직): 거의 깜깜하다 (I = 0)
  • θ = 180°: 다시 가장 밝다 — 주기가 180° 이다

진폭에 비례하는 |cos θ| 모양과 헷갈리기 쉽습니다. 두 모양은 45° 근처에서 0.71 과 0.50 으로 크게 달라서 측정으로 구별할 수 있습니다.

2-3. 실제 측정에 맞춘 식

실제 측정에서는 편광판 눈금의 0° 가 가장 밝은 위치와 정확히 맞지 않고, 주변 빛이나 카메라 잡음 때문에 가장 어두울 때도 밝기가 0 이 되지 않습니다. 그래서 다음 식으로 데이터에 맞춥니다.

I = A · cos²(θ − θ₀) + B

  • A: 밝기가 변하는 크기 (가장 밝을 때 − 가장 어두울 때)
  • θ₀: 가장 밝은 위치의 눈금 각도
  • B: 배경 밝기 (주변 빛, 카메라 잡음, 편광판이 완전히 막지 못한 빛)

2-4. 왜 정규화하나요? (I − B) / A

회차마다 레이저 세기, 카메라와 스크린의 위치, 노출이 조금씩 달라서 A 와 B 가 달라집니다. 그러면 같은 법칙을 따르더라도 곡선의 높이가 회차마다 달라 한 그래프에서 비교하기 어렵습니다.

회차마다 따로 A, B 를 구한 뒤 (I − B) / A 로 바꾸면, 모든 회차가 0(가장 어두움)~1(가장 밝음) 범위로 맞춰집니다. 이렇게 하면 곡선의 모양만 남으므로, 모양이 cos²(θ − θ₀) 를 따르는지 여러 회차를 함께 비교할 수 있습니다.

2-5. 카메라로 밝기 재기

카메라 사진의 픽셀 값(0~255)은 빛의 세기에 정비례하지 않습니다. 사람 눈에 자연스럽게 보이도록 감마라는 변환을 거쳤기 때문입니다. 이 페이지는 감마 보정으로 픽셀 값을 다시 빛의 세기에 비례하는 값으로 바꿔 계산합니다.

픽셀 값이 255 에 닿으면(포화) 그보다 밝은 빛도 255 로 잘려 cos² 곡선의 꼭대기가 눌립니다. 또 카메라가 밝기에 따라 노출을 스스로 바꾸면 측정값이 비교되지 않으므로 노출을 고정해야 합니다.

3. 준비물

  • 광원: 레이저 포인터(빨강 또는 초록, 권장). 레이저가 없으면 LED 손전등이나 모니터 화면(모니터 빛은 이미 편광되어 있음)
  • 편광판: 1장(편광된 레이저·모니터) 또는 2장(편광되지 않은 빛: 1장은 고정, 1장은 돌림). 편광 필름을 잘라 써도 됩니다.
  • 각도기 또는 각도 눈금을 붙인 회전판 (편광판을 돌린 각도를 읽음)
  • 스크린: 종이나 휴지 (빛이 고르게 번지도록)
  • 스마트폰 (카메라, 크롬 브라우저 권장)과 거치대 또는 테이프 — 폰과 스크린이 움직이지 않게 고정
  • 레이저·편광판을 세울 받침(클램프, 점토 등)
  • 어두운 환경: 커튼을 치거나 불을 끄면 배경 밝기 B 가 작아집니다.
⚠️ 안전: 레이저 빛을 눈으로 직접 보거나 다른 사람의 눈에 비추지 마세요. 거울·유리처럼 빛을 반사하는 물건은 치웁니다.

  1. 아래에서 예측하고, 측정 계획과 이상한 값 판단 기준을 정합니다.
  2. 레이저 → 편광판(회전) → 종이/휴지 스크린 → 카메라 순으로 놓습니다. 폰은 스크린 뒤에서 빛 번짐을 찍도록 거치대나 테이프로 고정합니다.
  3. 5. 데이터에서 카메라를 켜고, 초록 사각형(측정 영역)을 빛 번짐 전체가 들어가게 맞춘 뒤 노출 고정을 누릅니다(아이폰 등은 사진 불러오기).
  4. 가장 밝은 각도에서 포화 픽셀이 거의 0% 가 되도록 종이를 겹치거나 노출을 낮춥니다.
  5. 계획대로 편광판을 돌리며 각도마다 측정 기록을 누릅니다. 배경을 뺀다면 레이저를 끄고 배경을 잽니다.
  6. 카메라·스크린을 다시 맞췄다면 새 회차를 시작해 같은 측정을 반복합니다.

ℹ️ 빛 위치 자동 추적과 이동 경고의 한계
  • 자동 추적은 화면 속 빛 번짐의 위치를 따라 초록 사각형을 옮길 뿐입니다. 편광판이나 폰이 돌아간 것(각도·영점 변화)은 보정하지 못합니다.

  • 그래서 폰과 스크린은 거치대나 테이프로 고정하는 것이 가장 확실합니다.

2. 어떤 모델이 맞을까?

비교해 볼 모델을 고르세요. 각 모델을 회차마다 I = A·f(θ − θ₀) + B 꼴로 데이터에 맞춥니다. 어느 모델이 더 잘 맞는지는 그래프와 잔차(측정값 − 모델값)를 보고 직접 판단하세요.

모델회차별 R² (평균)정규화 잔차 RMS

점: 측정값(회차별 색, 빈 원은 결측). 선: 고른 모델 (실선 cos², 긴 점선 |cos|, 짧은 점선 직선).

잔차가 0 주위에 고르게 흩어지면 모델이 잘 맞는 것입니다. 잔차에 물결 같은 규칙적인 모양이 남으면 모델이 빠뜨린 것이 있다는 신호입니다.

3. 정규화 전/후 비교

생각해 보기: 회차마다 레이저 세기나 카메라 위치가 조금씩 달라 곡선의 높이가 다릅니다. 여러 회차의 결과를 공정하게 비교하려면 어떻게 하면 좋을까요?

정규화: 회차마다 따로 모델을 맞춘 뒤 (I − B) / A 로 바꿔 모든 회차를 0~1 범위로 맞춥니다. 아래 모델은 위에서 고른 잔차를 볼 모델을 따릅니다.

마지막 그래프: 정규화 밝기를 모델 모양 f(θ − θ₀) 에 대해 그린 것입니다. 모델이 맞으면 점들이 기울기 1인 점선 위에 놓입니다.

function doPost(e) {
  var d = JSON.parse(e.postData.contents);
  var sh = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  if (sh.getLastRow() === 0) sh.appendRow(d.header);
  d.rows.forEach(function (r) { sh.appendRow(r); });
  return ContentService.createTextOutput('ok');
}
