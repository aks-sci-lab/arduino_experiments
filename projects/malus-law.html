🔦 말루스 법칙 실험 (스마트폰 카메라)

레이저 → 편광판(회전) → 종이/휴지 스크린 → 카메라 순으로 놓고, 편광판 각도별 스크린의 밝기를 측정해 I = I₀·cos²θ 를 검증합니다. 카메라 접근은 https 주소에서만 동작합니다.

📖 실험 방법 / 정확하게 측정하는 요령
  1. 스크린(종이/휴지) 뒤에서 카메라가 스크린 한가운데의 레이저 번짐을 찍도록 고정합니다. 이후 폰·스크린은 건드리지 않습니다. 폰은 거치대나 테이프로 고정하는 것이 좋습니다.
  2. 카메라 켜기 후 화면을 눌러 측정 영역(ROI, 초록 사각형)을 빛 번짐 중앙에 맞추고, 번짐 전체가 사각형 안에 들어가도록 영역 크기를 키웁니다. 이렇게 하면 폰이 조금 흔들려도 밝기 합이 거의 변하지 않습니다. 맞춘 뒤 확대 보기로 바꾸면 편합니다.
  3. 노출 고정을 누르세요(안드로이드 크롬). 자동 노출이 켜져 있으면 밝기를 폰이 마음대로 보정해 측정이 틀어집니다. 지원이 안 되는 기기(아이폰 등)는 기본 카메라 앱에서 노출을 고정해 촬영한 뒤 사진 불러오기를 이용하세요.
  4. 가장 밝은 각도에서 포화 비율이 거의 0%가 되도록 종이를 겹치거나 노출을 낮춥니다.
  5. 레이저를 끈 상태에서 배경 측정을 한 번 합니다(주변광 제거).
  6. 편광판을 돌린 뒤 측정 기록을 누르고 대기 시간 동안 손을 뗍니다. 각도 자동 증가를 켜 두면 각도를 매번 입력할 필요가 없습니다. 0°~180°를 10~15° 간격으로 측정하고, 마지막에 0°를 한 번 더 측정해 처음 값과 비교하면 측정 중 흔들림이 있었는지 알 수 있습니다.

현재 밝기 –
포화 픽셀 –
영역 최대 –
⚠️ 빛 번짐이 측정 영역 밖으로 넘칩니다. 영역 크기를 키워 번짐 전체가 초록 사각형 안에 들어가게 하세요. 그래야 폰이 조금 움직여도 값이 변하지 않습니다.
⚠️ 포화된 픽셀이 있습니다. 밝기가 255에서 잘려 cos² 곡선이 눌립니다. 종이를 겹치거나 노출·ISO를 낮추세요.
ℹ️ 데이터가 있으면 채널/감마를 바꿀 수 없습니다. 바꾸려면 데이터를 지우세요.

2. 측정

1회차

0°~180° 한 바퀴를 한 회차로 측정합니다. 카메라·스크린을 다시 맞췄다면 새 회차를 시작하세요. 회차마다 따로 정규화하므로 회차 사이에 밝기가 달라져도 괜찮습니다.

배경 미측정

버튼을 누른 뒤 대기 시간 동안 폰에서 손을 떼세요. 블루투스 키보드가 있으면 Enter 키로도 기록됩니다.

⚠️ 이번 회차 첫 측정 때보다 빛 위치가 많이 옮겨져서 이 점을 결측으로 표시했습니다. 폰이나 스크린이 움직였다면 다시 맞춘 뒤 새 회차를 시작하세요. 잘못 판정됐다면 표에서 복원을 누르세요.

3. 측정 데이터

회차각도 (°)밝기 I정규화포화

4. 말루스 법칙 검증

회차마다 따로 I(θ) = A·cos²(θ − θ₀) + B 로 적합하고, 그 회차의 A, B 로 정규화 밝기 (I − B)/A 를 구합니다. 결측 처리한 점은 계산에서 빠집니다. (회차마다 유효한 점 3개 이상, 서로 다른 각도 필요)

회차점ABθ₀R²

위 그래프: 회차별(색) 밝기와 적합 곡선, 속이 빈 원은 결측 처리한 점. 아래 그래프: 모든 회차의 정규화 밝기를 cos²(θ−θ₀) 에 대해 모은 것으로, 말루스 법칙이 맞으면 점들이 기울기 1인 점선 위에 놓입니다.

🔧 내 시트 연결 방법 (1회만)
  1. 구글 스프레드시트를 새로 만들고 확장 프로그램 → Apps Script를 엽니다.
  2. 아래 코드를 붙여넣고 저장합니다.
  3. 배포 → 새 배포 → 유형: 웹 앱, 실행 사용자 나, 액세스 권한 모든 사용자로 배포하고 권한을 승인합니다.
  4. 나온 웹 앱 URL을 위 칸에 붙여넣습니다.
function doPost(e) {
  var d = JSON.parse(e.postData.contents);
  var sh = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  if (sh.getLastRow() === 0) sh.appendRow(d.header);
  d.rows.forEach(function (r) { sh.appendRow(r); });
  return ContentService.createTextOutput('ok');
}
