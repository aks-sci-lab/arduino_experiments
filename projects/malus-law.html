🔦 말루스 법칙 실험 (스마트폰 카메라)

레이저 → 편광판(회전) → 종이/휴지 스크린 → 카메라 순으로 놓고, 편광판을 돌릴 때 스크린의 밝기가 어떻게 변하는지 탐구합니다. 카메라 접근은 https 주소에서만 동작합니다.

① 예측하기

편광판을 0°에서 180°까지 돌린다고 생각해 봅시다. 0°를 가장 밝은 위치로 정하면, 각도가 커질 때 밝기는 어떻게 변할까요? 측정하기 전에 예측해 두면 나중에 결과와 비교할 수 있습니다.

예상 그래프 그리기: 아래 칸에 손가락으로 그려 보세요. (가로: 가장 밝은 위치에서 편광판을 돌린 각도 0~180°, 세로: 밝기)

③ 측정 계획 세우기

어떤 각도를 몇 번씩 잴지 정해 보세요. 밝기가 빠르게 변하는 곳과 가장 어두운 곳 근처는 어떻게 재면 좋을까요?

주변 빛(배경광)은 어떻게 할까요?

⑤ 이상한 값 판단 기준 정하기

측정하다 보면 이상해 보이는 값이 나옵니다. 데이터를 보기 전에 어떤 값을 의심할지 정해 두세요. 결과를 본 뒤에 마음에 들지 않는 값을 빼면 공정하지 않기 때문입니다.

기준에 걸린 값은 ⚠ 의심으로 표시됩니다. 실제로 뺄지(결측 처리)는 분석하기에서 이유를 적고 직접 결정합니다.

1. 카메라 준비

📖 정확하게 측정하는 요령
  1. 스크린(종이/휴지) 뒤에서 카메라가 레이저 번짐을 찍도록 폰을 거치대나 테이프로 고정합니다.
  2. 화면을 눌러 초록 사각형(측정 영역)을 빛 번짐에 맞추고, 번짐 전체가 사각형 안에 들어가도록 영역 크기를 키웁니다. 그러면 폰이 조금 흔들려도 값이 거의 변하지 않습니다.
  3. 노출 고정을 누르세요(안드로이드 크롬). 지원하지 않는 기기(아이폰 등)는 기본 카메라 앱에서 노출을 고정해 찍은 뒤 사진 불러오기를 씁니다.
  4. 가장 밝은 각도에서 포화 픽셀이 거의 0%가 되도록 종이를 겹치거나 노출을 낮춥니다.
화면을 누르거나 끌어서 측정 영역을 옮기세요.

⚠️ 빛 번짐이 측정 영역 밖으로 넘칩니다. 영역 크기를 키워 번짐 전체가 초록 사각형 안에 들어가게 하세요. 그래야 폰이 조금 움직여도 값이 변하지 않습니다.
⚠️ 포화된 픽셀이 있습니다. 밝기가 255에서 잘려 cos² 곡선이 눌립니다. 종이를 겹치거나 노출·ISO를 낮추세요.
ℹ️ 데이터가 있으면 채널/감마를 바꿀 수 없습니다. 바꾸려면 데이터를 지우세요.

2. 측정

1회차

계획한 각도를 한 바퀴 다 재면 한 회차입니다. 카메라·스크린을 다시 맞췄다면 새 회차를 시작하세요.

배경 미측정

버튼을 누른 뒤 대기 시간 동안 폰에서 손을 떼세요. 각도 칸에서 Enter, 블루투스 키보드의 Enter로도 기록됩니다.

ℹ️ 빛 위치 자동 추적과 이동 경고의 한계
  • 자동 추적은 화면 속 빛 번짐의 위치를 따라 초록 사각형을 옮길 뿐입니다. 편광판이나 폰이 돌아간 것(각도·영점 변화)은 보정하지 못합니다.
  • 이동 경고는 초록 사각형의 위치 변화로 판단합니다. 추적을 끄거나 가장 어두운 각도 근처라 추적을 건너뛰면 실제로 움직여도 경고하지 못할 수 있고, 손으로 사각형을 옮기면 움직이지 않았어도 경고할 수 있습니다.
  • 그래서 폰과 스크린은 거치대나 테이프로 고정하는 것이 가장 확실합니다.

2. 어떤 모델이 맞을까?

비교해 볼 모델을 고르세요. 각 모델을 회차마다 I = A·f(θ − θ₀) + B 꼴로 데이터에 맞춥니다. 어느 모델이 더 잘 맞는지는 그래프와 잔차(측정값 − 모델값)를 보고 직접 판단하세요.

모델회차별 R² (평균)정규화 잔차 RMS

점: 측정값(회차별 색, 빈 원은 결측). 선: 고른 모델 (실선 cos², 긴 점선 |cos|, 짧은 점선 직선).

잔차가 0 주위에 고르게 흩어지면 모델이 잘 맞는 것입니다. 잔차에 물결 같은 규칙적인 모양이 남으면 모델이 빠뜨린 것이 있다는 신호입니다.

3. 정규화 전/후 비교

생각해 보기: 회차마다 레이저 세기나 카메라 위치가 조금씩 달라 곡선의 높이가 다릅니다. 여러 회차의 결과를 공정하게 비교하려면 어떻게 하면 좋을까요?

정규화: 회차마다 따로 모델을 맞춘 뒤 (I − B) / A 로 바꿔 모든 회차를 0~1 범위로 맞춥니다. 아래 모델은 위에서 고른 잔차를 볼 모델을 따릅니다.

마지막 그래프: 정규화 밝기를 모델 모양 f(θ − θ₀) 에 대해 그린 것입니다. 모델이 맞으면 점들이 기울기 1인 점선 위에 놓입니다.

function doPost(e) {
  var d = JSON.parse(e.postData.contents);
  var sh = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  if (sh.getLastRow() === 0) sh.appendRow(d.header);
  d.rows.forEach(function (r) { sh.appendRow(r); });
  return ContentService.createTextOutput('ok');
}
