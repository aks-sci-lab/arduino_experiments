🔦 말루스 법칙 실험 (스마트폰 카메라)

레이저 → 편광판(회전) → 종이/휴지 스크린 → 카메라 순으로 놓고, 편광판 각도별 스크린의 밝기를 측정해 I = I₀·cos²θ 를 검증합니다. 카메라 접근은 https 주소에서만 동작합니다.

📖 실험 방법 / 정확하게 측정하는 요령
  1. 스크린(종이/휴지) 뒤에서 카메라가 스크린 한가운데의 레이저 번짐을 찍도록 고정합니다. 이후 폰·스크린은 건드리지 않습니다.
  2. 카메라 켜기 후 화면을 눌러 측정 영역(ROI, 초록 사각형)을 빛 번짐 중앙에 맞춥니다.
  3. 노출 고정을 누르세요(안드로이드 크롬). 자동 노출이 켜져 있으면 밝기를 폰이 마음대로 보정해 측정이 틀어집니다. 지원이 안 되는 기기(아이폰 등)는 기본 카메라 앱에서 노출을 고정해 촬영한 뒤 사진 불러오기를 이용하세요.
  4. 가장 밝은 각도에서 포화 비율이 거의 0%가 되도록 종이를 겹치거나 노출을 낮춥니다.
  5. 레이저를 끈 상태에서 배경 측정을 한 번 합니다(주변광 제거).
  6. 편광판을 돌려 각도를 입력하고 측정 기록을 누릅니다. 0°~180°를 10~15° 간격으로 측정하세요.

4. 말루스 법칙 검증

I(θ) = A·cos²(θ − θ₀) + B 로 최소제곱 적합합니다. (측정 3개 이상, 서로 다른 각도 필요)

위 그래프: 각도별 밝기와 적합 곡선. 아래 그래프: 정규화한 밝기 (I−B)/A 를 cos²(θ−θ₀) 에 대해 그린 것으로, 말루스 법칙이 맞으면 점들이 기울기 1인 점선 위에 놓입니다.
