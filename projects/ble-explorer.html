블루투스 센서 해석 도구

시판 무선 센서가 보내는 바이트를 기록하고, 어느 자리를 어떤 형식으로 읽으면 온도·힘·전압이 되는지 해석 규칙을 찾아 저장합니다. 선생님·개발자용이며 수업 화면이 아닙니다.

연결 안 됨 기록 0개

열어 볼 서비스 고르기 (Web Bluetooth 는 여기 적은 서비스만 열 수 있어요)

기기

🔎 데이터 서비스가 안 보이나요? 웹 블루투스는 위 ‘열어 볼 서비스’에 적은 UUID 만 열어 줍니다. 제조사 전용 서비스는 아래 방법으로 30초 만에 찾을 수 있어요.

  1. PC 크롬: 새 탭 주소창에 chrome://bluetooth-internals/#devices 입력 → Start Scan → 이 기기 옆 Inspect → Services: … 줄을 통째로 복사 (복사 뒤 Disconnect 또는 탭 닫기)
  2. 스마트폰: 무료 앱 nRF Connect 로 스캔·연결 → 서비스 UUID 복사
  3. 복사한 내용을 위 ‘열어 볼 서비스 고르기 → 직접 넣을 서비스 UUID’ 칸에 붙여 넣고 🔍 기기 찾아 연결을 다시 누르세요 (여러 개도 한꺼번에 처리돼요).

버니어 센서는 연결한 뒤 처음 인사(init) 명령을 받지 못하면 잠시 뒤 스스로 끊는 것 같아요. 공개 도구(godirect-js)가 보내는 것과 같은 명령을 보냅니다. 다른 회사 센서에는 아무 명령도 보내지 않아요.

연결 기록 (연결·끊김 시각, 선생님이 보내 주실 때 복사)

    서비스와 특성

    🔔 알림 = 센서가 값을 계속 보냄, 📖 읽기 = 한 번 읽기, ✏️ 쓰기 = 센서에 명령 보내기(② 기록 탭 아래)

    같은 길이의 패킷끼리 비교해 값이 바뀌는 바이트를 칠합니다. 측정값이 들어 있을 가능성이 큰 자리예요.

    📦 포장 풀기 (전처리) 그대로 (원본 바이트)

    Base64({{…}}), 16진수 글자, 텍스트/CSV 숫자로 감싸서 보내는 센서의 포장을 먼저 풀고 아래 표·참값 맞추기·그래프에 적용합니다.

    바이트별 10진수 (최근 30개, 위가 최신)

    받은 값 (최근 200개)

    시각(s)특성길이16진수
    ✏️ 특성에 쓰기 · 시작 명령 시퀀스 (주의)

    ⚠️ 센서 설정을 바꾸거나 기기가 이상하게 동작할 수 있어요. 무엇을 보내는지 알 때만 쓰세요. 센서를 깨우는 시작 명령을 찾으면 아래 ‘시작 명령 목록’에 저장해 프로필과 함께 쓸 수 있어요.

    저장된 시작 명령 순서 (연결 뒤 자동으로 보낼 명령 — ④ 규칙에 함께 저장됨)

      먼저 ① 연결에서 🔔 알림을 켜거나 📖 읽어 기록을 모으세요. ④ 저장에서 예전 기록 파일을 불러와도 돼요.

      연결해서 받은 패킷을 포장 풀기 → 자리·형식 추론 → 전체 패킷 로컬 검증 → 규칙 저장까지 한 번에 자동화합니다. API 키 없이도 동작하며, Gemini·Claude·GPT API 키를 넣으면 복잡한 시판 센서도 AI 가 함께 역추적합니다.

      🔑 외부 AI API 설정 키 없음

      선생님 개인 API 키(Gemini·Claude·GPT)는 이 브라우저에만 두고 서버로 절대 보내지 않습니다. 수업 연결 화면에서 저장한 키가 있으면 자동으로 불러옵니다.

      시작 위치는 0부터 셉니다. 값 = 읽은 수(마스크를 쓰면 그 비트만) × 배율 + 더할 값

      온도계·저울처럼 믿을 수 있는 기기로 잰 값을 넣고 📌 를 누르면, 이 특성의 가장 최근 패킷과 짝지어 둡니다. 값을 바꿔 가며(데우기·식히기, 추 바꾸기) 3번 이상 찍으세요.
